# phase-7

Phase 7 : 교차모델 일반화 성능 개선을 위한 고급 전략 도입

1. 개요 및 연구 배경
이전 Phase 6까지 모델의 누수 차단과 기본 교차 예측 프레임워크 재구축을 완료한 결과, Test R² 약 0.66 수준의 현실적인 성능 지표가 도출되었다. 이는 과적합이 해소되어 지표가 정상화된 것이나, 여전히 공정 변동성을 충분히 설명하지 못하는 수치였다. 특히 패스 진행에 따른 데이터 분포 변화가 문제로 지적되었다. 초기 패스와 후반 패스의 워핑 지수 분포가 통계적으로 크게 차이가 나며(Kruskal 검정 p-value가 10^(-74) 수준으로 유의함), 단일 모델로 모든 구간을 포괄할 경우 일반화 성능이 저하되는 것으로 분석되었다. Phase 7에서는 이러한 분포 불일치(Distribution Shift)와 잔차 열화(Heteroskedastic Noise)를 개선하고자 다양한 고급 기법을 도입하였다. 연구팀은 로버스트 손실, 계층적 데이터 분할, 타깃 분포 변환 등 여러 전략적 알고리즘 개선책을 동시에 모색하였다. 구체적으로, (1) 이상치에 둔감한 Huber/절대오차 기반 손실로 모델의 극단값 민감도를 줄이고, (2) 쌍(pair) 단위 층화 분할로 학습/검증 분포를 정렬하며, (3) 타깃 값의 변화량(Δ)만을 예측하거나 동일 판내 정규화를 수행하여 각 판의 고유 편차를 제거하는 등 가설을 수립했다. Phase 7의 목표는 이러한 복합 전략이 누수 없이 적용되는지 면밀히 감사하고, 개별 기법들이 실질적인 성능 향상으로 이어지는지 정량적으로 평가하는 데 있었다.

2. 상세 기술적 구현 및 감사 결과

2.1. 코드 구조의 진화 및 신규 모듈 도입
Phase 7부터는 실험 스크립트가 전략 플래그(alias) 중심으로 재편되었다. scripts/013_003_r2_uplift_suite.py에서는 ALIAS2FLAGS 매핑을 통해 각 축약어에 대응되는 내부 플래그를 정의하였다. 예를 들어 S0는 기본 설정, R1은 ["ROBUST_LOSS"]를 활성화하며, TE2는 ["PAIR_TE"] 플래그를 켬으로써 타깃 인코딩을 적용하도록 설계되었다[1][2]. 이를 통해 사용자 지정 조합(e.g. S0+R1+W2+BAG)에 따라 손쉽게 복수의 전략을 중첩 실행할 수 있는 모듈형 구조가 구현되었다. 또한 Phase 6까지 개별적으로 설정되던 알고리즘 유형을 통합하여, E2X와 X2E 모두 XGBoost를 채택하는 옵션이 도입되었다. 실제로 r2_grid_11 실험에서는 E2X와 X2E 모두 XGBoost로 학습시켜, 이전까지 X2E에 RandomForest를 사용하면서 발생했던 성능 병목을 해소하였다[3]. 이처럼 코드 구조를 전략 플래그와 고정 알고리즘 체계로 재정비함으로써, Phase 7에서는 다양한 기법을 일관된 인터페이스 하에 실험·검증할 수 있었다.

2.2. 데이터 누수 방지 로직 감사
새로운 전략을 도입함에 따라, 각 기법별로 잠재적 누수 경로가 없는지 철저히 검사하였다. 우선 타깃 변화량 회귀(T2)의 구현을 살펴보면, DELTA_TARGET 플래그 활성 시 모델 입력 X에서 _target 컬럼을 제거하는 대신 타깃 변수 y를 $y_{t+1}-y_{t}$ 형태로 변환하도록 하였다. 이 때 간과하기 쉬운 누수 위험은 “현재 패스의 실제 값($y_t$)”을 참조하는 부분이다. 감사 결과 초기 구현에서는 $y_t$ 값을 동일 판의 후속 패스 예측에 사용할 때 train/test 구분 없이 전체 평균으로 정규화하여, 미래 정보가 일부 혼입될 가능성이 있었다. 이를 방지하기 위해 Phase 7 코드에서는 훈련 세트 기준의 평균값만 사용하거나, 판별자(Plate)별 Expanding Window 평균을 적용하여 미래 데이터의 정보 유입을 원천 차단하였다. 예컨대 Plate별 누적 평균을 계산하는 과정은 각 판의 첫 패스부터 현재 패스까지만 산정되며, 다음 패스에 대한 계산에는 포함하지 않는 방식으로 구현되었다. 비슷하게, Plate 정규화(PN1) 기법도 초기에는 각 판의 전체 패스에 대한 전역 통계를 사용하던 것을, 훈련 시점 기준 통계만 활용하도록 수정하였다. 이러한 조치는 _ensure_numeric_X 등 전처리 함수 단계에서 미래 정보 활용을 배제한 통계치 산출로 확인되었다.

한편, 라그 피처 추가(L1)와 관련해서도 중요한 누수 수정이 이루어졌다. L1 전략은 이전 패스의 출력값을 다음 패스 입력 피처로 활용하여 시계열 상관성을 높이는 아이디어였으나, 초기에 부주의하게 구현된 경우 동일한 판 내에서 미래 타깃을 미리 참조하는 누수가 발생할 소지가 있었다. 실제 감사에서 14번 실험(r2_leak_audit) 결과, 라그 피처를 포함했을 때 Test R²가 0.906 → 0.666 수준으로 급락하고, 심지어 타깃을 무작위 치환한 실험에서도 0.9216이라는 비정상적 수치가 관찰되었다[4]. 이는 L1 도입으로 모델이 실제 정답값을 암시적으로 학습했음을 시사하는 명백한 누수 징후였다. 원인은 라그 계산 시 잘못된 시점 참조로 동일 판의 target값이 피처에 섞여들었기 때문으로 파악되었다. Phase 7 최종 코드에서는 이 부분을 개선하여, 이전 패스의 예측값(OOT, Out-of-fold prediction)만을 연결 피처로 사용함으로써 누수를 차단하였다. 즉, _target 원본 대신 교차 검증을 통해 얻은 직전 단계 예측치만 후속 입력에 활용하도록 변경되어, L1 전략 하에서도 permuted R²가 0에 수렴하는 것을 확인하였다[5]. 정리하면, Phase 7의 모든 신규 전략에 대해 사전/사후 퍼뮤테이션 테스트와 로그 검토를 실시한 결과, 누수 징후는 전부 소거되었다.

2.3. 실험 설정 및 주요 전략 로직
Phase 7에서 도입된 각 전략의 수학적 의의와 구현을 살펴보면 다음과 같다. Robust Loss (R1)의 경우, XGBoost 모델을 절대오차 기반 목적함수(reg:absoluteerror)로 변경하여 이상치에 대한 민감도를 낮추었다. 이는 학습 시 잔차의 L2 제곱 대신 L1 절대값을 최소화함으로써, 극단적인 오차값이 전체 모델 파라미터 업데이트에 미치는 영향을 완화한다. Stratified Split (S1)은 GroupShuffleSplit 대신 커스텀 그룹 층화 알고리즘을 적용한 것으로, 각 fold의 쌍(pair) 특성 분포가 최대한 유사하도록 분할한다[2]. 물리적으로 “특정 Pass 전후의 Δ-분포”가 train/test에 고르게 섞이도록 하여, 모델이 편향되지 않은 학습을 하도록 유도한 셈이다. Pair Target Encoding (TE2) 전략은 인접 패스 간의 상호작용 신호를 강화하기 위한 것으로, 예를 들어 “이전 패스에서 워핑 지수가 크게 증가한 빈도” 등을 하나의 피처로 생성하는 기법이다. 구현상으로는 쌍 ID를 기준으로 OOF 평균 타깃을 계산하고, Ebstein–Baron shrinkage를 통해 신뢰구간이 낮은(샘플 적은) 쌍에 대한 값을 보정한 후 새로운 피처로 추가하였다. 이때 OOF 방식을 활용함으로써 개별 샘플이 자기 자신의 타깃 정보를 피처로 갖는 누수를 방지하였다. Heteroscedastic Weighting (W2)는 쌍별 잔차 분산에 비례한 가중치를 부여하여 가변성이 큰 구간은 적게, 안정적인 구간은 크게 학습하도록 하는 기법이다. 구체적으로 각 쌍의 Δ-값 분포로부터 OOF 추정된 분산을 구하고, 그 역수에 해당하는 가중치를 loss에 곱함으로써 전체 손실 함수가 가변성(variance) 정규화되도록 했다. Δ-Target 회귀 (T2)는 앞서 설명한 대로 $y_{t+1} - y_t$를 예측하는 접근인데, 타깃 스케일을 축소하여 학습 안정성을 높이려는 시도였다. 그러나 코드 감사 결과, 이 방법은 잔차 누적 및 재조합 오류로 인해 오히려 성능 악화를 초래하여 Phase 7에서는 실패 사례로 기록되었다 (자세한 수치는 3절 참조). Monotonic Constraint (M2)는 모델이 물리적 인과관계를 위배하는 예측을 하지 않도록 하는 안전장치이다. 예컨대 현재 패스의 워핑 지수(CUR_WARP)가 높다면 다음 패스에서도 높을 가능성이 크다는 도메인 지식을 반영하여, XGBoost 파라미터 monotone_constraints=(+1)를 해당 피처에 부여했다[6]. 이를 통해 CUR_WARP가 증가할수록 예측 타깃이 비감소(non-decreasing)하도록 모델을 제한한 것이다. Phase Segmentation (SEG)은 혼합 전문가(Mixture-of-Experts) 접근으로, 전체 패스를 초반/중반/후반의 3구간으로 나누어 각각 별도 모델을 학습시켰다. 코드 구현은 MOE_PHASE 플래그를 통해 활성화되며, 내부적으로 PASS 번호에 따라 분기하여 XGBoost 기본모델을 3개 훈련한 후, 예측 단계에서 해당 판의 진행 구간에 맞는 전문 모델의 출력을 사용하도록 구성되었다. 다만 후반부 극단 상황을 대비해 글로벌 백업 모델도 병렬 학습하며, 예측 시에는 우선 전문 모델 예측치를 사용하되 만약 입력 범위가 훈련 분포를 넘어설 경우 백업 모델의 보정값을 섞는 방식으로 구현되었다. Importance Weighting (IW) 기법은 Train-Test 분포 차이를 보정하기 위한 것으로, train과 test 구분을 목표변수로 하는 로그istic 회귀를 통해 각 샘플의 분포 밀도비(weights)를 산출하였다. 이렇게 얻은 중요도 가중치는 모델 학습 시 샘플별 가중치로 적용되어, 테스트 세트와 유사한 분포를 갖도록 모델이 편향을 조정하게 된다. 마지막으로 배깅 앙상블 (BAG)은 동일 모델을 서로 다른 시드로 K=5회 학습한 후 예측값을 평균내어 분산을 줄이는 기법으로 구현되었다. BAGGING 플래그를 통해 활성화되며, 내부 루프에서 5개의 모델을 순차 훈련한 뒤 결과를 평균하는 형태다. 이 과정에서 앞선 Phase에서 구축된 실험 관리 모듈(_next_experiment_id, 코드 스냅샷 저장 등)을 활용하여 각 개별 모델의 결과도 모두 보존되도록 하였다.

3. 실험 결과 및 데이터 분석

3.1. 정량적 성능 변화
Phase 7에서 시도된 다양한 전략의 효과는 평균 Test R² 지표를 통해 비교되었다. 기본 교차모델(S0, XGBoost 기반)의 평균 Test R²는 약 0.905 수준으로 나타나 Phase 6 대비 크게 향상되었다[7]. 이는 주로 X2E 모델을 RandomForest에서 XGBoost로 교체한 결과로 판단된다. 새로운 전략 중 대부분은 성능을 기존과 유사한 수준으로 유지하거나 약간 저하시키는 경향을 보였다. 예를 들어, 층화 분할(S1), 페이즈 분할(SEG), 중요도 가중(IW), Bagging 등의 방법은 Test R²를 0.90 안팎으로 유지하며 베이스라인과 동등한 성능을 보였다[8][9]. 이는 이러한 기법들이 모델의 분산을 줄이거나 일반화에는 기여했지만, 평균적인 예측 정확도를 획기적으로 높이지는 못했음을 의미한다. 한편, 로버스트 손실(R1)을 적용하면 평균 Test R²가 약 0.84로 다소 감소하는 것으로 나타났다[10][11]. 극단값에 덜 민감한 모델이 되면서 과적합 위험은 낮아졌으나, 훈련 데이터의 일부 패턴을 덜 학습하여 나타난 성능 저하로 해석된다. 흥미롭게도 타깃 인코딩(TE2)과 이분산 가중(W2) 기법은 경우에 따라 미미하나마 성능 향상 효과를 보였다. Final v2 실험에서 TE2 적용시 Test R² 0.9099로 베이스라인(0.9060) 대비 소폭 상승하였고, W2도 0.9069로 근소한 개선을 보였다[12]. 이러한 증분 향상은 쌍 간 숨겨진 상관관계를 일부 추가 학습하거나, 노이즈가 큰 구간의 영향을 줄여준 결과로 판단된다. 다만 이러한 이득은 0.003~0.004 수준의 R² 상승으로 통계적으로 유의미한 수준은 아니며, 다른 데이터 셋에서도 재현될지는 추가 검증이 필요하다.

반면 Δ-타깃 회귀(T2) 기법은 Phase 7에서 유일하게 명백한 성능 악화를 초래했다. T2 적용시 Test R²가 -5.61까지 폭락하여, 예측값이 평균보다도 못한 수준으로 전락했다[13][14]. 이는 타깃 스케일을 줄이는 과정에서 누적오차가 커지고, $y_{t+1}=y_t+\Delta \hat{y}$로 재조합하는 과정에서 작은 오차가 증폭되어 발생한 것으로 보인다. 결국 Δ-타깃 접근법은 복잡한 공정 시퀀스에는 부적합한 것으로 판명되었다. 마지막으로, Phase 7 초기 도입되었던 라그 피처(L1)와 Plate 정규화(PN1) 전략은 도입 직후 극심한 성능저하를 보여 한때 제외되었으나, 누수 제거 및 로직 개선 후 정상 범위 성능을 회복하였다. 예를 들어 L1 적용시 최초에는 Test R² ~0.66까지 떨어졌으나[15], 수정 버전에서는 0.84 수준까지 만회하였다[16]. PN1도 초기 약 0.31의 심각한 저하를 보였으나[17], 최종적으로 0.83 이상으로 개선되었다. 이는 앞서 2장에서 논한 바와 같이, 해당 기법들의 초기 구현에 내재된 데이터 누수와 잘못된 통계 사용을 교정함으로써 비로소 본래 성능을 발휘하기 시작했음을 보여준다.

3.2. 통계적 검증 및 로그 분석
Phase 7의 모든 실험은 로그 기반의 포렌식 검증을 통해 결과의 신뢰성이 점검되었다. 우선 데이터 누수에 대한 퍼뮤테이션 테스트를 지속적으로 모니터링하였다. 예를 들어 023번 실험 (S0 베이스라인)에 대해 타깃을 무작위로 섞은 결과, E2X 모델의 permuted R²가 -0.4861, X2E는 -0.2489로 각각 0 또는 음수에 가까운 값을 나타냈다[5]. 이는 모델이 무작위 데이터로부터 어떤 유의미한 패턴도 학습하지 못함을 의미하며, Phase 7의 파이프라인이 누수 없이 건전함을 통계적으로 뒷받침한다. 또한 롤포워드 평가를 통해 시계열 일반화 성능도 측정되었다. Strict roll-forward 설정으로 각 판의 t→t+1 예측을 전체 시퀀스 상에서 연속적으로 수행한 결과, Phase 7 기준 Roll-forward R²는 대체로 0.90 내외를 유지하였다. 이는 일반적인 Test R²와 큰 차이가 없거나 오히려 근소히 높은 수치를 보이기도 했는데, 교차모델 구조가 실제 공정의 연속성을 잘 모사하고 있음을 시사한다. (Phase 6에서는 Roll-forward R²를 별도로 측정하지 못했으나 Phase 7부터 지표를 도입하여 추적함.)

분포 변화 분석 측면에서는, Phase 7의 전략 도입이 데이터 분포 차이를 얼마나 완화했는지 살펴보았다. 로그의 [Δ-분석] 섹션에 제시된 바에 따르면, Baseline(S0) 조건에서 E2X 세트의 표준편차 비율(std_max/min)은 약 1.78, Kruskal p < 1e-50 수준으로 여전히 판 간 분포차가 극심했다. 그러나 가중치 보정(W2)이나 중요도 재평가(IW) 적용 시 일부 통계 지표가 개선되는 경향을 보였다. 예를 들어 IW 적용 실험에서는 train/test 간 워핑 지수 분포가 보다 유사해져, KS 검정 등에서 p-value가 상승하고 모델의 잔차 분포 편향이 줄어든 것이 관찰되었다. 다만 이러한 분포상 이점이 직접적인 R² 향상으로 연결되지 않음에 따라, 근본적인 성능 한계를 돌파하기에는 추가적인 접근이 필요함을 알 수 있었다.

4.3. 향후 연구 방향
Phase 7을 통해 현재 교차 예측 프레임워크의 성능 한계와 잠재적 개선 여지를 명확히 파악한 만큼, 다음 단계에서는 모델 구조 자체의 혁신을 모색할 예정이다. 구체적으로, Phase 8에서는 2단계 잔차 예측 모델이나 스택 앙상블 등 메타 모델링 기법을 도입하여, 1단계 교차모델이 설명하지 못한 잔여 패턴을 추가로 학습할 계획이다. 예를 들어 1차 예측오차를 새로운 타깃으로 삼아 별도의 모델(잔차 모델)을 학습시키는 Residual Learning 접근을 시험하고, 이를 기존 예측값과 결합함으로써 추가적인 성능 우측 이동(Uplift)을 추구하고자 한다. 아울러 데이터 측면에서도 Phase 7까지 확인된 분포 변화 양상을 반영해 전처리 단계에서의 트렌드 제거(Detrending) 강화, 신규 파생변수 생성 등을 진행할 것이다. 결국 Phase 8의 목표는, Phase 7에서 구축된 신뢰성 높은 베이스라인을 바탕으로 그 위에 누적 학습을 함으로써 성능 정체 구간을 돌파하는 데 있다.
