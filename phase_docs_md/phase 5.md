# phase 5

[Phase 5] : Entry–Exit 교차 예측 모형 재도입 및 성능 회복 분석

1. 개요 및 연구 배경
Phase 4에서 데이터 누수를 차단한 후 모델의 Test R² 점수가 –0.08 수준까지 하락하자, 연구팀은 압연 공정의 Entry와 Exit 예측을 분리함으로써 정보를 낭비하고 있는 것이 아닌지 의문을 제기하였다. 이에 따라 두 예측 모델을 상호 연결하여 각각의 정보를 공유하면 성능을 향상시킬 수 있다는 가설을 수립하였다. 과거 Phase 1 초기에 시도되었던 교차 예측 아이디어(E→X, X→E 예측)를 이번에는 엄격한 롤포워드 평가 체계하에서 재도입하고자 했으며, Entry(입측) 조건과 이전 패스의 Exit(출측) 결과를 활용하여 다음 패스의 품질 지표(워핑 지수)를 예측하는 교차 예측 모형을 설계하였다. 목표는 누수를 유발하지 않으면서 연속 패스 간 물리적 연관성을 모델에 주입하여, 급락한 예측 성능을 회복하는 것이었다.

2. 기술적 구현 및 감사 결과
 교차 학습 구조 도입: Phase 5의 핵심 구현은 Entry–Exit 교차 학습 루프이다. 실제 코드(scripts/079_experiment.py 등)를 살펴보면, 하나의 학습 epoch 내에서 Entry 예측 → 그 결과를 피드백으로 활용한 Exit 예측을 순차적으로 수행하는 구조가 등장한다. 예컨대 이전 패스의 Exit 모델 예측치를 다음 패스의 Entry 특징으로 포함시키고, 두 모델을 교대로 업데이트함으로써 두 예측이 점진적으로 정교해지도록 설계되었다. 또한 알고리즘 측면에서는 Entry→Exit 모델에 XGBoost, Exit→Entry 모델에 RandomForest 등을 혼용하여 다양한 조합을 시험한 후, 최종적으로 양측 모두 XGBoost 회귀모델로 통일함으로써 예측 안정성을 높였다. 이 과정에서 PAIR_TE, HETERO_W 등 여러 플래그가 도입되었는데, Phase 5에서는 해당 옵션들을 활성화(=1)*하여 최대한 교차 정보를 활용하고자 하였다. (USE_PAIR_TE: Entry–Exit 쌍 단위 타깃 인코딩, USE_HETERO_W: 이분산 가중치 적용 등)

데이터 누수 검증: 교차 모형의 구현 코드를 포렌식 감사한 결과, 일부 개선에도 불구하고 잔여 데이터 누수 요인이 식별되었다.

❗ Critical Data Leakage Detected: Pattern B (Sequence Leak) – 069_experiment.py 등의 전처리 로직에서 미래 행의 값을 현재 피처로 이동시키는 결함이 발견되었다. 구체적으로, 전체 데이터프레임을 Plate별로 그룹화한 뒤 warping_index(목표 변수)를 shift(-1) 연산으로 이동시켜 다음 패스의 값을 현재 행에 레이블로 할당하였다. 이 때 Train/Test 구분 전에 수행된 잘못된 시계열 정렬으로 인해, 일부 테스트 타깃 정보가 훈련 피처에 혼입되는 누수가 발생했다. (예: 동일 강판의 t+1 패스 출측 값이 t 패스 입측 데이터에 포함됨)

❗ Critical Data Leakage Detected: Pattern C (Transductive Leak) – 전역 통계치 활용으로 인한 누수도 확인되었다. 표준화 및 통계 피처 생성 단계에서 StandardScaler를 Train/Test 구분 없이 전체 데이터에 대해 fit하고, 롤링 평균 등의 특성을 모든 플레이트 데이터를 기반으로 산출한 부분이 있었다. 이로 인해 테스트 세트의 분포 정보가 훈련 데이터 특성에 반영되는 문제가 발생하였다. 이는 비록 모델 훈련 시 직접적인 정답 노출은 아니지만, 모델이 테스트 분포를 사전에 학습하게 되어 평가의 순수성을 훼손하는 누수이다.

(보조 확인) 이 외에도 IsolationForest 기반 이상치 제거 등의 전처리가 데이터 분할 전에 수행되어, 테스트 데이터의 존재가 학습 데이터 필터링에 영향을 미친 정황이 포착되었다. 이는 Pattern D (Target-Aware Filtering Leak)에 준하는 사례로, 비지도 방식이긴 하나 전체 데이터 분포를 참조하여 훈련 샘플을 걸러낸 것이므로 결과적으로 테스트 정보가 간접 유입되었다고 볼 수 있다.
이러한 누수 요소들은 Phase 5의 교차모델 성능 향상 폭을 일부 과대평가했을 가능성이 있다. 다만 Phase 1~3의 명백한 Label 누수(Pattern A)처럼 즉각적인 고성능 폭증을 야기한 치명적 결함은 이번 단계에서 제거된 상태였다. 실제로 Phase 5의 빠른 누수 점검(LEAK_AUTOCHECK) 옵션에 따르면, 무작위 타깃 퍼뮤테이션시 모델 R²가 0에 수렴하여(예: E2X permuted R² ≈ -0.00) 대형 누수는 없는 것으로 보고되었다. 하지만 위의 미세한 누수들은 여전히 존재하여, 평가 점수의 신뢰도 저하 요인으로 지적되었다.

3. 실험 결과 및 시사점
 성능 지표 회복: 교차 예측 전략을 도입한 069~083번 실험들에서 모델 성능의 유의미한 회복이 관찰되었다. Test R² 기준으로 Phase 4 말기의 -0.08 수준에서 약 0.32~0.34 수준으로 상승하였다. 예를 들어 실험 ID 083에서는 Entry→Exit 모델과 Exit→Entry 모델 모두 XGBoost를 활용하여 평균 Test R² 0.3354를 기록하였다(각 모델 개별 Test R²: 0.3729 및 0.2979). 이는 비록 절대값으로 높지는 않으나, 이전 단계의 모델이 사실상 무작위 추측 수준에 머물렀던 것에 비하면 분명한 개선이다. 더욱이 Rollforward 시뮬레이션 상의 R²도 0.36 내외로 나타나, 교차모델이 시간 순차적 예측에서도 효과를 발휘함을 시사한다.
 교차모형의 유용성과 한계: 이번 Phase 5 실험을 통해 Entry와 Exit 예측을 연계하면 상호 보완적 정보 활용이 가능하다는 점이 입증되었다. 특히 Entry 측 정보로 Exit 결과를 예측하는 E2X 모델의 성능이 상대적으로 높게 나타나, 공정 초기 조건이 다음 패스 품질을 좌우하는 영향을 일부 포착한 것으로 해석된다. 다만 Exit 정보로 다음 Entry를 예측하는 X2E의 경우도 개선은 되었지만 그 폭이 제한적이어서, 교차 특성의 일방향성(Entry 조건 → 차기 품질)이 더 강하다는 도메인 지식을 재확인하였다. 한편, 기술 감사 결과 드러난 잔여 누수 요인은 향후 해소가 필요하다. 실제 Phase 5의 성능 상승분 중 일부는 여전히 데이터 분할상의 허점에서 기인했을 가능성이 있으므로, 연구팀은 Phase 6에서 시계열 정합성 강화(잘못된 shift 정정) 및 전처리의 Train-set 한정 적용 등의 개선 조치를 취할 계획이다. 전반적으로 Phase 5는 엄격한 평가 환경에서도 교차모형으로 성능을 일정 부분 회복했다는 점에서 의미가 있으나, 동시에 데이터 관리의 중요성을 재부각시키는 계기가 되었다.
