# phase 10

[Phase 10] : 최종 모델 통합 및 성능 소폭 향상

1. 개요 및 연구 배경
Phase 9에서 누수 차단과 데이터 정규화를 통해 모델 성능이 초기 기준선에 근접하자, 연구팀은 최종 통합 모델의 검증과 추가 개선 가능성 탐색에 착수하였다. 남은 개선 여력으로 앙상블 기법이나 데이터 증강 등의 아이디어가 논의되었으며, 모델이 학습한 패턴의 유의미성을 최종 점검하기 위한 무작위 타겟 대조 실험도 계획되었다. 본 Phase의 목표는 기존 최적 성능(Test R²≈0.24)을 약간이라도 상회하는 모델을 구축함과 동시에, 이전 단계까지 발견된 데이터 누수 요인을 완전히 제거하여 일반화 성능을 확보하는 데 있었다.

2. 기술적 구현 및 감사 결과
 모델 앙상블 시도: 최종 단계에서 연구팀은 서로 다른 예측기의 결합을 시험하였다. 예를 들어 scripts/272_test.py에서는 두 모델의 예측값을 단순 평균하여 (final_pred = 0.5 * pred_model1 + 0.5 * pred_model2) 성능 향상을 모색하였으나, 해당 실험에서 Test R²=0.1750*로 이전 단일 모델 수준(≈0.20)보다 오히려 소폭 저하되었다. 이에 따라 곧 앙상블안을 철회하고 단일 모델 체제로 복귀하여 일관성을 유지하였다.

디버깅 모드 활성화: Phase 10 후반부 코드(scripts/321_test_no_op.py 등)에서는 상세 로그 출력이 도입되었다. 실행 시 상위 중요 피처 목록과 잔차 분포 분석 결과가 콘솔에 기록되도록 하여, 모델이 어느 피처에 의존하고 있는지 투명하게 점검하였다. 요약 파일에 “FM_R_4[…]” 형태로 상위 10~12개 변수명이 나열된 것은 이러한 디버깅 출력의 결과로, 더 이상 새로운 정보 없이 동일한 주요 피처만 반복됨을 보여준다. 이는 모델이 학습할 수 있는 거의 모든 패턴을 이미 소화하여 추가적인 정보 이득이 제한적임을 시사한다.

최종 하이퍼파라미터 및 구조: 최종적으로 채택된 모델 구성은 XGBoost와 RandomForest 기반의 회귀 조합으로, Phase 9에서 확립된 디트렌딩(detrending) 및 스케일링 오류 수정 로직이 그대로 유지되었다. 실험 로그에 따르면 XGBoost 모듈은 max_depth=6, learning_rate≈0.02 등의 값을 사용하고 RandomForest 모듈은 n_estimators=300, max_depth=None로 설정되는 등, Phase 1 초기 베이스라인과 유사한 파라미터가 적용되었다. 이는 여러 실험을 거친 후 결국 모델이 원점에 가까운 형태로 회귀했음을 의미한다. 딥러닝(LSTM/RNN)과 같은 복잡한 아키텍처도 일부 검토되었으나, 데이터 특성과 실험 결과를 고려해 현실 구현이 어렵다는 판단 하에 최종 배제되었다.

데이터 누수 감사지점: 코드 수준 감사 결과, Phase 10의 일부 스크립트에 남아있는 누수 요소가 확인되었다. 특히 Sequence Leak (패턴 B)이 발견되었는데, scripts/272_test.py 등에서 데이터 프레임을 그룹화한 후 shift(-1) 연산으로 다음 공정의 값을 현재 행의 피처로 포함시키는 로직이 존재했다. 이 방식은 동일 압연판 내 연속 패스를 예측하는 E→X/X→E 전이 모델에서 미래 정보가 현재 학습에 혼입되는 누수를 발생시킬 위험이 있었다. 또한 Transductive Leak (패턴 C)도 일부 식별되었다. 예를 들어, scripts/333_test.py에서는 전체 데이터셋에 대해 전처리 변수를 산출하거나 최종 모델을 재학습하는 코드가 포착되었다. StandardScaler().fit(X)를 활용한 스케일링이나 model.fit(X, y) 호출이 Train/Test 분리 이전에 수행되어, 테스트 세트의 분포 정보가 훈련 과정에 유입된 사례가 이에 해당한다. 이러한 누수 요인은 모델 평가지표를 왜곡시킬 소지가 있으므로, 최종 보고 단계에서 엄격한 주의가 요구되었다. (한편 이전 Phase에서 문제 되었던 Explicit Label Leak (패턴 A)이나 타겟 기반 이상치 제거 (패턴 D) 등은 Phase 10 코드에서는 등장하지 않아, 앞선 단계에서 충분히 개선되었음을 확인하였다.)

3. 실험 결과 및 시사점
 성능 개선 및 한계: Phase 10에서 달성된 최고 Test R²는 0.2513(실험 번호 250)으로, 초기 기준선(0.2416) 대비 소폭 향상된 수치이다. 그러나 이러한 향상폭은 통계적으로 미미하여, 모델 성능은 사실상 0.20대 수준에 수렴하였다. 260~320번대 다수 실험에서 Test R²가 0.18~0.22 범위에 머물렀고, 이는 모델이 추가적인 복잡도를 주입하더라도 본질적인 예측 한계를 넘어서기 어렵다는 점을 보여준다. 실제로 데이터 누수를 엄격히 차단한 이후에는 Train R² 대비 Test R² 격차*가 뚜렷이 벌어졌으며(예: 실험 322에서 Train R² ~0.39 대비 Test R² ~0.23), 이는 모델이 과적합을 억제하고도 얻을 수 있었던 최대한의 일반화 성능이 약 20% 수준임을 시사한다.

검증 실험 및 모델 신뢰도: 최종 단계에서 실시된 무작위 타겟 대조 실험은 모델의 유효성을 확인하는 중요한 근거가 되었다. 333_test와 334_test 실험에서 타겟 값을 무작위로 섞거나 의미 없는 더미 값으로 대체하자, Test R²가 -0.0002 및 -0.0037로 0에 수렴하는 결과가 나타났다. 이는 모델이 더 이상 무작위 노이즈에서 어떠한 신호도 학습하지 못함을 의미하며, 동시에 이전 정상 실험에서 얻은 0.2 수준의 R²가 순전한 우연이 아닌 실제 패턴 학습에 기인한 것임을 뒷받침한다. 달리 말해, Phase 2~3에서 관찰되었던 비정상적으로 높은 R²(>0.9)는 데이터 누수로 인한 허수였음을 최종적으로 입증하였고, 누수를 제거한 현실적인 조건에서 모델이 달성한 성능 지표는 0.2 내외가 타당함을 확인하였다.

결론 및 향후 계획: Phase 10의 결과, 압연 공정 예측 모델의 성능은 사실상 최적점에 도달한 것으로 평가된다. 여러 기법을 종합적으로 적용하고도 더 이상의 유의미한 향상을 이끌어내지 못했으며, 이는 현재 주어진 데이터셋의 한계에 기인한 것으로 보인다. 최종 통합 모델은 이전 Phase들에서 도출된 최적의 요소들(데이터 누수 차단, Feature Scaling 보정, 중요 피처 선택 등)을 모두 포함하였고, 그 성능은 안정적이면서도 검증된 수준으로 수렴되었다. 연구팀은 본 결과를 바탕으로, 추가적인 성능 향상을 위해서는 데이터 확장이나 새로운 특성 추출 등의 접근이 필요하다는 결론을 내렸다. 이번 Phase의 감사 과정에서 식별된 남은 누수 요인은 차기 프로젝트에서 재발되지 않도록 프로세스 전반에 교훈으로 남겼으며, 본 프로젝트는 이를 끝으로 완료되었다.
