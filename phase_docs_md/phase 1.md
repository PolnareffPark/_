# phase 1

[Phase 1] : 초기 데이터 파이프라인 구축과 Entry-Exit 교차 검증

1. 개요 및 연구 배경
베이스라인 모델 수립 단계에서 연구팀은 복잡한 딥러닝 아키텍처(LSTM 등)를 고려했으나, 우선 데이터 전처리 파이프라인을 견고히 구축하고 전통 회귀 모델 기반의 기준 성능을 확보하는 것을 목표로 삼았다. 이를 위해 여러 센서 소스(RM, FM)의 데이터를 통합하고 다음 패스(warping index) 예측을 위한 기본 회귀 모델을 개발하였다. 이후 연속 패스 간 교차 예측(Entry→Exit 및 Exit→Entry)을 도입하여, 인접한 패스의 정보를 활용하면 예측 성능이 향상될 것이라는 가설을 검증하고자 했다. 이 Phase에서는 특히 데이터 정합성과 지표 이상치를 면밀히 감사하여, 초기 모델 성능 개선 요인이 실제 물리적 패턴 학습인지 아니면 데이터 누수에 기인한 허수 효과인지를 판단하는 것이 핵심 배경이었다.

2. 기술적 구현 및 감사 결과
 데이터 병합 및 타깃 생성: scripts/001_pass_t_plus_2_pipeline.py 분석 결과, Entry 방향 및 Exit 방향의 원시 데이터를 결합하고 RM∙FM 센서 정보와 Join하여 최종 데이터프레임을 구성하였다. 이때 각 압연 판(Plate)의 패스 번호순으로 정렬한 후 다음 패스의 warping_index를 타깃(warping_index_target)으로 생성하였다. (예: Pass n의 레코드에 대해 동일 Plate의 Pass n+1의 warping 값을 타깃으로 지정) 또한 데이터 병합 과정에서 불필요한 식별자 컬럼(판번호, 패스번호 등)을 제거하고, SelectKBest 기법으로 상위 120개 피처만 선별하여 모델 입력 변수로 사용하였다.
 베이스라인 모델 학습: 초기 실험(001번)에서 Plate ID를 그룹 단위로 한 GroupShuffleSplit (훈련:검증=80:20, random_state=42)을 적용하여 데이터셋을 분리하였다. Entry 데이터에는 RandomForestRegressor, Exit 데이터에는 XGBoostRegressor를 각각 최적 알고리즘으로 선택하여 별도 모델을 학습하였다. Optuna 기반의 하이퍼파라미터 튜닝 결과를 적용한 모델의 성능 지표로, Entry 예측의 테스트 R² 약 0.2369, Exit 예측의 테스트 R² 약 0.2463을 기록하여 평균 약 0.24 수준의 초기 예측력을 확보하였다.
 교차 전이 모델 구현: 002번 실험부터는 인접 패스 정보를 활용하기 위해 Entry→Exit (E2X)와 Exit→Entry (X2E) 두 방향의 예측 모델을 도입하였다. 구현적으로는 전단계에서 생성된 통합 데이터프레임을 패스 번호의 홀수/짝수 구분으로 분리하여, 홀수 패스(Entry 성향)의 피처로 다음 짝수 패스의 목표값을 예측하는 세트(E2X)와 그 반대 방향(X2E)을 구성하였다. 각 세트에 대해 동일한 전처리(피처 엔지니어링 및 이상치 제거)를 거친 후 별도 모델을 학습하였다. 이 과정에서 동일 판 내 이전 패스 정보(예: 이전 패스 warping 값 prev_warping, 현재 대비 변화량 delta_prev 등)와 패스 진행 단계(Stage) 원-핫 인코딩 등의 파생 변수를 추가하여 시계열 문맥을 모델에 제공하도록 설계되었다.
 데이터 누수 및 버그 식별: 초기 교차 예측 실험(004~005번)에서 극단적으로 음수인 테스트 R²(-0.85)가 관측되었고, 내부 로그에는 IndexError 예외가 보고되었다. 심층 감사 결과, 이는 데이터 인덱싱 불일치로 인한 오결합 현상으로 판명되었다. 구체적으로, 연속 패스 타깃을 생성하는 로직에 결함이 있어 잘못된 다음 패스 값이 피처에 대응되는 Pattern E (Cross-Reference Leak) 유형의 누수가 발생한 것이다. 이 버그로 인해 Exit→Entry 방향 모델이 실질적으로 무작위 추측 이하의 성능을 보였다(R² 급락). 연구팀은 즉시 코드에서 Plate별 그룹화와 정렬 절차를 수정하여 (scripts/006_experiment.py 등) 잘못 연결된 타깃 대응을 교정하였다. 그 결과 후속 실험(006~007번)에서는 두 방향 모델의 테스트 R²가 정상 범위로 회복되었다.
 이상치 제거 절차 점검: 한편, 교차 데이터셋에 공통 적용된 이상치 필터링 과정도 감사되었다. IsolationForest 기반의 1차 필터와 KNN 기반의 2차 필터를 통해 전체 데이터(훈련+테스트 포함)에서 5% 수준의 이상치가 제거되었다. 이 구현은 제거 기준 산정에 타깃 변수까지 활용한다는 점에서 잠재적 누수 위험이 있었다. 즉, 훈련 전에 테스트 데이터의 분포 정보가 포함되어 샘플 제외 여부가 결정되는 Pattern D (Target-Aware Filtering Leak) 요소가 존재하였다. Phase 1에서는 해당 절차가 모델 성능에 큰 영향을 미치지는 않았으나, 본 감사에서는 이러한 설계가 평가 데이터에 간접 정보 노출*을 야기할 수 있음을 지적하였다. 추후 Phase에서는 이러한 누수 가능성을 원천 차단하도록 데이터 전처리 파이프라인을 개선할 계획이다.

3. 실험 결과 및 시사점
 성능 지표 변화: 초기 베이스라인 모델의 평균 테스트 R²가 약 0.2416에 그쳤던 반면, 인접 패스 교차 정보를 도입한 모델들은 평균 R² ≈ 0.4174로 성능이 향상되었다. 특히 Entry→Exit와 Exit→Entry 두 방향 모두 유사한 수준의 예측력을 보이며, 교차 활용 전략의 효과가 일관되게 검증되었다. 다만, 버그 수정 전 일시적으로 관측된 0.85 이상의 비현실적 R²는 데이터 누수로 인한 착시였음이 확인되었다.
 해석 및 향후 계획: Phase 1의 결과는 단기적인 인접 패스 정보가 왜곡 지수 예측에 유의미한 도움을 줄 수 있음을 시사한다. 이는 압연 공정에서 연속되는 두 패스 사이에 물리적 연관성이 존재함을 보여주지만, 장기 메모리 패턴 학습과는 거리가 있었다. 한편, 이번 감사로 식별된 여러 데이터 누수 가능성은 향후 실험의 신뢰도를 위해 선제적으로 차단할 필요가 있다. 연구팀은 Phase 1에서 구축한 파이프라인과 교훈을 바탕으로, 이후 Phase에서는 데이터 누수 방지 장치를 강화하고 딥러닝 등의 고도화된 기법을 적용할 준비를 진행하고 있다. 결과적으로, Phase 1은 초기가설 검증과 데이터 정합성 확보를 위한 단계로서 의미를 갖으며, 다음 연구 단계의 개선 방향을 명확하게 제시하였다.
