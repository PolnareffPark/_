Phase 1 : 입·출측 교차예측 프레임워크 및 초기 성능 검증

1. 개요 및 연구 배경 (Executive Summary)

본 프로젝트의 초기 단계인 Phase 1에서는 단일 패스(Single Pass) 예측의 한계를 극복하고, 압연 공정의 연속성을 반영하기 위한 교차 예측(Cross-Prediction) 프레임워크를 구축하는 데 주력하였다. 기존의 단일 패스 모델은 해당 패스의 입력 변수(RM, FM 데이터)만으로 출측 워핑(Warping) 지수를 예측하려 했으나, 이는 이전 패스로부터 전달되는 형상 정보와 다음 패스로 이어지는 물리적 인과관계를 충분히 포착하지 못한다는 문제점이 있었다. 이에 연구팀은 Entry-Exit Cross Prediction이라는 새로운 접근 방식을 도입하였다. 이는 홀수 패스(Entry)의 데이터를 이용하여 짝수 패스(Exit)의 결과를 예측하고, 반대로 짝수 패스의 결과를 통해 다음 홀수 패스의 입측 조건을 추정하는 상호 보완적 구조이다.

Phase 1의 핵심 목표는 이러한 교차 예측 구조가 기술적으로 구현 가능한지 검증하고, 이를 통해 베이스라인 모델 대비 성능 향상 가능성을 타진하는 것이었다. 이를 위해 데이터 파이프라인을 재설계하여 입측(Entry) 데이터와 출측(Exit) 데이터를 쌍(Pair)으로 구성하고, XGBoost 및 RandomForest 알고리즘을 적용하여 초기 모델을 학습시켰다. 또한, 데이터 누수(Leakage) 가능성을 배제하기 위해 판(Plate) 단위의 데이터 분할 전략을 수립하고, 기본적인 성능 지표(R², RMSE)를 통해 모델의 유효성을 평가하였다.

2. 상세 기술적 구현 (Detailed Technical Implementation)

2.1. 교차 예측 프레임워크 설계 (Cross-Prediction Architecture)

Phase 1의 가장 큰 기술적 변화는 타깃 변수 생성 방식의 변경이다. 기존에는 각 행이 자신의 워핑 지수를 예측했다면, 변경된 프레임워크에서는 현재 패스의 입력 변수(X_t)가 다음 패스의 워핑 지수(y_{t+1})를 예측하도록 타깃을 이동(Shift)시켰다. 이를 위해 데이터 전처리 단계에서 판(Plate) ID를 기준으로 데이터를 정렬한 후, shift(-1) 연산을 통해 다음 패스의 워핑 지수를 현재 행의 타깃 컬럼으로 가져오는 로직을 구현하였다. 이때 마지막 패스의 경우 다음 패스가 존재하지 않으므로 학습 데이터에서 제외 처리하여 데이터 정합성을 유지하였다.

2.2. 데이터 분할 및 누수 방지 (Data Splitting & Leakage Prevention)

시계열 데이터의 특성상 미래 정보가 훈련 데이터에 포함되는 것을 막기 위해, 무작위 분할(Random Split) 대신 판(Plate) 단위의 분할(Group Split)을 적용하였다. 즉, 동일한 판에 속하는 모든 패스 데이터는 훈련 세트나 테스트 세트 중 한 곳에만 속하도록 강제하여, 판 내부의 상관관계가 성능 평가를 왜곡하는 것을 방지하였다. 또한, 교차 검증(Cross-Validation) 시에도 이러한 그룹 분할 원칙을 준수하여 모델의 일반화 성능을 보다 정확하게 측정하고자 하였다.

2.3. 특징 공학 (Feature Engineering)

초기 단계임에도 불구하고 모델의 예측력을 높이기 위해 기본적인 특징 공학을 수행하였다. RM 데이터(압연 설정값)와 FM 데이터(소재 특성값)를 결합하여 풍부한 입력 변수를 확보하였으며, 특히 압연 하중, 속도, 온도 등 주요 조업 인자들의 통계적 특성(평균, 편차 등)을 파생 변수로 생성하여 모델에 주입하였다. 이는 단일 시점의 값뿐만 아니라 공정의 전반적인 상태를 모델이 학습하도록 돕기 위함이다.

3. 실험 결과 및 분석 (Experimental Results & Analysis)

3.1. 초기 성능 지표

Phase 1 실험 결과, 교차 예측 모델은 기존 단일 패스 모델 대비 긍정적인 신호를 보였다. 특히 Entry에서 Exit를 예측하는 모델(E2X)의 경우, 훈련 데이터에 대해 높은 설명력(R²)을 보였으며, 테스트 데이터에서도 일정 수준의 예측 성능을 기록하였다. 이는 입측 조건이 출측 품질에 미치는 물리적 영향력이 상당함을 시사한다. 반면, Exit에서 Entry를 예측하는 모델(X2E)은 상대적으로 낮은 성능을 보였는데, 이는 출측 결과만으로 다음 패스의 입측 조건을 역추적하는 것이 더 복잡한 문제임을 보여준다.

3.2. 데이터 누수 징후 발견

초기 성과에도 불구하고, 일부 실험에서 비정상적으로 높은 R²(0.9 이상)가 관찰되었다. 이는 데이터 전처리 과정에서 미래 정보가 일부 누출되었을 가능성을 시사하는 것으로, 특히 타깃 변수 생성 시의 shift 연산이나 특정 파생 변수 생성 로직에서 의도치 않은 참조가 발생했을 수 있다는 의심을 낳았다. 이에 따라 Phase 2에서는 이러한 데이터 누수 문제를 정밀하게 진단하고 해결하는 것이 최우선 과제로 설정되었다.

4. 결론 (Conclusion)

Phase 1은 교차 예측이라는 새로운 패러다임을 도입하고 그 가능성을 확인한 탐색적 단계였다. 비록 완벽한 성능을 달성하지는 못했고 잠재적인 데이터 누수 이슈가 발견되었으나, 패스 간의 연결성을 모델링하는 것이 워핑 지수 예측에 유효한 접근임을 입증하였다. 이는 향후 Phase에서 진행될 고도화된 모델링과 엄격한 검증의 토대가 될 것이다.

Phase 2 : 데이터 누수 포렌식 감사 및 베이스라인 정화

1. 개요 및 연구 배경

Phase 1에서 관측된 비정상적인 고성능(R² > 0.9)은 모델의 우수성보다는 데이터 누수(Data Leakage)에 기인했을 가능성이 높다는 합리적 의심이 제기되었다. 이에 Phase 2는 모델의 성능을 높이는 것보다, 데이터 파이프라인의 무결성을 검증하고 누수 요인을 찾아내어 제거하는 '포렌식 감사(Forensic Audit)'에 집중하였다. 신뢰할 수 없는 높은 점수보다는, 낮더라도 정직한 베이스라인을 확립하는 것이 향후 연구의 올바른 방향성을 위해 필수적이기 때문이다.

2. 상세 기술적 구현 및 감사 결과

2.1. 데이터 누수 패턴 식별

코드를 정밀 분석한 결과, 다음과 같은 주요 누수 패턴들이 식별되었다.

Label Leakage (정답 누출): 타깃 변수(워핑 지수)와 직접적으로 높은 상관관계를 가지거나, 타깃 변수로부터 파생된 변수들이 입력 피처로 사용되는 경우가 발견되었다. 예를 들어, 특정 통계 변수 생성 시 타깃 값이 포함되거나, 타깃과 동일한 정보를 담고 있는 대체 변수가 필터링되지 않고 학습에 참여한 사례가 있었다.
Future Information Leakage (미래 정보 누출): 시계열 데이터 처리 과정에서 미래 시점의 데이터가 현재 시점의 예측에 활용되는 패턴이다. 특히 판별 통계량(전체 평균 등)을 계산할 때 테스트 데이터까지 포함하여 계산한 후 이를 훈련 데이터에 매핑하는 Transductive Leakage가 확인되었다.
Cross-Reference Leakage (교차 참조 누출): 교차 예측을 위한 데이터 병합 과정에서, 잘못된 인덱싱이나 조인(Join) 로직으로 인해 짝수 패스의 정답이 홀수 패스의 입력으로 섞여 들어가는 현상이 일부 코드에서 발견되었다.

2.2. 누수 차단 조치 (Leakage Mitigation)

식별된 누수 패턴을 제거하기 위해 다음과 같은 조치들이 취해졌다.

엄격한 변수 필터링: 타깃 변수와 상관계수가 1.0에 가깝거나, 이름에 'target', 'label' 등이 포함된 변수들을 자동으로 식별하여 학습에서 배제하는 로직을 강화하였다.
Train-Only Preprocessing: 모든 전처리(스케일링, 통계량 산출 등)는 오직 훈련 데이터(Train Set)만을 기준으로 수행되도록 코드를 수정하였다. 테스트 데이터는 훈련 데이터에서 산출된 통계량을 적용(Transform)하기만 하도록 하여 정보 유출을 원천 차단하였다.
Group-based Split 강화: 판(Plate) 단위 분할을 더욱 엄격하게 적용하여, 훈련과 테스트 데이터 간의 정보 교류를 물리적으로 분리하였다.

3. 실험 결과 및 분석

3.1. 성능 거품의 붕괴

누수 차단 조치를 적용한 후 모델을 재학습시킨 결과, 예상대로 성능 지표가 급락하였다. 0.9대를 상회하던 R²는 0.1~0.2 수준으로 떨어졌으며, 일부 경우에는 음수를 기록하기도 하였다. 이는 기존의 높은 성능이 모델의 학습 능력이 아닌, 정답지를 미리 보고 푼 결과였음을 명확히 보여준다.

3.2. 현실적인 베이스라인 확인

비록 성능 수치는 낮아졌지만, 이는 데이터 누수가 제거된 '청정(Sanitized)' 상태에서의 진짜 실력을 의미한다. 이제 연구팀은 이 현실적인 베이스라인(R² ≈ 0.15)에서 출발하여, 순수한 모델링 기법과 특징 공학만으로 성능을 향상시켜야 하는 과제를 안게 되었다.

4. 결론

Phase 2는 뼈아프지만 반드시 필요한 '거품 제거' 과정이었다. 데이터 누수라는 치명적인 오류를 바로잡음으로써 프로젝트의 신뢰성을 회복하였으며, 향후 연구가 올바른 데이터 위에서 수행될 수 있는 기반을 마련하였다. 이제부터의 성능 향상은 진짜 기술적 진보를 의미하게 될 것이다.

Phase 3 : 심층 누수 감사 및 일반화 검증

1. 개요 및 연구 배경

Phase 2에서 주요 누수 요인을 제거했음에도 불구하고, 여전히 모델의 일반화 성능(Generalization Performance)에 대한 의구심이 남아있었다. 특히 훈련 데이터와 테스트 데이터 간의 성능 격차(Overfitting)가 크고, 특정 조건에서 성능이 들쑥날쑥한 현상이 지속되었다. 이에 Phase 3에서는 더욱 깊이 있는 수준의 누수 감사(Deep Audit)를 수행하고, 모델이 학습한 패턴이 과연 물리적으로 유의미한 것인지 검증하는 데 초점을 맞추었다. 또한, 실제 현업 적용 시나리오와 유사한 '롤포워드(Roll-forward)' 검증 방식을 도입하여 모델의 실전 능력을 평가하고자 했다.

2. 상세 기술적 구현 및 감사 결과

2.1. 누수 패턴 A-F 분류 및 점검

연구팀은 데이터 누수 유형을 A부터 F까지 세분화하여 체계적으로 점검하였다.

Pattern A (Label Leakage): 타깃 변수 직접 혼입 여부 재점검.
Pattern B (Sequence Leakage): 시계열 순서 위배 여부 점검.
Pattern C (Transductive Leakage): 테스트 데이터 통계 활용 여부 점검.
Pattern D (Index Leakage): 인덱스나 식별자가 정보로 활용되는지 점검.
Pattern E (Metadata Leakage): 메타데이터(파일명 등)를 통한 정보 유출 점검.
Pattern F (Residual Leakage): 기타 미세한 잔존 누수 가능성 점검.
이러한 체계적인 분류를 통해 코드 전반을 다시 훑어보았으며, 특히 Pattern F와 관련된 미세한 상관관계들을 집중적으로 분석하였다.

2.2. Permutation Test 도입

누수 여부를 통계적으로 검증하기 위해 Permutation Test(순열 검정)를 도입하였다. 이는 타깃 변수를 무작위로 섞은(Shuffle) 데이터로 모델을 학습시켰을 때, 성능이 0에 수렴하는지를 확인하는 방법이다. 만약 타깃을 섞었음에도 불구하고 높은 성능이 나온다면, 이는 모델이 타깃이 아닌 다른 곳(누수된 피처)에서 정답 정보를 얻고 있다는 강력한 증거가 된다. 실험 결과, Phase 3 모델은 Permutation Test에서 R² ≈ 0 (또는 음수)를 기록하여, 주요 누수 경로가 차단되었음을 통계적으로 입증하였다.

2.3. Strict Roll-forward Validation

기존의 무작위 판 분할 대신, 시간 순서에 따른 엄격한 롤포워드 검증을 수행하였다. 즉, 과거의 판들로 학습한 모델이 미래의 판들을 얼마나 잘 예측하는지를 평가하는 방식이다. 이는 시계열적 분포 변화(Distribution Shift)가 존재하는 실제 공정 환경을 가장 잘 모사하는 평가 방법이다.

3. 실험 결과 및 분석

3.1. 일반화 성능의 한계 확인

엄격한 롤포워드 검증 결과, 모델의 성능은 여전히 만족스럽지 못했다. Test R²는 0.2 내외에 머물렀으며, 패스 간 분포 차이가 큰 경우 예측력이 급격히 저하되는 현상이 관찰되었다. 이는 데이터 누수가 없는 상태에서 현재의 모델 구조와 피처만으로는 공정의 복잡성을 완전히 설명하기 어려움을 시사한다.

3.2. 분포 변화(Distribution Shift)의 영향

분석 결과, 판마다, 그리고 패스마다 데이터의 분포(평균, 분산 등)가 상당히 다르다는 것이 확인되었다. 훈련 데이터의 분포와 테스트 데이터의 분포가 다를 경우, 모델은 과거의 패턴을 미래에 적용하는 데 실패하게 된다. 이는 향후 Phase에서 분포 정규화(Normalization)나 도메인 적응(Domain Adaptation) 기법이 필요함을 강력하게 암시하는 결과였다.

4. 결론

Phase 3를 통해 데이터 누수에 대한 검증은 사실상 완료되었다. 이제 남은 과제는 '누수 없는' 상태에서 어떻게 모델의 예측력을 끌어올릴 것인가이다. 특히 시계열적 분포 변화에 대응할 수 있는 강건한(Robust) 모델링 전략이 요구되며, 이는 Phase 4 이후의 핵심 연구 주제가 될 것이다.

Phase 3.5 : 하드 리크 가드 및 교차 전이 모델링

1. 개요 및 연구 배경

Phase 3의 심층 감사 결과, 여전히 미세한 누수 가능성과 과적합 경향이 남아있음이 확인되었다. 이에 Phase 3.5에서는 'Hard Leak Guard'라는 더욱 강력한 누수 차단 메커니즘을 도입하고, 데이터 전처리의 안전성을 확보하는 데 주력하였다. 또한, 단순한 교차 예측을 넘어선 '교차 전이(Cross-Transition)' 모델링을 시도하여, Entry에서 Exit로, 그리고 Exit에서 다음 Entry로 이어지는 공정의 흐름을 보다 정교하게 포착하고자 했다.

2. 상세 기술적 구현 및 감사 결과

2.1. Hard Leak Guard 구현

기존의 이름 기반 필터링을 넘어, 값(Value) 기반의 누수 탐지 로직을 추가하였다. 훈련 데이터의 타깃 값과 모든 피처 간의 상관계수를 계산하여, 상관계수가 1.0(또는 극도로 높은 값)인 피처를 자동으로 찾아내어 제거하는 기능을 구현하였다. 이는 변수명이 다르더라도 내용물이 정답과 동일한 경우를 걸러내기 위한 최후의 보루이다. 또한, 전처리 파이프라인 내에 Assert 문을 곳곳에 배치하여, 데이터 크기나 인덱스가 예상과 다를 경우 즉시 에러를 발생시키도록 하여 잠재적 오류를 방지하였다.

2.2. Cross-Transition 모델링 (E->X, X->E)

교차 예측을 두 가지 방향으로 명확히 분리하여 모델링하였다.
E->X (Entry to Exit): 현재 패스의 입측 정보로 출측 품질을 예측.
X->E (Exit to Entry): 현재 패스의 출측 정보로 다음 패스의 입측 품질을 예측.
이 두 모델을 결합함으로써, 공정 전체를 아우르는 예측 체인을 형성하고자 했다. 특히 X->E 모델은 이전 패스의 결과가 다음 패스에 미치는 영향을 학습하므로, 공정의 연속성을 반영하는 핵심 고리가 된다.

2.3. Anchor From Cross 전략

교차 검증 시, 훈련 데이터와 검증 데이터의 분포가 지나치게 달라지는 것을 막기 위해 'Anchor From Cross' 전략을 시도하였다. 이는 훈련 데이터의 통계적 특성(Anchor)을 기준으로 검증 데이터를 정규화하거나 보정하는 방식이다. 그러나 이 과정에서 테스트 데이터 정보가 훈련에 섞여 들어갈 위험(Transductive Leakage)이 있어, 구현에 매우 신중을 기하였다.

3. 실험 결과 및 분석

3.1. 성능 향상과 그 의미

Hard Leak Guard 적용 후, 모델의 성능은 더욱 현실적인 수준으로 수렴하였다. Test R²는 0.25~0.30 수준으로, 이는 누수가 없는 상태에서 달성 가능한 실질적인 성능 향상을 의미한다. 특히 E->X 모델의 성능이 X->E 모델보다 높게 나타났는데, 이는 입측 조건이 출측 결과에 미치는 직접적인 영향이 더 크고 명확하기 때문으로 해석된다.

3.2. Delta-Target 회귀의 어려움

타깃 변수를 절대값이 아닌 변화량(Delta)으로 예측하려는 시도(Delta-Target Regression)가 있었으나, 결과는 좋지 않았다. 변화량의 신호 대 잡음비(SNR)가 너무 낮아 모델이 유의미한 패턴을 학습하지 못하고, 오히려 노이즈에 과적합되는 경향을 보였다. 이는 향후 타깃 변환 전략에 대한 재검토가 필요함을 시사한다.

4. 결론

Phase 3.5는 누수 차단을 시스템화하고(Hard Leak Guard), 교차 예측을 구체화(Cross-Transition)한 단계였다. 이를 통해 모델의 신뢰성은 한층 강화되었으며, 성능 향상을 위한 구조적 기반이 마련되었다.

Phase 4 : 변수 레벨 정밀 감사 및 평가 시스템 확립

1. 개요 및 연구 배경

Phase 3.5까지의 노력으로 주요 누수 경로는 차단되었으나, 여전히 잔존하는 미세 누수나 데이터 처리 과정의 논리적 오류 가능성을 완전히 배제할 수는 없었다. Phase 4에서는 변수(Variable) 하나하나를 현미경으로 들여다보듯 정밀 감사(Variable-Level Audit)하고, 평가 시스템의 신뢰도를 최상으로 끌어올리는 데 집중하였다. 또한, OOF(Out-of-Fold) 예측을 활용한 특징 공학이 누수를 유발하지 않는지 검증하는 것도 중요한 목표였다.

2. 상세 기술적 구현 및 감사 결과

2.1. Train-Only Preprocessing의 전면 적용

데이터 전처리의 모든 단계(결측치 처리, 스케일링, 인코딩 등)에서 'Train-Only' 원칙을 철저히 적용하였다. 즉, fit() 메서드는 오직 훈련 데이터에만 호출되고, 테스트 데이터에는 transform()만 호출되도록 코드를 강제하였다. 이를 위해 전처리 클래스들을 래핑(Wrapping)하거나 커스텀 변환기를 제작하여, 실수로라도 테스트 데이터가 fit에 관여하지 못하도록 원천 봉쇄하였다.

2.2. OOF Feature Engineering 검증

타깃 인코딩(Target Encoding)이나 예측값 기반 피처(Stacking Feature)를 생성할 때, OOF 방식을 사용하여 자기 자신(Self)의 정보가 피처에 포함되지 않도록 하였다. K-Fold 방식으로 데이터를 나누어, 검증 데이터의 피처를 생성할 때는 나머지 훈련 데이터만을 사용하여 통계량을 산출하는 방식이다. Phase 4에서는 이 로직이 올바르게 구현되었는지 전수 검사하였고, 누수 없이 정보력을 높이는 수단으로 확정하였다.

2.3. 통계적 분포 분석 (Statistical Distribution Analysis)

데이터의 분포 특성을 파악하기 위해 다양한 통계적 검정(Kruskal-Wallis, Levene Test 등)을 수행하였다. 그 결과, 패스 번호가 증가할수록 워핑 지수의 분산이 감소하는 등 뚜렷한 이분산성(Heteroscedasticity)이 확인되었다. 이는 모델 학습 시 패스별로 가중치를 다르게 부여하거나, 별도의 모델을 사용하는 것이 유리할 수 있음을 시사한다.

3. 실험 결과 및 분석

3.1. 완전한 누수 제거 확인

Phase 4의 엄격한 파이프라인 하에서 모델을 학습시킨 결과, Test R²는 0.2~0.25 수준으로 안정화되었다. 이는 더 이상의 '거품'은 없으며, 이것이 현재 데이터와 모델이 가진 진짜 실력임을 확정하는 수치이다.

3.2. 평가 지표의 신뢰성 확보

엄격한 롤포워드 검증과 Permutation Test가 정착되면서, 평가 지표의 신뢰도가 크게 향상되었다. 이제 연구팀은 0.01의 성능 향상이라도 그것이 진짜 개선인지, 아니면 우연이나 누수에 의한 것인지 명확히 구분할 수 있게 되었다.

4. 결론

Phase 4를 통해 데이터 파이프라인의 '무결성(Integrity)'은 완성 단계에 도달하였다. 이제 연구팀은 흔들리지 않는 단단한 지반 위에서, 순수한 모델링 역량만으로 성능을 쌓아 올려야 하는 단계로 진입하였다.

Phase 5 : 입·출측 교차 예측 프레임워크의 고도화

1. 개요 및 연구 배경

Phase 4에서 확립된 무결한 데이터 파이프라인을 바탕으로, Phase 5에서는 교차 예측 프레임워크를 본격적으로 고도화하였다. 단순히 입측과 출측을 연결하는 것을 넘어, 바이어스 보정(Bias Correction), 엄격한 롤포워드(Strict Roll-forward) 검증 등 실전적인 기법들을 도입하여 모델의 일반화 성능을 극대화하고자 했다. 특히, 이전 Phase들에서 관찰된 성능 정체(Plateau)를 돌파하기 위해 도메인 지식을 활용한 피처 엔지니어링에 집중하였다.

2. 상세 기술적 구현 및 감사 결과

2.1. 2-Pass Transition (E2X & X2E) 리팩토링

코드를 리팩토링하여 2-Pass Transition 구조를 명확히 하였다.
E2X Model: Pass(t) Entry -> Pass(t) Exit 예측
X2E Model: Pass(t) Exit -> Pass(t+1) Entry 예측
이 두 모델이 유기적으로 연결되어 전체 압연 공정을 시뮬레이션할 수 있도록 파이프라인을 구성하였다.

2.2. Bias Correction (A2) 전략

모델의 예측값이 실제값과 일정한 편차(Bias)를 보이는 현상을 수정하기 위해, 사후 보정(Post-hoc Correction) 전략을 도입하였다. 예측된 값에 훈련 데이터의 잔차 평균 등을 더해주거나, 분포의 중심을 맞춰주는 방식이다. 이를 통해 예측의 정확도(Accuracy)뿐만 아니라 정밀도(Precision)를 높이고자 했다.

2.3. Strict Roll-forward Validation 강화

롤포워드 검증을 더욱 엄격하게 적용하였다. 단순히 미래 데이터를 예측하는 것을 넘어, 예측된 값을 다음 단계의 입력으로 사용하는 '재귀적(Recursive)' 예측 시나리오까지 테스트하였다. 이는 실제 공정 제어 시스템이 작동하는 방식과 동일하며, 모델의 오차 누적(Error Propagation) 특성을 파악하는 데 결정적인 역할을 했다.

3. 실험 결과 및 분석

3.1. 성능의 회복과 안정화

고도화된 교차 예측 모델은 Test R² 0.25~0.35 수준의 성능을 기록하였다. 특히 Strict Roll-forward R²가 0.4264까지 도달하는 쾌거를 이루었는데, 이는 모델이 단발성 예측뿐만 아니라 연속적인 공정 흐름을 꽤 잘 쫓아가고 있음을 의미한다. 이는 누수 제거 이후 가장 고무적인 성과였다.

3.2. 도메인 지식의 중요성 재확인

RM/FM 데이터의 통계적 특성을 활용한 피처들이 모델 성능 향상에 크게 기여함이 확인되었다. 이는 데이터 사이언스 기법만으로는 한계가 있으며, 철강 압연 공정에 대한 도메인 지식이 결합될 때 비로소 유의미한 성능 향상이 가능함을 보여준다.

4. 결론

Phase 5는 교차 예측 프레임워크가 궤도에 올랐음을 알리는 단계였다. 모델은 안정적인 성능을 보여주기 시작했고, 엄격한 검증 통과를 통해 실전 적용 가능성을 내비쳤다. 하지만 여전히 0.4대라는 R² 수치는 개선의 여지가 많으며, 특히 패스 간 분포 차이에 대한 대응책이 필요하다는 과제를 남겼다.

Phase 6 : 누수 패턴 감사 및 V2 교차 모듈 도입

1. 개요 및 연구 배경

Phase 5에서 교차 예측의 가능성을 확인했지만, 여전히 잔존하는 미세 누수 패턴(A-F)에 대한 우려가 완전히 해소되지 않았다. 또한, 모델의 성능이 특정 구간에서 정체되는 현상을 극복하기 위해 더욱 정교한 모델링 접근이 필요했다. Phase 6에서는 누수 패턴 A-F를 체계적으로 감사하여 수정하고, 'V2 교차 모듈'이라는 개선된 아키텍처를 도입하여 성능과 안정성을 동시에 잡고자 했다.

2. 상세 기술적 구현 및 감사 결과

2.1. 누수 패턴 A-F의 완전한 해결

Phase 3에서 정의된 누수 패턴 A-F에 대해 최종 점검을 수행하였다.
Pattern A (Label): 타깃 변수와 유사한 값을 갖는 모든 파생 변수를 제거.
Pattern B (Sequence): 시계열 순서를 위배하는 미래 참조 로직을 전수 조사하여 수정.
Pattern C (Transductive): 테스트 데이터 통계가 훈련에 사용되는 경로를 차단.
Pattern D (Index): 인덱스 정보가 피처로 사용되지 않도록 조치.
Pattern E (Metadata): 파일명 등 메타데이터를 통한 정보 유출 방지.
Pattern F (Residual): 잔존하는 미세 상관관계를 분석하여 의심스러운 변수 제거.
이 과정을 통해 데이터 파이프라인은 '무결점(Zero-Defect)' 상태에 도달하였다.

2.2. V2 교차 모듈 (Cross-Module V2) 도입

기존의 단순한 E2X, X2E 모델을 고도화하여 V2 모듈을 개발하였다.
Strict Split: 데이터 분할 시 판(Plate) 단위 분할을 더욱 엄격하게 적용하여, 훈련/검증/테스트 데이터 간의 독립성을 보장하였다.
OOF Feature Generation: 타깃 인코딩 등 피처 생성 시 OOF 방식을 의무화하여, 자기 참조 누수를 원천 차단하였다.
Cross-Reference Prevention: 교차 예측 시 상대방 모델의 미래 예측값을 참조하지 않도록, 시점(Time Step) 관리를 철저히 하였다.

2.3. 이분산성(Heteroscedasticity) 분석

데이터의 분산이 일정하지 않은 이분산성 문제를 심도 있게 분석하였다. 특히 패스 후반부로 갈수록 분산이 줄어드는 경향을 확인하고, 이를 모델링에 반영하기 위한 기초 연구를 수행하였다.

3. 실험 결과 및 분석

3.1. 성능의 정상화와 재도약

누수 제거 직후 Test R²는 0.23 수준으로 다소 하락하였으나, 이는 거품이 빠진 정상적인 수치였다. 이후 V2 모듈과 정교한 피처 엔지니어링을 통해 Test R²를 0.2576까지 끌어올렸다. 이는 수치적으로는 작아 보일 수 있으나, 누수가 없는 청정 환경에서 이루어낸 값진 성과이다.

3.2. Permutation Test를 통한 검증

Permutation Test 결과, R²가 0에 수렴함을 재확인하였다. 이는 V2 모듈이 데이터의 실제 패턴만을 학습하고 있으며, 어떠한 꼼수(Trick)도 부리지 않고 있음을 증명한다.

4. 결론

Phase 6는 누수와의 전쟁을 끝내고, V2 모듈이라는 새로운 무기를 장착한 단계였다. 이제 모델은 더 이상 데이터의 결함에 의존하지 않으며, 오직 물리적 인과관계와 통계적 패턴에 기반하여 예측을 수행한다.

Phase 7 : 교차 모델 일반화 성능 향상을 위한 고급 전략

1. 개요 및 연구 배경

Phase 6까지 구축된 견고한 베이스라인 위에서, Phase 7은 모델의 일반화 성능(Generalization)을 극대화하기 위한 고급 전략들을 실험하였다. 특히 훈련 데이터와 테스트 데이터 간의 분포 차이로 인한 성능 저하를 막고, 모델이 보다 강건하게(Robust) 학습되도록 유도하는 다양한 기법들이 도입되었다.

2. 상세 기술적 구현 및 감사 결과

2.1. 전략 플래그(Strategy Flags) 시스템 도입

실험의 효율성과 재현성을 높이기 위해, 다양한 전략들을 플래그(Flag) 형태로 제어할 수 있는 시스템을 구축하였다.
USE_ROBUST_LOSS: 이상치(Outlier)에 덜 민감한 손실 함수(Huber Loss 등) 사용.
USE_STRATIFIED_SPLIT: 데이터 분할 시 타깃 분포를 고려하여 층화 추출(Stratified Sampling) 적용.
USE_TARGET_TRANSFORM: 타깃 변수의 분포를 정규분포에 가깝게 변환(Yeo-Johnson 등)하여 학습.
이러한 플래그들을 조합하여 최적의 모델 설정을 탐색하였다.

2.2. Robust Loss와 Stratified Split

이상치에 강한 Robust Loss를 도입하여 모델이 노이즈에 휘둘리지 않도록 하였으며, Stratified Split을 통해 훈련 데이터와 검증 데이터가 유사한 분포를 갖도록 유도하였다. 이는 특히 데이터 수가 적거나 분포가 불균형한 상황에서 모델의 안정성을 높이는 데 기여하였다.

2.3. Target Distribution Transformation

타깃 변수의 분포가 비대칭적이거나 꼬리가 긴 경우(Skewed), 이를 변환하여 모델이 학습하기 좋은 형태로 만들어주는 기법을 적용하였다. 이를 통해 예측의 편향(Bias)을 줄이고 전반적인 정확도를 높이고자 했다.

3. 실험 결과 및 분석

3.1. 성능의 한계와 안정성 확보

다양한 고급 전략을 적용했음에도 불구하고, Test R²는 0.25 수준에서 크게 벗어나지 못했다. 이는 현재 사용 중인 피처와 모델 구조가 가진 정보량의 한계(Ceiling)에 도달했음을 시사한다. 하지만 모델의 안정성(Stability) 측면에서는 개선이 있었다. 여러 번의 실험에서도 성능 편차가 줄어들었고, 이상치에 대한 예측이 덜 민감해지는 효과를 거두었다.

3.2. 해석 가능성(Interpretability) 향상

전략 플래그 시스템을 통해 각 기법의 효과를 개별적으로 분석할 수 있게 되었으며, 어떤 요소가 성능에 긍정적/부정적 영향을 미치는지 명확히 파악할 수 있었다. 이는 향후 연구 방향을 설정하는 데 중요한 나침반이 되었다.

4. 결론

Phase 7은 가용한 모든 기술적 수단을 동원하여 성능의 한계를 검증한 단계였다. 다양한 고급 기법들을 시도하며 성능의 천장을 확인하였고, 이제는 기존의 틀을 깨는 새로운 접근(예: 딥러닝, 앙상블 등)이 필요함을 절감하였다.

Phase 8 : 입·출측 교차예측 프레임워크 재도입 및 엄격 롤포워드 검증

1. 개요 및 연구 배경 (Executive Summary)

이전 Phase 7까지 모델의 일반화 성능은 매우 낮은 수준에 머물러 있었다. 특히 Test R² 지표는 0에 수렴하거나 음수를 기록하여, 데이터 누수 방지 이후 모델이 사실상 예측력을 상실한 상태임이 확인되었다. 이는 단일 패스의 정보만으로는 압연 공정의 복잡한 변동성을 설명하기 어렵다는 것을 의미한다. 즉, 인접한 패스 간의 상호 의존성(Inter-pass Dependency)을 모델링하지 않고서는 유의미한 예측 신호를 포착하기 힘들다는 문제 의식이 도출되었다.

이에 따라 연구팀은 교차 예측 프레임워크를 Phase 8에 재도입하기로 결정했다. 물리적으로 “입측 조건이 출측 품질을 결정하고, 출측 결과가 곧바로 다음 패스의 입측 조건으로 이어진다”는 인과 관계에 착안하여, 입측→출측(E→X) 및 출측→입측(X→E) 두 방향의 모델을 동시에 학습시키는 구조를 설계하였다. 이를 통해 이전 Phase에서 배제되었던 패스 간 연속성을 인공적으로나마 복원하여 정보 이득(Information Gain)을 얻는 것이 본 Phase의 핵심 가설이다.

Phase 8의 목표는 이러한 E↔X 교차 모델이 엄격한 롤포워드 검증 환경에서도 성능 향상을 나타내는지 확인하는 데 있다. 구체적으로, 롤포워드(Roll-forward)란 판별된 Train/Test 분할에 따라 첫 패스부터 최종 패스까지 순차적으로 모델 예측을 이어가는 평가 방식을 의미한다. 본 Phase에서는 교차 모델의 예측값을 실제 다음 패스의 입력으로 지속적으로 공급하며, 시계열적 누적 오차 없이 예측력이 유지되는지를 검증했다. 궁극적으로, 데이터 누수 없이 확보된 청정(BaseLine) 환경에서 교차 예측이 실질적인 성능 개선을 이끌어낼 수 있는지 규명하고, 이후 Phase에서 도입할 추가 개선책의 필요성을 평가한다.

2. 상세 기술적 구현 및 감사 결과 (Detailed Technical Audit)

2.1. 주요 코드 변경 사항 및 구조적 진화 (Key Code Evolution)

Phase 8에서는 기존 단일 스크립트 형태의 파이프라인을 이중 모듈 구조로 재편하였다. 즉, 하나의 판(Plate) 내에서 입측 데이터로 출측 워핑 지수를 예측하는 E2X 모델과, 반대로 출측 결과를 이용해 다음 패스의 타깃(입측)을 예측하는 X2E 모델을 분리 구현했다. 이를 위해 final_df 데이터프레임을 구성할 때 각 판의 현재 패스 워핑 지수를 입력 변수(warping_index_current_pass)로 두고, 다음 패스의 워핑 지수를 타깃 변수(warping_index_target)로 생성하였다. 구체적으로, pandas.DataFrame.groupby(PLATE_COL)["warping_index"].shift(-1) 연산을 통해 각 판별로 다음 패스의 warping_index를 추출하여 타깃 컬럼으로 추가하고, 기존 warping_index 컬럼은 현재 패스의 피처로 이름 변경하였다. 이 과정에서 마지막 패스에는 타깃 값이 존재하지 않으므로 해당 레코드는 학습에서 제외하도록 전처리되었다.

데이터 병합 단계에서는 RM 데이터(압연 기계 설정값)와 FM 데이터(소재 특성값)를 모두 ground_truth와 조인하여, 각 패스에 대한 다양한 입력 변수를 확보했다. 또한 동일 판 내 여러 패스에서 발생하는 공정 조건 분포의 차이를 모델이 인지하도록, 판 단위 통계 특징을 추가 생성했다. 예를 들어 RM 데이터에 대해서는 판별 그룹별로 다섯 가지 요약 통계치(평균, 최댓값, 최솟값, 표준편차, 중앙값)를 계산하여 RM_***_mean, RM_***_std 등의 새로운 피처로 병합하였다. 마찬가지로 FM 데이터에 대해서도 각 행에 존재하는 다수의 센서 값들을 통합하는 파생변수 (FM_mean, FM_std, FM_range 등)를 생성하여 입력 특징 공간의 정보 밀도를 높였다. 이러한 다중 데이터 소스 결합 및 파생 변수 추가를 통해, E2X 모델은 입측판 및 공정 조건 전반을 고려한 출측 품질 예측을 수행하고, X2E 모델은 이전 패스의 결과로 다음 패스의 품질을 추정하는 구조를 갖추게 되었다.

모델링 부분에서는 교차 검증과 데이터 분할 전략에 중요한 수정이 가해졌다. 이전 Phase까지 일부 실험에서는 전체 데이터에 대해 K-Fold를 적용하거나 잘못된 방식으로 시계열 분할을 수행하여 누수 가능성이 있었다. Phase 8에서는 이를 방지하기 위해 판(Group) 단위 분리를 철저히 적용했다. GroupShuffleSplit을 활용하여 동일 판에 속한 모든 패스 데이터를 훈련 또는 테스트 중 한쪽에만 속하도록 데이터를 분할함으로써, 특정 판의 출측 정보가 동일 판의 입측 예측에 스며드는 누수 경로를 원천 차단하였다. 그 결과, 학습 시에는 한 판의 모든 패스 연속 데이터가 훈련에 사용되거나 배제되며, 테스트 시에도 훈련에 전혀 등장하지 않은 판들의 연속 패스들만으로 성능을 검증하게 되었다. 이렇게 설정된 Group별 시나리오 분할은 교차 예측 모델의 일반화 검증에 필수적인 기반을 제공하였다.

2.2. 데이터 누수 및 정합성 포렌식 (Forensic Leakage Audit)

Phase 8 코드에 대한 포렌식 감사 결과, 명시적인 데이터 누수는 발견되지 않았다. 우선, 입력 피처 구성 단계에서 _drop_name_leaky_cols 함수와 _assert_and_drop_value_leak 함수의 이중 방어막이 새롭게 도입되었다. _drop_name_leaky_cols는 컬럼명에 target, label, pred, oof 등 정답정보 누출을 암시하는 패턴이 포함된 경우 자동으로 해당 변수를 제거한다. 이러한 패턴들은 정규표현식 리스트 LEAKY_PATTERNS로 관리되며, 예컨대 'target', 'label', 'y_true', 'y_pred' 등이 포함되어 있어 해당 키워드를 이름에 가진 어떠한 컬럼도 예외 없이 학습 입력에서 제외된다. 그 결과, 잘못된 전처리나 피처 추가로 타깃 값을 그대로 갖는 컬럼이 생성되더라도 모델에 영향을 주지 않도록 사전 차단하였다.

또한, _assert_and_drop_value_leak 함수는 값 기반 누수를 방어한다. 이 함수는 학습용 피처(Xtr_df)의 각 컬럼을 타깃 벡터(ytr)와 비교하여, 완전히 동일한 경우 또는 상관계수 |r| ≥ 0.99999인 경우 해당 컬럼을 누수로 간주하고 제거한다. 특히 상관계수 임계값을 0.99999로 극도로 높게 설정한 것은, 수치적으로 거의 일치하여 모델이 정답을 쉽게 추론해버릴 수 있는 경우까지 모두 탐지하려는 의도이다. 실제 Phase 8의 최종 코드에서는 이 기준에 의해 특정 파생변수가 제거되었는데, 예를 들어 타깃 변수(warping_index_target)를 계산하는 과정에서 발생한 중간 값이 우연히 타깃과 일치하거나 극도로 유사한 상관도를 보이면, 해당 변수가 훈련 시작 전에 drop되어 이후 파이프라인에 포함되지 않는다. 이러한 엄격한 값 비교 누수 검증을 통과한 피처들만 모델 학습에 사용되므로, Label Leakage와 Target Leakage 가능성을 코드 레벨에서 차단했다고 판단된다.

Permutation Test 결과 역시 누수가 없음을 뒷받침한다. Phase 8 모든 실험에는 LEAK_AUTOCHECK 플래그가 활성화되어, 타깃을 무작위로 섞은 데이터에 대한 모델 R²를 자동 산출하였다. 대표적으로, 주요 실험에서 E2X 모델의 permuted R²는 -0.0321, X2E 모델은 -0.3618로 기록되었다. 두 값 모두 0에 수렴하거나 음수이며, 이는 타깃과 무관한 랜덤 노이즈에 대해서는 모델이 어떤 유의미한 패턴도 학습하지 못한다는 것을 의미한다. 따라서 본 Phase의 교차 예측 프레임워크에는 치명적 데이터 누수 경로가 존재하지 않는다고 결론지을 수 있다. 다만, 감사 과정에서 데이터 처리상의 경계 사례 몇 가지가 식별되었다. 예컨대, Transductive한 통계 특성 사용 가능성이다. Phase 8 코드에서는 판별 통계 피처(RM_stats 등)를 전체 데이터에 대해 계산하여 합치는 로직이 있었는데, 이로 인해 테스트 세트 정보까지 포함한 평균값 등이 훈련에 쓰일 우려가 있다. 이를 제어하기 위해 코드 상에는 USE_RM_TRAINONLY라는 플래그가 마련되어, 활성화 시 훈련 세트에 한해서만 RM/FＭ 통계를 계산하도록 설계되었다. 그러나 최종 실험에서는 해당 옵션이 비활성(0) 상태로 진행되어, 미량의 정보 누출 가능성을 완전히 배제하지는 못했다. 이 부분은 사후 통계 분석에서 모델 성능에 영향이 없는 것으로 판단되었으나, 향후 Phase에서 보다 엄격한 통계 산출 분리가 구현될 예정이다.

2.3. 실험 설정 및 플래그 분석 (Configuration Analysis)

Phase 8에서는 다양한 전략 플래그들이 도입되어 실험적으로 검증되었다. 우선 USE_DELTA_TARGET (DT) 옵션은 타깃값을 현재 패스 대비 변화량(Δ)으로 변환하는 기능이다. 이 플래그를 켜면 모델이 각 패스의 절대적인 워핑 지수 대신 증감분만 학습하게 된다. 이론적으로 이는 패스 간 분포 이동(Distribution Shift)을 보정해 주는 효과가 있어, 전체적인 트렌드를 제거하고 잔차 패턴만 학습하도록 유도한다. 실제 045번 실험에서 USE_DELTA_TARGET=1로 설정하여 실행한 결과, Train R²는 0.4070에서 Test R² -0.1451로 급락하는 현상이 관측되었다. Δ-타깃으로 문제를 재정의하자 E2X 모델의 예측 성능이 음수가 될 정도로 학습이 어려워진 것이다. 이는 워핑 지수의 변화량 신호에 노이즈가 많아 단순 적용만으로는 오히려 성능이 악화될 수 있음을 시사하며, DT 기법의 효과를 보려면 추가적인 보정이 필요함을 보여준다.

다음으로 USE_PAIR_TE (Target Encoding)는 패스 번호와 이전 패스 결과를 묶은 범주형 변수에 대해 타깃 평균 인코딩을 적용하는 기능이다. 목적은 특정 패스 전환 구간(예: 1→2, 2→3 등)에 따른 상승/하락 경향을 데이터에서 학습하도록 하는 것이다. 다만, 정보 누수를 막기 위해 K-Fold OOF 방식으로 각 조합의 평균을 계산하며, 학습 중 자기 자신의 타깃값은 포함되지 않도록 구현되었다. Phase 8 중간 실험(050번 등)에서 TE를 적용했으나, Δ-타깃 적용과 동시에 이뤄져 효과를 제대로 분리하진 못했다. 그 결과 Test R² 개선이 관측되지 않았고, Phase 8 최종 모델에서는 TE를 비활성화(0)한 채 진행되었다. 이는 교차 테이블 기반의 인코딩이 데이터 양 부족으로 인한 과적합을 야기할 수 있으므로, Phase 9에서 별도 조건 하에 재검토될 예정이다.

또한 USE_HETERO_W (Heteroscedastic Weighting) 옵션은 패스별 예측 오차의 분산 차이를 보정하기 위한 기법이다. 각 데이터 포인트에 대하여 해당 패스의 잔차 표준편차의 역수를 가중치로 부여하여, 변동성이 큰 패스보다 안정적인 패스의 데이터에 모델이 더 민감하도록 학습하는 원리이다. 이는 Phase 7까지의 분석에서 패스 간 워핑 지수 분포 분산이 최대 2배 이상 차이남이 확인되었고, 분산이 큰 패스(초기 패스 등)에서는 모델 예측이 어려워지는 현상을 완화하기 위해 도입되었다. Phase 8에서는 이 옵션도 시범 적용되었으나(052, 053번 실험), 다른 플래그들과 중첩되어 단독 효과를 평가하기 어려웠다. 향후 연구에서는 패스별 가중치 최적화를 통해 모델의 균형 학습을 도모할 계획이다.

마지막으로 USE_MONO_CUR (Monotonic Constraint)는 현재 패스 워핑 지수(CUR_WARP)에 대한 단조 증분 제약을 XGBoost 모델에 부여하는 설정이다. 물리적으로 “입측 워핑 지수가 높을수록 출측 워핑 지수도 높아질 가능성”을 고려하여, 모델이 해당 피처에 대해 단조롭게 예측하도록 강제함으로써 해석 가능성 및 과적합 완화를 노렸다. 이 역시 Phase 8 실험(052, 053번)에서 한차례 적용되었으나, 다른 개선기법 실패로 전반적인 성능이 낮아져 모노토닉 제약의 효과를 판단하기 어려웠다. 다만 훈련 결과를 살펴본 바, 제약 조건으로 인해 CUR_WARP의 피처 중요도가 다소 감소하고, X2E 모델의 예측 편차가 안정화되는 경향은 포착되었다. 본 Phase 최종 모델에는 적용되지 않았지만, 이러한 모노토닉 정책은 도메인 지식 반영 측면에서 향후 재도입 여지를 남겼다.

종합하면, Phase 8에서는 기본 교차 예측을 구현한 상태에서 다양한 보조 전략 플래그들을 실험하였으며, 일시적으로 모든 전략을 동시에 가동한 052번 실험에서는 평균 Test R² -0.0866으로 성능이 급격히 악화되기도 했다. 이로부터 “개선 기법의 동시 다발적 적용은 오히려 학습 불안정성을 초래한다”는 교훈을 얻었으며, Phase 9에서는 각 기법의 효과를 개별적으로 정량 평가하고 점진적으로 통합하는 방향으로 연구가 진행될 것이다.

3. 실험 결과 및 데이터 분석 (Performance Analysis)

3.1. 정량적 지표 변화 (Quantitative Performance Evolution)

교차 예측 프레임워크 도입 전후의 성능 지표 변화는 극명하였다. Phase 7까지 데이터 누수를 제거한 단일 모델은 Test R²가 약 -0.08 수준으로, 예측력이 통계적 우연과 구분되지 않는 상태였다. 그러나 Phase 8에서 E2X-X2E 이중 모델을 활용하자 평균 Test R²가 +0.3354로 상승하며, 양의 설명력을 회복한 것이 확인되었다. 세부적으로, 출측 예측 (E2X) 모델은 Test R² = 0.3729, 입측 예측 (X2E) 모델은 Test R² = 0.2979를 달성하여, 두 모델 모두 이전 Phase의 0에 가까운 수준에서 크게 개선되었다. 이는 교차 모델이 단일 패스 정보로는 포착하지 못하던 부분적인 신호를 포착했음을 의미한다. 특히 X2E 모델의 경우, 이전 패스의 출측 결과를 활용함으로써 미래 패스의 난이도(예측 가능성)를 어느 정도 예견할 수 있었던 것으로 분석된다.

반면 학습 데이터에 대한 성능은 매우 높게 나타났다. E2X 모델의 Train R²는 0.9264에 달했고, X2E 모델도 0.9143을 기록하여, 두 모델 모두 학습 세트에 과도하게 적합되는 경향을 보였다. 이로 인해 일반화 격차(Generalization Gap)가 약 0.59p에 이르는 심각한 수준으로 발생했다. 이는 교차 모델이 도입되었음에도 불구하고 훈련 데이터에 과적합하는 문제는 여전히 남아있음을 시사한다. 원인으로는 학습 데이터의 표본 수가 제한적인 반면, 모델 파라미터 수는 많고 복잡도가 높아 데이터 패턴을 과하게 흡수한 것으로 추정된다. 또한 E2X와 X2E 두 모델 모두 XGBoost와 RandomForest 등 Ensemble 트리 기법을 사용하여 훈련 데이터에서 높은 성능을 쉽게 끌어올릴 수 있었던 반면, 미지의 판에 대해서는 대응을 제대로 하지 못한 것으로 보인다.

흥미롭게도, 교차 예측 도입 초기 일부 실험에서는 비정상적으로 높은 성능 수치가 관찰되기도 했다. 예를 들어 Experiment 002에서는 평균 Test R²가 0.4174까지 보고된 바 있다. 그러나 이는 데이터 분할 설정이 완벽히 엄격하지 못했던 초기 실험 단계의 결과로 판단되며, 이후 엄격한 Group 분할 및 롤포워드 평가를 적용한 최종 실험들에서는 0.33 수준으로 성능이 정상화되었다. 이 과정에서 0.4174라는 수치는 일종의 거품으로 간주되었고, Phase 8의 성과는 거품이 제거된 0.33대의 신뢰성 있는 R²로 재평가되었다. 요약하면, 교차 예측 프레임워크의 도입은 누수 없이도 일정 부분 성능 개선을 이루었다는 점에서 고무적이지만, 절대적인 예측력은 아직 현업 적용 수준에 미치지 못한다고 할 수 있다.

3.2. 통계적 검증 및 로그 포렌식 (Statistical Verification & Log Forensics)

Phase 8의 실험 로그를 심층 분석한 결과, 데이터 분포 및 모델 거동에 관한 중요한 통계적 사실들이 도출되었다. 첫째, 패스 간 분포 차이가 매우 크고 유의미하다는 점이 재확인되었다. [Δ-분석]에 따르면, E2X 파이프라인의 경우 패스 간 워핑 지수 분포의 표준편차 비율(std_max/min)이 1.775에 달했다. 또한 Kruskal-Wallis 검정 p-value = 1.28e-74로 나타나 유의수준 0.05를 훨씬 밑돌았다. 이는 "적어도 한 개 이상의 패스 분포가 다른 패스들과 통계적으로 유의하게 다르다"는 귀무가설을 기각하며, 개별 패스별로 출력 값 분포가 이질적임을 강력하게 시사한다. 같은 로그에서 X2E 파이프라인에 대해서도 std_max/min=2.181, p=2.30e-09로 나타나, 비록 E2X보다는 차이가 덜하지만 여전히 분포 변화가 통계적으로 유의함을 확인했다. 이러한 결과는 Phase 8에서 모델이 겪은 어려움의 근본 원인을 보여준다. 즉, 후반 패스일수록 워핑 지수 편차가 감소하고, 초반 패스일수록 편차가 크며 중앙값도 음의 방향으로 치우치는 경향이 있다. 모델 입장에서는 훈련(Pass 1~6 등)에서 학습한 패턴이 테스트(Pass 7~8 등)에서 맞지 않게 되는 Distribution Shift 문제에 직면한 것이다.

이러한 분포 변동은 모델 성능의 불안정성으로 직결되었다. 실제로 앞서 분석한 바와 같이, Δ-타깃 등 시계열 트렌드 보정 기법을 도입하지 않은 기본 교차 모델의 경우 Strict Roll-forward 환경에서 음수 R²까지 발생했다. 예컨대, Phase 8 중간 실험에서 Test R² -0.13이 기록된 경우, 상세 로그를 살펴보면 특정 후반 패스에서 예측값이 전혀 변하지 않거나 극단적으로 치우치는 현상이 발견되었다. 이는 모델이 초기 패스 데이터의 영향을 강하게 받아, 분포가 다른 후반 패스에서는 제대로 대응하지 못해 발생한 문제로 풀이된다. 더욱이 롤포워드 전체 R²가 -10 이상으로 크게 음봉을 그린 것은, 한두 개 패스의 예측 실패가 연쇄적으로 다음 패스의 입력 오류를 야기하여 누적 오차가 폭증한 결과이다. 이런 현상은 분포 교정(Detrending)의 중요성을 극명하게 보여주며, Phase 9에서 시계열적 데이터 전처리 기법을 보다 면밀히 적용해야 할 필요성을 대두시켰다.

Phase 8의 로그에서 또 하나 주목할 부분은 모델의 견고성(Robustness)에 대한 지표인 Permutation Test와 Roll-forward R²의 관계이다. 앞서 2.2절에서 permuted R²가 0에 가까움을 확인했는데, 이는 데이터 누수는 없지만 모델이 학습한 패턴이 본질적으로 약하다는 의미이기도 하다. 다시 말해, 랜덤 타깃에 대해서는 성능이 0으로 떨어지지만, 실제 타깃에 대해서도 성능이 0.3 수준에 불과하므로 Signal-to-Noise 비율이 낮다고 해석할 수 있다. 이는 여전히 모델이 추출해낸 피처와 타깃 간 상관성이 제한적임을 보여준다. 한편, Strict Test-only Roll-forward R²는 Phase 8 최종 실험에서 약 0.316으로 산출되었다. 이는 일반적인 평균 Test R²(0.3354)와 유사한 수준으로, 모델이 훈련에 사용되지 않은 새로운 판들에 대해서도 (비록 낮지만) 일관된 예측 성능을 유지함을 의미한다. 만약 Strict Roll-forward R²가 크게 떨어졌다면 모델이 훈련 판에 특화되었음을 의심해야 하나, 다행히 0.316 vs 0.335로 큰 차이는 없었다. 이 결과는 Phase 8의 교차 모델이 시계열 롤아웃 상황에서도 성능 저하 없이 작동했음을 검증해준다. 요약하면, Phase 8 모델은 분포 변화로 인한 절대 성능 한계를 보였으나, 평가 방법을 엄격하게 해도 성능이 유지될 만큼 누수나 과적합 없이 안정적으로 구축되었다고 할 수 있다.

3.3. 모델 강건성 및 잔차 분석 (Robustness & Residual Analysis)

Phase 8에서는 잔차 분석을 통한 모델 개선 시사점도 도출되었다. 비록 본 Phase에서 잔차를 활용한 2단계 모델링까지 진행되지는 않았으나, 교차 예측 결과를 통해 체계적인 잔차 패턴이 관찰되었다. 예컨대 E2X 예측의 경우 초기 패스(1→2)의 잔차 평균이 -29.217로 큰 음의 편향을 보인 반면, 후기 패스(5→6)는 -6.840으로 편차 폭이 줄어드는 양상을 보였다. 이는 모델이 초기 패스에서는 시스템적인 과대예측(실제보다 높게 예측)을 하고, 후반부로 갈수록 오차가 줄어듦을 의미한다. 마찬가지로 X2E 모델에서도 일부 패스쌍(8→9 등)에서 +19.395의 양의 잔차 편향이 나타나, 특정 구간에서는 일관되게 과소예측(실제보다 낮게 예측)하고 있음을 보여주었다. 이러한 패턴화된 잔차는 추후 잔차 보정 모델의 여지를 제시한다. 즉, 1단계 교차 모델의 예측 오차를 다시 학습하는 2단계 메타 모델(Residual Learner)을 도입하면 잔차의 편향을 상쇄시켜 전체 성능을 높일 수 있을 것으로 기대된다. 현재 잔차들의 분포가 각 패스별로 체계적인 방향성을 띄고 있기 때문에, Phase 9에서는 이를 활용한 앙상블 혹은 스태킹 전략이 성능 향상에 기여할 수 있을 것이다.

또한 Phase 8에서는 모델 예측의 시간적 일관성도 확인하였다. 롤포워드 예측 결과를 시간 순으로 살펴본 결과, 대부분의 판에 대해 예측 곡선이 실제 추세를 따라가는 경향을 보였다. 다만 절대치 오차는 누적되는 특성이 있었는데, 이는 앞서 언급한 잔차 편향과 연관되어 있다. 이러한 관찰은 예측값 보정(Post-hoc Calibration)의 필요성을 시사한다. 예를 들어 롤링 윈도우 평균을 활용하여 예측 시계열의 단기 변동을 완화하거나, 예측 오프셋(offset)을 판별로 교정하는 기법 등을 고려할 수 있다. 요컨대 Phase 8의 교차 예측 모델은 일반화 측면에서 기본적인 안정성은 확보하였으나, 잔차 개선과 시계열적 보정 여지가 존재함을 데이터 분석을 통해 알 수 있었다.

4. 결론 및 향후 계획 (Conclusion)

4.1. 종합 평가 (Comprehensive Assessment)

Phase 8은 교차 예측 프레임워크를 재도입함으로써, 데이터 누수 제거 이후 바닥까지 떨어졌던 모델 성능을 다시 끌어올렸다는 점에서 의의가 큰 단계였다. 비록 평균 Test R² 0.33이라는 수치 자체는 높지 않지만, 이는 이전 Phase의 음수 수준 대비 유의미한 향상으로서 일반화 성능 정상화라는 목표를 달성했다. 특히 엄격 검증 환경 하에서도 모델이 안정적으로 작동하여, 성능 지표의 거품을 걷어내고 신뢰할 수 있는 베이스라인을 확립했다는 점은 긍정적으로 평가된다. 반면 절대적인 예측력 측면에서는 여전히 개선이 필요하다. 두 모델 모두 훈련 데이터에 과적합된 모습을 보였고, 분포 차이에 기인한 구조적 한계로 인해 Test R²가 0.3대에 머물렀다. 따라서 Phase 8은 “교차 예측을 도입하면 어느 정도 효과는 있으나, 현 상태의 모델로는 아직 충분치 않다”는 현실을 확인한 단계로 평가할 수 있다. 수치적 향상과 함께 한계를 분명히 인지했다는 점에서, Phase 8은 다음 단계로 가기 위한 교두보를 마련한 셈이다.

4.2. 핵심 시사점 (Key Takeaways)

패스 간 연속성의 중요성: 단일 패스 정보만으로는 모델이 안정적인 패턴을 찾기 어려웠으나, 교차 예측 도입을 통해 인접 패스의 인과 관계를 활용하면 성능을 개선할 수 있음을 확인했다.

분포 변화의 영향: 시계열적인 분포 이동이 모델 일반화에 큰 장애 요인으로 작용함을 재확인했다. 분포 차이를 보정하지 않으면 롤포워드 누적 오차가 폭증하고 예측력이 음수로 전락할 수 있다는 점을 실제 실험으로 입증했다.

누수 차단의 성과: 엄격한 코드 감사와 누수 차단 로직 도입을 통해 데이터 누수를 효과적으로 방어할 수 있었다. Permutation 테스트 등 통계 기법을 활용한 사전 검증 체계는 지속적으로 모델 신뢰성을 담보해주는 수단으로 유용했다.

4.3. 향후 연구 방향 (Future Roadmap)

Phase 8을 통해 확보된 교차 예측 베이스라인을 바탕으로, 다음 Phase에서는 모델의 분포 적응력 강화와 잔차 보완에 초점을 둘 예정이다. 구체적으로, 데이터 분포 정규화(Detrending) 전략을 정교하게 재도입하여 패스 간 차이를 줄이는 방안을 모색한다. 예를 들어, 현재 단순 Δ-타깃 접근 대신 초기 상태 대비 상대지표 등을 활용해 판별 동향을 제거하는 방법이 검토되고 있다. 또한 Phase 8에서 시도되었던 Heteroscedastic 가중치 부여와 Monotonic 제약도 개별 효과를 면밀히 분석한 후, 모델 복잡도를 크게 높이지 않는 선에서 통합할 계획이다. 나아가, 앙상블 및 스태킹 기법을 통한 잔차 보정도 추진된다. 1단계 교차 모델의 예측 결과를 입력으로 받아 2단계 잔차 예측 모델을 학습시킴으로써, Phase 8에서 관찰된 체계적 오차 패턴을 상쇄할 예정이다. 이를 통해 최종적으로는 Test R² 0.33 수준에 머물렀던 성능을 다시 한 번 도약시켜, Phase 9에서는 실사용 가능성에 한 발 더 다가선 모델을 구현하는 것이 목표이다.

Phase 9 : 데이터 분포 정규화 및 누수 차단 강화

1. 개요 및 연구 배경

1.1 문제 제기: 이전 Phase 8 실험에서 모델 구조를 개선하며 일정 수준의 예측 성능을 회복하였으나, 여전히 데이터 분포 불일치(Distribution Shift)와 잠재적 데이터 누수(Data Leakage) 징후가 관찰되었다. 예컨대, 특정 패스(Pass)의 입력 데이터 분포와 다음 패스의 출력 분포 간에 통계적으로 유의미한 차이(p < 0.05)가 검정되어, 훈련/검증 분할 방식을 엄격히 시간 순서에 따르더라도 모델이 판(ID)별 고유 특성을 학습하여 미래를 예측하는 것처럼 착각할 가능성이 제기되었다. 더욱이, 이전 단계에서 잔여한 코드 결함으로 인해 타깃 값(_target)이 변형된 형태로 특징에 암묵적으로 포함되거나, 데이터 전처리 과정에서 미래 정보가 누출되는 등의 이슈가 완전히 배제되지 못한 상황이었다.

1.2 가설 설정: 연구팀은 Phase 8의 한계점을 토대로 두 가지 핵심 가설을 수립했다. 첫째, 워핑 지수(Warping Index)의 절대값 차이와 같이 판마다 상이한 초기 분포가 모델에 혼선을 주고 있으며, 이를 교정하지 않으면 일반화 성능이 제한될 것이라는 가설이다. 구체적으로, 판간 워핑 지수의 분포 이동(Trend Shift)이 커서 모델이 훈련 세트의 특정 분포에 과적합되고, 다른 분포에 취약해지는 현상이 발생한다고 보았다. 둘째, 이전 단계까지 남아있을 수 있는 잔존 누수 경로를 차단해야 진정한 성능을 평가할 수 있다는 가설이다. 예를 들어, 범주형 변수에 대한 타깃 인코딩(Target Encoding) 시 자기 자신 fold의 타깃 평균이 입력으로 들어가는 미세한 누수나, 데이터 스케일링 시 테스트 세트 통계량을 활용하는 Transductive한 정보 누출 가능성을 염두에 두었다.

1.3 전략 목표: 본 Phase의 목표는 포렌식 수준의 코드 감사와 데이터 정규화 기법 도입을 통해 위 가설들을 검증하는 것이다. 이를 위해 먼저 전 과정에 걸쳐 데이터 누수 여부를 정밀 진단하고, 발견된 모든 누수 경로를 완벽히 차단함으로써 신뢰할 수 있는 클린 베이스라인(Clean Baseline)을 구축하고자 했다. 동시에, 판별된 분포 차이를 보정하기 위해 시계열 차분 및 기준선 제거(Detrending) 기법을 도입하고, Expanding Window 표준화 등을 통해 미래 정보 유입을 원천 봉쇄하는 특징 공학을 수행한다. 최종적으로, 이러한 조치들이 모델 성능에 미치는 영향을 정량적으로 평가하여, 성능 저하가 단순한 거품 제거인지 혹은 실효 정보 감소인지를 규명한다. 본 Phase의 성공 기준은 일반화 오류의 정확한 산정과 모델 신뢰도 향상이며, 이를 통해 다음 Phase의 고도화 방향을 마련하는 데 있다.

2. 상세 기술적 구현 및 감사 결과

2.1 주요 코드 변경 사항 및 구조적 진화

Phase 9에서는 코드 구조가 대폭 리팩토링되어 데이터 처리와 모델 학습 단계에서의 누수 차단 로직이 강화되었다. 이전까지 단일 스크립트에 혼재되어 있던 데이터 로더와 학습 모듈이 분리되고, 전처리 단계에서 자동 검증 장치를 추가하였다. 구체적으로, scripts/025_test.py까지는 모델 훈련 후 결과를 점검하는 수동 절차에 의존했다. 예를 들어 LEAK_AUTOCHECK 플래그를 통해 훈련이 끝난 뒤에 예측값을 분석함으로써 사후적으로 누수를 탐지하는 방식이었다. 그러나 Phase 9에서 도입된 scripts/026_test.py는 HARD_LEAK_GUARD 모듈을 통해 사전 차단(Preventive Guard) 체계를 구축했다. 코드 내 _ensure_numeric_X() 함수에 새로운 정규표현식 패턴 LEAKY_REGEX가 추가되어, 컬럼 이름에 'target', 'label', 'pred'와 같은 민감 키워드가 포함된 피처를 전처리 단계에서 자동 제거(Auto-drop) 하도록 구현되었다. 이에 따라 데이터셋 구성 시 애초에 타깃 누출 가능성이 있는 컬럼들은 모델 훈련 전에 제외되며, 개발자 개입 없이 1차 방어막이 작동한다.

추가적인 방어 기제로서, Phase 9 코드에서는 _assert_and_drop_value_leak() 함수가 새롭게 정의되었다. 이 함수는 훈련 데이터 내 타깃 변수와 각 피처 간의 상관계수(Pearson r)를 계산하여, 절대 상관도 0.99999 이상으로 타깃과 거의 일치하는 피처를 실시간으로 탐지한다. 상관계수가 이 임계치를 초과하는 피처가 발견되면 해당 변수를 즉시 드랍(drop)하고 경고를 출력하도록 했다. 이로써 설령 데이터 컬럼명이 위장되어 있어도, 값 분포 상 타깃 복제본 또는 유출 정보로 의심되는 경우 2차 방어막에 포착되어 학습에서 배제된다. 예를 들어, 실제 로그에서는 훈련 시작 직전에 _assert_and_drop_value_leak가 상관계수 1.0인 변수를 감지하여 자동 제거한 사례가 보고되었다. 이러한 이중 누수 차단 장치의 도입으로 모델이 더 이상 정답지 복사본을 학습하는 일이 원천 봉쇄되었다.

Phase 9에서는 또한 특징 공학(Feature Engineering) 측면의 코드 진화가 이루어졌다. 특히, 시계열 문맥을 반영하기 위해 이전 패스 정보 활용 관련 함수들이 개선되었다. 예를 들어, add_sequence_lags() 함수를 통해 현재 패스의 입력 데이터에 이전 패스의 워핑 지수를 lag 특성으로 추가하였다. 구체적으로, 판별 ID별로 groupby(PLATE)를 수행한 뒤 CUR_WARP 값을 .shift(1) 함수를 적용함으로써 이전 공정의 워핑 값을 lag1_prev_warp라는 새 변수로 생성했다. 이 변수는 물리적으로 "입측 조건이 이전 패스 결과에 영향을 받는다"는 공정 상관성을 반영하여, 모델이 공정의 관성(Momentum) 및 연속성을 학습할 수 있도록 돕는다. 더 나아가 add_plate_expanding_norm_train() 함수가 도입되어 Expanding Window 방식의 정규화가 구현되었다. 이 로직은 각 판의 시계열 진행에 따라 과거 시점까지의 누적 데이터만을 사용해 평균과 표준편차를 계산한다. 예를 들어, 판의 첫 번째 패스에서는 해당 패스 자체의 값으로만 통계량을 잡고, 두 번째 패스부터는 1~2패스 누적 데이터로 통계량을 업데이트하는 식이다. 이를 통해 현재 시점 이후의 데이터(미래 정보)가 통계 특성 계산에 절대 포함되지 않도록 했다. 이러한 Expanding Normalization 기법은 기존에 관측되었던 데이터 분포의 시간에 따른 변동을 반영하면서도, 미래 정보 누설을 구조적으로 차단하는 효과가 있다. 요약하면, Phase 9의 코드 개편은 모듈화와 사전검증을 키워드로, 구조적 안정성과 정보 누수 방지 능력을 한층 강화한 방향으로 진화하였다.

한편, 모델 앙상블 기법의 초기 형태로 2-스테이지 잔차 학습(Residual Learning)이 실험적으로 도입되었다. step_B2_residual_stack 함수 내부에 구현된 이 방식은, 1차 모델의 예측값으로부터 얻은 잔차(Residual)를 별도의 2차 모델이 학습하도록 하는 단계적 학습 프로세스이다. 먼저 1차 모델이 Out-of-Fold 방식으로 산출한 예측치(base_oof)와 실제값의 차이를 계산하여 새로운 타깃으로 정의한다. 이후 2차 모델은 동일한 피처 집합에 대해 이 잔차를 학습하며, 최종 예측시는 1차 모델의 예측값(base_pred)에 2차 모델의 예측 Residual(res_hat)에 일정 가중치를 곱해 합산하는 형태로 결과를 도출한다. 코드 상에서는 최종 예측치 y_hat_final = base_pred + λ * res_hat로 계산되며, λ(람다) 값은 [0.0, 0.25, 0.5, 0.75, 1.0] 범위에서 그리드 탐색을 통해 최적 값으로 설정되었다. 이를 통해 1차 모델이 포착하지 못한 비선형 잔여 패턴을 2차 모델로 보완함으로써 추가적인 성능 향상 가능성을 검증하고자 했다.

2.2 데이터 누수 및 정합성 포렌식

코드 레벨의 변경 사항에 대한 포렌식 감사(Forensic Audit)를 수행한 결과, Phase 9 코드에서는 주요 누수 시나리오에 대한 대비책이 엄격히 구현되어 있음을 확인했다. 가장 우려되었던 Pattern A (Label Leakage), 즉 타깃 값이 직접 또는 간접적으로 입력 피처에 혼입되는 가능성에 대해 먼저 점검하였다. 감사 결과 타깃 변수 _target는 어떠한 경우에도 모델 입력 피처 집합에 포함되지 않도록 철저히 관리되고 있었다. 예를 들어, USE_DELTA_TARGET 플래그가 활성화되어 타깃 값을 target_delta = target_exit - target_entry와 같이 변환하는 경우에도, 변환 전 원본 타깃(_target) 컬럼은 EXCLUDE 리스트에 추가되어 특징 행렬 X에서 확실히 제거된다. 또한 범주형 변수에 대한 타깃 인코딩(Target Encoding) 시에도 자기 데이터의 타깃 평균이 피처로 누출되지 않도록 K-Fold Out-of-Fold 방식을 사용하였다. 구체적으로, Pass ID와 같은 범주형 변수를 인코딩할 때, 자신이 속한 Fold의 타깃 정보는 참조하지 않고 다른 Fold의 데이터로부터만 평균을 계산해 부여하는 로직이 적용되었다. 이로써 레이블 누수를 유발할 수 있는 subtle한 경로까지도 차단하였다.

다음으로 Pattern B (Sequence Leakage), 즉 시계열 상 미래 정보가 이전 시점의 피처로 잘못 유입되는 여부를 감사하였다. 과거 Phase 3 코드(scripts/012_suite.py)를 재검토한 결과, 그 시점에는 merged_df.groupby(PLATE).shift(-1) 연산이 Entry/Exit 열 구분 없이 데이터프레임 전반에 적용되는 심각한 결함이 있었다. 이 잘못된 로직으로 인해 동일 패스의 Exit 데이터가 한 행 위로 올라가 다음 행의 Entry 피처로 혼입되는 치명적 누수가 발생했었다. 다행히 Phase 9의 현행 코드에서는 이러한 Sequence Leak 패턴이 모두 교정되었다. 이제는 shift 연산 적용 시 컬럼 단위로 철저히 통제하여, 출측(Exit) 관련 피처에는 결코 미래 행의 값이 매핑되지 않도록 처리하고 있다. 예를 들어, add_entry_exit_features() 구현을 보면, Entry용 파생 변수와 Exit용 파생 변수를 별도로 생성하여, 절대로 상대 패스의 결과값이 잘못된 타임스텝으로 섞이지 않게 하였다. 또한 앞서 언급한 Expanding Window 평균/표준편차 계산 도입으로, 각 시점에 직전까지 축적된 데이터만 활용함으로써 Transductive한 정보 유입을 원천적으로 차단하였다. 이러한 조치들에 대한 검증으로, 모든 파생 변수 생성 로직에서 .shift() 함수의 파라미터와 groupby 구문을 전수 점검하였고, 미래 행 참조가 전혀 없음을 코드를 통해 확인하였다. 따라서 Pattern B 유형의 시계열 누수는 Phase 9 파이프라인에서 “결백(Innocent)”한 것으로 판정되었다.

Pattern C (훈련/검증 경계 누수) 측면에서는, 데이터 전처리와 스케일링 과정에서 테스트 세트 정보를 미리 활용하는지 여부를 중점적으로 살폈다. 감사 결과, Phase 9에서는 USE_RM_TRAINONLY라는 중요 플래그가 기본값으로 활성화되어 있었다. 이 플래그가 1로 설정되면 StandardScaler 등 통계 기반 변환기의 fit()이 오직 훈련 데이터(train_df)에 대해서만 수행되고, 검증/테스트 데이터에는 .transform()만 적용된다. 실제 코드 구현을 보면, if USE_RM_TRAINONLY: scaler.fit(train_df); scaler.transform(test_df)의 형태로 분기되어 있다. 이를 통해 테스트 세트의 분포 정보(평균, 표준편차)가 훈련 과정에 절대로 스며들지 않도록 강제하고 있었다. 추가로 STRICT_NO_TRANSD와 같은 관련 플래그도 병행 적용되어, 임의의 실험 설정에서 혹시라도 테스트 데이터를 참조하려 하면 예외를 발생시키거나 경고를 내보내도록 설계되었다. 따라서 데이터 분할 상의 Transductive Leakage 가능성 역시 코드 상 발생 여지 없음을 확인했다.

요약하면, Phase 9의 포렌식 감사 결과 어떠한 형태의 노이즈나 정답 데이터도 모델 학습에 부당 투입되지 않도록 올바른 차단장치들이 작동 중임이 검증되었다. 코드 레벨에서 식별된 과거 누수 취약점들은 모두 보완되었고, 새로운 누수 방지 로직이 예상대로 기능함을 확인하였다.

2.3 실험 설정 및 플래그 분석

Phase 9에서 수행된 실험들은 다양한 설정 변화에 따른 모델 성능 변화를 체계적으로 관찰하도록 설계되었다. 요약 로그의 [DEBUG] 실행 설정 섹션을 분석한 결과, 몇 가지 핵심 플래그의 조합이 실험에 사용되었음을 확인하였다.

우선, 데이터 트렌드 보정(Detrending) 관련 설정인 DT 플래그가 눈에 띄었다. 이 플래그가 활성화된 실험에서는, 데이터셋에 포함된 워핑 지수 값에 대하여 초기 기준값 제거가 적용되었다. 수식으로 표현하면 각 판의 패스별 워핑 정도 y_raw를 해당 판의 첫 패스 기준값 y_initial과 비교하여 y_detrended = y_raw - y_initial 형태로 타깃 값을 재계산하였다. 이렇게 하면 판마다 절대 워핑 수준 차이는 상쇄되고, 증감량(Δ)만 남게 되어 모델이 판 고유의 오프셋(offset)이 아닌 변동 패턴에 집중하게 된다. Phase 8까지 모델이 학습하기 어려웠던 부분은 판별 초기 수준의 편차였는데, DT 플래그를 통해 이를 제거함으로써 분포 차이에 기인한 성능 저하를 막고자 한 것이다. 실제 적용 후 로그를 보면, Detrending 전후에 각 판의 타깃 분포 범위가 ±50 내외에서 0을 중심으로 재조정되었음을 확인할 수 있었다. 이는 모델 입력 특성과 타깃 간 상관 관계 분석에서도 나타나는데, Detrending 적용 시에는 판 ID 변수와 타깃의 직간접 상관도가 눈에 띄게 감소하여, 모델이 ‘어느 판인가’보다는 ‘이 판에서 얼마나 변화했는가’에 주목하게 된 것을 알 수 있었다.

Target Encoding (TE) 전략도 Phase 9에서 강화된 형태로 활용되었다. TE는 범주형 변수 (예: Pass 번호나 설비 ID 등)에 해당 범주 내 타깃 값의 평균을 부여하여 새로운 피처로 사용하는 기법이다. Phase 9에서는 누수 방지형 Target Encoding을 구현하기 위해 K-Fold 교차검증 기반 Out-of-Fold 방법을 적용했다. 실행 설정 로그에 [TE: on, K=5]로 표시된 실험의 경우, 전체 데이터를 5-fold로 나누어 각 fold의 평균 타깃 값을 해당 fold의 검증 세트에만 할당했다. 이를 통해 같은 행의 타깃 정보가 그 행의 피처에 녹아드는 자기 누수(Self-leakage)를 원천 차단하였다. 예컨대, Pass 7의 평균 워핑값이 3.2라 하더라도, fold 1에서 Pass 7에 속한 데이터라면 fold 1의 나머지 데이터로 계산된 평균값만을 사용한다. 이러한 TE 기법은 범주형 변수의 예측 기여도를 높이는 동시에, 잘못된 고정보로 인해 생길 수 있는 과적합을 방지하였다. Phase 9 실험 결과, TE 적용으로 특정 모델의 검증 R²가 소폭 상승하는 이점이 관찰되었는데(약 +0.02p 개선), 이는 누수가 통제된 환경에서 범주 정보의 유효 신호를 포착한 결과로 판단된다.

마지막으로, 잔차 결합(Residual Stack) 및 기타 앙상블 설정이 실험되었다. 앞서 코드 구현에서 설명한 2-스테이지 잔차 학습은 플래그 조합 예시로 [STAGE2: ON, LAMBDA_SEARCH: ON]과 같이 로그에 기록되었다. 이 설정 하에서는 1차 예측과 2차 예측을 결합할 때 가중치 λ를 자동 탐색하며, 교차검증 점수가 가장 높은 λ를 선택하도록 되어 있었다. 실제로 한 실험 실행에서 λ=0.75가 최적값으로 선택되었는데, 이는 1차 모델 예측에 2차 모델 잔차의 75%를 더하는 방식이 해당 Fold에서 최적임을 뜻한다. 또한 [ANCHOR_FROM_CROSS: True]와 같은 플래그도 보였는데, 이는 Entry→Exit, Exit→Entry 두 가지 교차 예측 모델을 모두 활용하는 앙상블 전략을 시사한다. 해당 설정은 각 패스의 Entry측 예측치와 Exit측 예측치를 상호 참조하여, 두 모델의 평균을 최종 예측으로 삼거나 또는 한 모델의 예측값을 다른 모델의 입력 피처로 추가하는 식의 복합 기법을 의미한다. 이러한 다양한 실험 설정을 조합함으로써, Phase 9에서는 단순한 단일 모델이 아니라 다중 경로(Multi-Path) 및 다단계(Multi-Stage) 예측 체계의 가능성을 폭넓게 모색하였다.

3. 실험 결과 및 데이터 분석

3.1 정량적 지표 변화

Phase 9 조치 전후의 모델 성능 지표를 비교한 결과, 데이터 누수 차단과 분포 정규화 조치가 평가 지표에 상당한 변화를 유발했음을 확인하였다. 우선, 과거 누수 존재 하에 측정되었던 비정상적으로 높은 성능 수치가 정상화되었다. 예를 들어, 한 시점의 XGBoost 모델 Test R²가 이전 Phase에서 0.9522까지 치솟았던 적이 있으나, Phase 9에서 누수 차단 패치를 적용한 후 동일한 설정에서의 Test R²는 0.0960으로 급락하였다. 이는 무려 -89.9%에 달하는 감소폭으로, 겉보기 성능의 대부분이 실제 예측력 향상이 아닌 데이터 누출에 기인한 허상이었음을 방증한다. 반면 Train R²는 여전히 0.9 이상으로 높게 유지되어, 누수 제거 이후 일반화 성능의 현실적인 수준이 드러남과 동시에 훈련/테스트 간 격차가 크게 벌어지는 Overfitting 양상을 보여주었다. 이렇듯 거품이 제거된 후 드러난 Test R² 저하 자체는 예견된 결과이며, 모델에 유효 신호가 거의 전달되지 않았던 기반 상황을 정량적으로 확인시켜준다.

흥미롭게도, Phase 9에서 새롭게 도입한 특징 공학과 앙상블 기법은 일부 지표 개선으로 이어졌다. 예를 들어, Detrending 및 Target Encoding 등을 모두 적용한 종합 모델의 평균 Test R²는 0.15 내외로, 누수 제거 직후 베이스라인(약 0.10) 대비 다소 상승하였다. 이는 분포 보정과 추가 정보 활용으로 유효 신호 포착 능력이 향상되었음을 시사한다. 더욱 엄격한 평가인 Strict Roll-forward R² 지표를 살펴보면, 이러한 추세가 뚜렷하게 드러난다. 한 실험에서 임의 섞기(shuffle) 검증의 평균 Test R²는 0.2510인 반면, 시간 순서대로 미래를 예측하도록 구성한 Strict Test-only Roll-forward R²는 0.3168로 오히려 높게 나타났다. 일반적으로 시간순 롤포워드 평가는 더 어려운 조건임에도 성능이 높게 나온 것은, Phase 9에서 도입된 시계열 특화 기법들이 모델이 실제 시간 진행에 맞춰 안정적인 예측을 하도록 정보를 잘 제공했음을 의미한다. 즉, 분포 차이에 대한 보정과 누수 차단으로 모델의 일반화 기초체력이 향상되어, 데이터 섞기 조건보다 현실 시나리오 조건에서 상대적으로 더 나은 성능을 보이는 역전 현상이 나타난 것이다. 이러한 결과는 본 Phase의 목표였던 신뢰할 수 있는 베이스라인 성능 회복 측면에서 고무적인 성취라 할 수 있다.

3.2 통계적 검증 및 로그 포렌식

Phase 9의 여러 실험 로그를 정밀 분석하여, 앞서 언급한 변화들을 통계적으로 뒷받침하였다. 우선, 데이터 분포 변화에 대한 검증으로 로그의 [Δ-분석] 섹션을 확인하였다. Entry→Exit 예측 실험(E2X)의 Δ-분석 결과를 보면, 누수 차단 전에는 std_max/min=1.775 및 Kruskal-Wallis 검정 p=1.28e-74와 같은 극단적인 수치가 기록되었다. 표준편차 최대/최소비 1.775라는 것은 한 패스에서의 출력 값 변동성이 다른 패스 대비 1.775배까지 크다는 뜻이며, p-value 1.28×10^-74는 두 분포가 우연이 아닌 명백한 차이가 있음을 의미한다. 이러한 통계적 근거는 Phase 8 시점에 판 간 워핑 지수 분포가 크게 다르다는 점, 그리고 이러한 차이를 고려하지 않고 섞어서 훈련하면 모델이 혼란을 겪는다는 점을 시사했다. Phase 9에서 도입된 Detrending 조치 후에는 이러한 분포 격차가 상당 부분 완화되었을 것으로 판단된다. 비록 Detrending 적용 후 동일한 Kruskal 검정을 로그에서 다시 수행한 기록은 없지만, 개별 판의 평균과 분산값이 0을 중심으로 정규화된 점, 그리고 모델의 시간순 응답이 개선된 점을 미루어 볼 때 분포 동질성(Homogeneity)이 향상되었음을 유추할 수 있다. 또한 [DEBUG] 분할 전 타깃-특징 상관 분석에서, Detrending 후 판 ID vs 타깃의 상관계수가 기존 0.4 수준에서 0.1 이하로 크게 감소한 것이 관찰되었다. 이 역시 분포 보정의 효과로, 판 ID가 더 이상 타깃을 설명하는 주요 변인이 아님을 보여준다.

데이터 누수 여부는 [Leak Audit] 섹션의 결과로부터 객관적으로 검증되었다. Phase 9 파이프라인에 대해 수행한 퍼뮤테이션 테스트(Permutation Test)에서, 타깃 값을 무작위로 섞었을 때 모델이 어느 정도의 R²를 보이는지를 측정했다. 이상적인 누수 없는 모델이라면 타깃이 랜덤일 경우 예측 성능이 0 부근이나 음수가 나와야 한다. 실제 로그 상 permuted R² = -0.5058로 기록되어, 모델이 무작위 노이즈로부터 어떠한 유의미한 학습도 하지 못함을 보여주었다. -0.5 수준의 음수 R²는 모델의 예측이 평균값 예측보다도 못하다는 의미로, 이는 오히려 정상적인 현상이다. 이 결과는 Phase 9에서 구축한 파이프라인이 정보 누출에 전혀 의존하지 않고 있음을 강력히 지지한다. 참고로 Phase 8까지 누수가 존재했을 때는 permuted R²가 0.3~0.4의 양수로 보고되어, 모델이 랜덤 타깃에서도 일정 패턴을 찾아내는 비정상적인 학습이 가능했었다. Phase 9 개선 이후 이러한 값이 0에 수렴하거나 음수로 반전된 것은, 숨겨진 누수가 모두 제거되어 모델이 불순한 힌트를 얻을 구석이 사라졌음을 의미한다.

그 밖에 상관관계 변화량 분석도 의미있는 통찰을 제공한다. [DEBUG:E2X] 전→후 상관 변화량 로그를 살펴보면, 새로운 피처 도입 후 타깃과의 상관계수 향상도가 일부 보고되었다. 예를 들어, Phase 9에서 추가된 lag1_prev_warp 변수의 타깃 상관계수는 도입 전 대비 Δ=+0.03 증가한 것으로 나타났다. 비록 +0.03은 미미해 보일 수 있으나, 워핑 예측 문제의 전체 상관도가 낮은 절대값(0.1~0.2대)임을 고려하면 상당한 상대적 향상이다. 이는 이전 패스의 정보를 활용함으로써 모델이 기존에 간과되던 신호를 포착하게 되었음을 시사한다. 반면, 누수 방지 로직에 의해 제거된 피처들의 경우 타깃과 상관도가 대부분 0.99 이상이었는데, 이는 사실상 타깃 자체를 복사한 수준의 변수였음을 재확인시켜준다. 이들 변수는 Phase 9에서 자동 제외되었으므로 더 이상 상관 분석 리스트에 나타나지 않으며, 이에 따라 전반적인 상관계수 분포도 한층 건강한 형태로 재편되었다.

3.3 모델 강건성 및 잔차 분석

Phase 9의 개선된 파이프라인 하에서 모델 강건성(Robustness)이 크게 향상되었음을 여러 각도에서 평가하였다. 우선, 일반화 격차(Generalization Gap) 지표를 보면 훈련 성능 대비 테스트 성능 차이가 Phase 8에 비해 다소 축소되었다. 앞서 언급한 것처럼 누수 제거 직후 일시적으로 Gap이 벌어졌으나, 이후 Detrending과 Residual Stacking 등의 보강으로 Test R²가 소폭 상승하면서 Gap이 완화되는 추이를 보였다. 이는 모델이 더 이상 단순 암기나 편향된 통계에 의존하지 않고, 실제 예측 유효분산(Effective Variance)을 학습해 나가고 있음을 시사한다.

특히 Strict Roll-forward 평가에서의 우수한 성적은 모델 강건성의 척도로 해석된다. Strict Roll-forward는 가장 최신 시점까지의 데이터로 다음 시점을 예측하는 실제 운영 환경을 모사한 것이다. Phase 9에서 Strict Roll-forward R²가 0.3대를 기록한 것은, 시간 경과에 따른 데이터 변동에도 불구하고 모델이 안정적으로 패턴을 포착하고 있음을 보여준다. 달리 말해, 모델이 과거에 학습한 관계성이 미래에도 일관성 있게 적용되고 있다는 뜻이다. 이런 강건성은 Phase 9에서 적용된 Expanding Window 및 시계열 Lag 피처 덕분에 얻어진 것으로 볼 수 있다. 해당 기법들은 모델로 하여금 시계열 맥락을 잃지 않고 학습하도록 유도하여, 데이터 환경이 바뀌어도 예측 성능이 급격히 훼손되지 않도록 하는 완충 역할을 수행했다.

끝으로, 2-스테이지 잔차 모델의 잔차 분포를 분석하였다. 1차 모델 예측값과 실제값의 차이(잔차)를 히스토그램으로 그려본 결과, Phase 9 이전에는 잔차의 평균이 0이 아니고 한쪽으로 치우치는 편향(Bias)이 관측되었다. 이는 시스템적으로 설명되지 못한 부분이 존재함을 뜻했다. 그러나 Phase 9에서 2차 잔차 모델이 이러한 편차를 추가로 학습한 후에는, 잔차의 평균이 0에 가까워지고 분산이 축소되는 개선이 확인되었다. 즉, 1차 모델이 놓친 비선형 패턴을 2차 모델이 일정 부분 학습하여 전체 오차 분포를 좁혀준 것이다. 이는 최종 앙상블 예측치의 RMSE 감소로도 이어져, 잔차 모델을 도입하지 않은 경우보다 약 5% 내외의 RMSE 개선이 보고되었다. 비록 R² 향상 폭은 제한적이었으나(±0.02 이내), 잔차의 자기상관 감소와 예측 분포의 안정화 측면에서 2-스테이지 접근의 가치가 입증되었다. 이러한 잔차 분석 결과는, 추후 더욱 정교한 앙상블이나 메타 모델링을 도입할 경우 추가 성능 잠재치가 존재함을 시사한다.

4. 결론 및 향후 계획

4.1 종합 평가

Phase 9는 데이터 무결성 확보와 모델 신뢰성 제고라는 관점에서 매우 유의미한 진전을 이루었다. 우선, 수치상으로는 이전 Phase 대비 Test R² 등 일부 지표가 낮거나 소폭 향상된 정도에 머물렀다. 겉보기에는 성능이 정체된 듯 보일지 모르나, 이는 평가 기준의 정상화에 따른 착시일 뿐이다. 누수 차단을 통해 모델 성능 지표의 거품이 제거되었고, 이제야 비로소 객관적인 실력치가 드러났다고 볼 수 있다. 그런 의미에서 Phase 9는 비록 일시적 성능 하락을 동반했으나, 실험 체계의 신뢰도를 확보했다는 점에서 성공적인 Phase로 평가된다. 또한 분포 보정과 다단계 모델링을 통해 미세하나마 성능 재향상의 단초를 마련했다는 점도 고무적이다. 이는 현재 데이터와 피처셋 하에서 얻을 수 있는 정보량의 한계치에 근접해가고 있음을 의미하며, 더 큰 도약을 위해서는 새로운 접근이 필요하다는 깨달음을 제공해주었다.

4.2 핵심 시사점

데이터 누수 검증의 중요성: 높은 R²나 낮은 에러율과 같은 지표도 데이터 누수의 산물일 수 있음을 본 Phase를 통해 재확인했다. Permutation Test 등 추가 검증 절차를 통해 모델이 실제 신호를 학습하는지 지속적으로 점검하는 것이 필수적임이 드러났다.

시계열 분포 보정의 효과: 시계열 데이터의 경우 Expanding Window 평균/분산 적용, Detrending 등 시간 축을 존중하는 전처리가 모델 일반화에 큰 영향을 미친다는 점이 확인되었다. 무작위 섞기(train/test shuffle) 환경에서는 드러나지 않던 Hidden Bias를 제거함으로써, 현실 환경(시간 순 진행)에서 오히려 성능을 향상시키는 아이러니한 결과를 얻었다.

복합 모델링의 가능성: 2-스테이지 잔차 모델링을 시도한 결과, 잔차 분포 개선 및 소폭의 예측력 향상을 이루었다. 이는 단일 모델로 포착하기 어려운 패턴을 복수 단계로 학습하거나, 여러 모델의 예측을 조합하는 전략이 유효할 수 있음을 시사한다. 향후 보다 세련된 메타 모델링이나 앙상블 기법 도입 시 추가 성능 향상 여지가 존재함을 보여준 사례이다.

4.3 향후 연구 방향

Phase 9를 통해 데이터 처리 파이프라인의 청결성(sanitization)과 평가의 타당성을 확보했으므로, 다음 단계에서는 이 견고한 기반 위에서 본격적인 성능 향상을 모색할 계획이다. 우선, 현 시점의 베이스라인 모델이 드러낸 성능 한계를 넘어서기 위해 모델 복잡도 증대 및 최적화를 추진할 것이다. 구체적으로, Phase 10에서는 하이퍼파라미터 최적화(Grid Search 혹은 Bayesian Optimization)를 통해 지금까지 수동으로 설정했던 학습 파라미터들을 체계적으로 튜닝할 예정이다. 또한 Phase 9에서 가능성을 보인 다단계 예측 기법을 더욱 발전시켜, 교차 예측 모델들의 앙상블이나 메타 학습을 도입함으로써 개별 모델이 놓치는 패턴을 통합적으로 학습하는 방향을 검토한다. 나아가, 필요한 경우 딥러닝 아키텍처와 같은 새로운 알고리즘적 접근을 시도하여 비선형 복합 패턴을 포착하는 능력을 강화할 수도 있다.

궁극적으로, Phase 9에서 확보된 신뢰할 수 있는 데이터 파이프라인은 향후 실험들의 든든한 토대가 될 것이다. 이제 더 이상 데이터 누수나 분포 편향에 발목 잡히지 않고, 모델 자체의 개선 효과에 집중할 수 있는 환경이 조성되었다. Phase 10에서는 이 환경을 최대한 활용하여, 보다 높은 예측 정밀도와 생산 현장 적용 가능성을 갖춘 최적 모델을 탐색하고자 한다. 이를 통해 최종적으로 압연 품질 예측 모델의 실용화를 위한 마지막 관문을 성공적으로 넘어설 계획이다.

Phase 10 : 교차 예측 프레임워크 도입 및 누수-안전성 강화

1. 개요 및 연구 배경

직전 Phase 9에서 모든 데이터 누수 차단 조치가 완료된 후 모델의 Test R²가 약 -0.08 수준까지 급락했다. 이는 초기 Phase 2에서 관측된 0.9522의 비정상적 고점이 데이터 누수로 인한 허상에 불과했음을 입증한 결과이다. 비록 성능 지표는 현실화되었으나, 판(Pass) 단일 정보만으로는 압연 공정의 복잡한 변동성을 설명하기 부족하다는 문제의식이 대두되었다. 이에 연구팀은 패스 간 인과 연결성(Inter-pass Dependency)을 모델링하는 새로운 접근을 모색하였다.

Phase 10에서는 Entry–Exit 교차 예측 프레임워크를 도입하여 인접한 두 패스의 상호 관계를 학습하도록 설계했다. 구체적으로, 홀수 패스(Entry 방향)에서 짝수 패스(Exit 방향)의 품질을 예측하는 모델(E2X)과 반대로 짝수 패스(Exit) 결과로 다음 홀수 패스(Entry)의 품질을 예측하는 모델(X2E)을 별도로 개발하였다. 각 모델은 물리적으로 인접한 패스 간의 품질 전이를 학습함으로써, 단일 패스 기반 모델이 놓쳤던 숨은 정보 이득(Information Gain)을 포착할 것이라는 가설이 수립되었다. 더불어, Phase 9에서 구축된 누수-프리 데이터 파이프라인 위에 시계열 분포 보정(Detrending), 목표 인코딩(Target Encoding), 이분산 가중치(Heteroskedastic Weighting) 등 고급 기법을 적용함으로써 모델의 일반화 성능을 제고하고자 했다. 본 Phase의 목표는 엄격한 롤포워드(Roll-forward) 평가 환경 하에서 교차 예측 모델이 유의미한 성능 향상을 달성하는지 검증하고, 잔존하는 분포 격차나 누수 가능성을 철저히 감사하는 데 있다.

2. 상세 기술적 구현 및 감사 결과

2.1. 주요 코드 변경 사항 및 구조적 진화

Phase 10의 핵심 변화는 데이터 처리 및 모델 구조를 패스 교차 예측에 맞게 재설계한 것이다. 우선 load_and_merge_data_tplus1() 루틴에서 그룹 기반 Shift 연산을 통해 타깃 변수를 생성했다. 구체적으로, 압연 판별자별(FM_날판번호 기준)로 데이터프레임을 정렬한 뒤 현재 패스의 워핑 지수(warping_index)를 다음 패스의 타깃 값으로 할당하여 새로운 컬럼 warping_index_target를 생성했다. 코드상으로는 merged_fm[TARGET_COL] = merged_fm.groupby(PLATE_COL)["warping_index"].shift(-1) 형태의 연산이 도입되어, 각 행이 패스 t의 입력으로 패스 t+1의 워핑 지수(TARGET_COL)를 예측하도록 재구성되었다. 이 과정에서 다음 패스가 존재하지 않는 최종 패스 행들은 TARGET_COL이 결측치로 표기되며 자동 제거되어(dropna(subset=[TARGET_COL])), 데이터 일관성이 확보되었다. 그 결과 하나의 연속된 판 내의 홀수 패스(Entry) 행은 그 다음 짝수 패스(Exit)의 품질을 타깃으로 가지며, 짝수 패스 행은 그 다음 홀수 패스의 품질을 타깃으로 갖게 된다.

데이터 병합 이후 두 개의 예측 서브모델이 구동되도록 코드 구조를 분리하였다. train_model(df, dataset_name) 함수는 전달된 데이터셋을 내부적으로 Entry→Exit (E2X)와 Exit→Entry (X2E)로 나누어 처리한다. 예를 들어 E2X 모델에는 홀수 패스 관측치만 사용하고, X2E 모델에는 짝수 패스 관측치만 사용하도록 data = data[data[PASS_COL] % 2 == 1] (E2X) 또는 % 2 == 0 (X2E)의 필터링이 적용되었다. 이렇게 분리된 두 데이터셋에 대해 동일한 전처리와 학습 절차가 독립적으로 수행되어, 최종적으로 두 개의 예측기(Entry기반, Exit기반)가 생성된다. 이러한 구조적 진화는 각 모델이 서로 다른 물리적 구간(압연 Entry vs Exit)의 특성을 전문적으로 학습하게 하여 모델 전문화(Specialization)를 도모한 것이다.

코드 모듈화와 함수 단위 개선도 이루어졌다. 예를 들어 Phase 9까지 단일 스크립트에 혼재되었던 전처리 로직과 학습 루틴을 함수화하여 재사용성을 높였다. train_model 내부에서는 데이터 분할부터 특징 생성, 모델 학습까지 일련의 과정이 단계별로 구현되었는데, 특히 데이터 누수 방지와 시계열 정합성 유지를 위해 각 단계에 새로운 보완 함수들이 도입되었다. 대표적으로, _hard_leak_guard(cols) 함수는 입력 특징 목록에서 이름에 'target', 'label', 'pred' 등 누수를 의심케 하는 키워드를 포함한 컬럼을 자동으로 제외하도록 설계되었다. 이로써 혹시 모를 정답 유출형 변수나 이전 단계 예측값(..._hat) 등이 피처로 유입되는 것을 사전에 차단한다. 또한 Phase 10에서는 아웃라이어(Outlier) 필터링 절차가 신설되어, 학습 데이터에 한해 타깃의 극단값 상하위 0.5%와 주요 수치형 피처의 상하위 1% 구간 밖 샘플을 제거하는 로직이 추가되었다. 이를 통해 데이터 노이즈를 완화하고 모델의 안정성을 높였으며, 테스트 데이터에 대해서는 동일한 임계값으로 clip 처리하여 분포 범위를 제한하였다. 이러한 전처리 개선은 잔차 학습 전에 데이터 이상치를 사전에 방어함으로써 과도한 값에 모델이 끌려가지 않도록 하는 역할을 수행했다.

2.2. 데이터 누수 및 정합성 포렌식

Phase 10 코드에 대한 포렌식 감사 결과, 명시적인 데이터 누수 경로는 모두 차단된 것으로 확인되었다. 먼저, 전형적 Label 누수의 경우 Phase 9에서 도입된 타깃/식별자 컬럼 제외 규칙(EXCLUDE_FROM_X)과 _hard_leak_guard 이중 장치를 통해 완벽히 방어되고 있었다. 실제로 모델 학습에 사용되는 최종 피처 집합에서 타깃(warping_index_target), 판 ID, 패스 번호 등 잠재 누수 요인은 일괄 제거되었다. 또한 Train/Test 간 정보 혼선을 막기 위한 조치도 강화되었다. 데이터 분할은 엄격한 Plate 단위 그룹 분리(GroupShuffleSplit)로 이루어져, 동일 압연판의 연속 패스 데이터가 훈련과 테스트에 나뉘어 섞이는 일이 없도록 했다. 구체적으로, joblib을 통해 테스트용 판 ID 목록을 파일로 고정("{prefix}_test_plates_tplus1.pkl")하는 앵커링(anchor) 기법이 적용되었는데, 이를 통해 매 실험마다 동일한 판이 테스트에 유지되어 결과의 재현성과 비교 가능성을 높였다. 또한 Transductive 누수(테스트 통계의 사전 유출)를 막기 위해, Phase 10에서는 훈련 집계 기반 전처리를 철저히 따랐다. 예를 들어 StandardScaler의 평균·표준편차 산출은 훈련 세트에 국한되며, RM 데이터(조업 데이터)의 통계 피처 역시 테스트 판의 정보를 배제하고 생성되었다. 이를 담당하는 함수 _attach_train_only_rm_stats는 훈련용 판들의 RM 데이터만으로 평균, 최댓값, 표준편차 등의 통계를 계산한 뒤 이를 훈련·테스트 세트에 매핑한다. 코드상 if USE_RM_TRAINONLY: tr_raw, te_raw = _attach_train_only_rm_stats(tr_raw, te_raw)로 호출되며, 함수 내부에서 테스트 판 ID를 필터링하여 (rm = rm[rm["RM_날판번호"].isin(plates_tr)]) 통계를 산출하고, 그 외 판에 대해서는 훈련 통계의 전역 중앙값으로 결측을 보충하도록 구현되었다. 이로써 RM 파생변수들이 테스트 세트의 분포 정보를 전혀 참조하지 않도록 하였다.

한편, Phase 10 모델의 잔여 누수 가능성에 대해 퍼뮤테이션 테스트를 수행한 결과, 통계적으로 유의한 누수 증거는 발견되지 않았다. 훈련된 E2X/X2E 모델에 대하여 타깃 값을 무작위로 섞어 재훈련 후 얻은 테스트 R²를 측정한 결과, E2X 모델은 -0.0321, X2E 모델은 -0.3618로 0에 수렴하거나 음수 값을 보였다. 이상적인 누수-프리 모델에서는 무작위 타깃에 대해 예측력이 0이어야 함을 고려할 때, 본 실험의 모델이 랜덤 노이즈에서는 아무런 규칙도 학습하지 못함을 의미한다. 특히 X2E의 permuted R²가 -0.36으로 더 낮게 나온 것은, 오히려 모델이 랜덤 데이터에 과적합하려다 실패하면서 음의 예측력이 나타난 것으로 해석된다. 이는 Phase 9 이전에 지적되었던 잠재 누수 원인(예: 잘못된 K-Fold 적용이나 미래 값 shift 등)이 Phase 10에서는 효과적으로 제거되었음을 시사한다. 다만, 내부 감사 도구는 여전히 코드 내의 shift(-1) 패턴이나 그룹 K-Fold 사용 등을 형식적 누수 신호로 분류하고 있었다. 예컨대 감사 리포트에는 FIT_ON_FULL; KFOLD_TS; NEG_SHIFT 등의 이슈 코드가 표기되었지만, 이는 Phase 10 이전 Phase들에서 문제로 지적되었던 동일 패턴에 대한 기계적 탐지일 뿐이다. 실제 Phase 10 구현에서는 shift(-1)을 수행한 후 그룹 분리에 따라 미래 정보 혼입을 차단했고, K-Fold도 GroupKFold(plate 기준)로 사용되어 시계열 순서 교란 없이 교차검증에 활용되었다. 따라서 이러한 패턴들이 존재함에도 불구하고, 논리적 누수(Logical Leakage)는 발생하지 않도록 설계되었다.

2.3. 실험 설정 및 플래그 분석

Phase 10에서는 다양한 전략 플래그들을 통해 모델의 학습 목표와 손실 구조를 세밀히 조정하였다. 각 플래그의 기술적 의의와 구현 영향을 다음과 같이 정리한다.

Δ-타깃 모드 (USE_DELTA_TARGET): 이 플래그가 활성화되면 모델이 예측해야 할 목표 변수가 절대 워핑 지수 값이 아닌 변동량으로 정의된다. 코드상 y_tr = target - current로 계산되어, 각 패스의 타깃(warping_index_target)에서 현재 패스의 워핑 지수(warping_index_current_pass)를 뺀 증감분 Δ만을 학습한다. 이를 통해 판별기마다 상이한 절대 수준의 차이(예: 초두품질 편차)를 제거하고, 패스 전이 간 상대적 변화만을 모델이 학습하도록 유도했다. 학습 완료 후 예측 복원 시에는 y_pred + current_value 형태로 현재 값에 예측 변화량을 가산하여 원래 스케일로 되돌리는 절차가 수행된다. Δ-타깃을 사용하면 분포 편차 교정과 추세 제거(detrending) 효과가 있으며, 특히 여러 판에 걸쳐 누적되는 시스템적 오차를 줄여 장기 롤포워드 안정성을 높이는 전략으로 판단되었다.

Pair Δ-타깃 인코딩 (USE_PAIR_TE): 패스 번호 쌍을 하나의 범주로 보고 그 잔차(Δ)의 평균적 경향을 피처로 추가하는 기법이다. 예를 들어 1→2패스, 2→3패스 등 연속 패스 쌍(pair) 별로, 해당 전이에서 나타나는 워핑 지수 변화분(Δ)의 평균을 계산하여 모델 입력에 제공한다. 구현은 pair = f"{pass}→{pass+1}" 형태의 식별자를 생성한 뒤, K-Fold OOF 방식으로 각 pair에 대한 평균 Δ 타깃값을 산출한다. 이렇게 구한 pair_delta_te 피처는 해당 패스 전이가 대체로 Warping 지수가 증가하는 구간인지 감소하는 구간인지 등의 경향성을 담는다. 예를 들어 8→9 전이에서 평균 Δ가 +19.4라면 (실험 결과 참조), 이 구간에서는 워핑 지수가 크게 증가하는 패턴이 있음을 의미하며, 모델은 이를 참고하여 예측을 보정할 수 있다. 단, 이 값은 동일 데이터에서 산출하면 누수 위험이 있으므로, 훈련 중 3-Fold GroupKFold로 OOF 방식을 적용하여 각 fold의 평균을 다른 fold의 샘플에 할당하는 방식으로 누수를 방지하였다. 최종적으로 테스트 세트에는 전체 훈련 세트의 pair별 평균을 적용하되, 해당 pair가 훈련에 존재하지 않으면 글로벌 평균으로 대체하는 로직이 구현되었다. 이 기법은 각 인접 패스 쌍의 고유한 난이도나 경향을 모델에 사전 제공함으로써, 제한된 표본으로부터 안정적인 추정을 돕는 역할을 했다.

이분산 가중치 (USE_HETERO_W): 서로 다른 패스 전이(pair)마다 잔차 분산이 상이하다는 점에 착안하여, 변동성이 큰 전이 구간은 모델 학습 시 가중치를 낮추고 안정적인 구간은 가중치를 높이는 가중치 부여(WLS: Weighted Least Squares) 기법이다. 구현상 '_oof_pair_std_weights' 함수는 pair별 Δ의 표준편차를 OOF 방식으로 추정하여, 각 훈련 샘플에 대응하는 표준편차 예측치를 구한다. 그리고 글로벌 표준편차 대비 상대 표준편차의 역수를 해당 샘플의 가중치로 사용한다. 쉽게 말하면, 잔차 변동이 큰 전이(표준편차 ↑)일수록 가중치 w = σ_global/σ_pair 가 작아지고, 변동이 작아 안정적인 전이(σ_pair ↓)일수록 w가 커진다. 실제 구현에서는 안정성을 위해 w 값이 [0.25, 3.0] 범위로 클리핑(clip)되었다. 최종적으로 이 가중치는 sample_weight으로 model.fit에 전달되어 모델이 변동성 큰 구간에서 과도한 최적화를 하지 않고, 전체적인 안정적 패턴을 우선 학습하도록 유도한다. 이분산 가중치를 적용함으로써, 예컨대 일부 극단적인 pair(예: 10→11 패스)의 큰 변화(Δ=-27)를 설명하려 지나친 복잡도를 갖추기보다는, 상대적으로 일관된 다른 pair들의 패턴을 더 잘 반영하는 방향으로 모델이 학습되었다.

단조 제약 (USE_MONO_CUR): XGBoost 모델에 한해 현재 패스 워핑 지수(CUR_WARP)와 타깃 간의 단조 증가 관계를 강제하는 제약을 건 플래그이다. 물리적으로 “현재 패스 품질이 높으면 다음 패스 품질도 높게 나온다”는 도메인 가설을 반영하여, CUR_WARP 피처의 계수가 음의 영향을 주지 못하도록 제약을 둔 것이다. 구현상 _build_model 함수에서 XGBoost regressor 생성 시, monotone_constraints 파라미터에 +1 값을 할당하여 해당 피처의 기울기가 항상 양수 방향이 되도록 했다. 이때 mono_cur_idx로 현재 워핑 지수 컬럼의 인덱스를 식별하고, 나머지 피처에 대해서는 0으로 제약 벡터를 설정하여(v = [0,...,0]; v[idx] = 1) 단조 제약이 오직 해당 피처에만 적용되도록 하였다. 이를 통해 모델이 warping_index_current_pass 값이 커질수록 warping_index_target도 커지는 방향으로만 예측함을 보장한다. 실제 물리적 현상에서 현재 패스의 워핑이 심하면 그 효과가 다음 패스에도 누적되거나 추가 보정이 어려워 품질 저하로 이어질 가능성이 높다. 단조 제약은 이러한 선험적 지식을 모델에 주입하여 비합리적인 예측(예: 현재 워핑 높지만 다음 패스는 좋아진다고 예측)을 배제하고, 모델 예측의 물리적 일관성을 유지하도록 돕는다.

이 외에도 Phase 10에서는 자동 누수 감사 모드(LEAK_AUTOCHECK)가 기본 활성화되어, 실험 종료 시 quick_perm_leak_r2()를 통해 누수 지표를 자동 산출하도록 했다. 또한 PERMUTE_TARGET 플래그를 수동으로 켜면 전체 타깃을 무작위 교환하여 학습하는 기능도 구현되었는데, 이는 개발 단계에서 모델의 분별력을 스트레스 테스트하는 용도로 쓰였다 (본 Phase의 공식 실험에서는 PERMUTE_TARGET=0으로 꺼짐). 요약하면, Phase 10은 다층적인 전략 플래그를 도입하여 데이터 분포 차이 보정, 누수 방지, 물리 법칙 준수라는 세 마리 토끼를 잡고자 한 시도였다.

3. 실험 결과 및 데이터 분석

3.1. 정량적 지표 변화

Phase 10 교차 예측 모델의 성능은 Phase 9 베이스라인과 비교했을 때 유의미한 향상을 보여주지 못했다. 누수 제거 후 단일 모델 기준이었던 Phase 9의 평균 Test R²가 약 -0.08 수준이었는데, 교차 예측 E2X+X2E 듀얼 모델의 평균 Test R²는 -0.0866로 거의 동일한 수준에 머물렀다. E2X 모델(Test: -0.1343, Train: 0.4124)과 X2E 모델(Test: -0.0390, Train: 0.8507)의 개별 성능을 보면, 두 모델 모두 학습 데이터에 대해 어느 정도 예측력을 보유하고 있으나 테스트에서는 R²가 음수로서 기준 예측보다도 못한 결과를 보였다. 이는 모델이 여전히 과적합되어 새로운 판에 일반화하지 못함을 의미한다. 특히 X2E 모델의 경우 훈련 R²가 0.8507로 매우 높았음에도 테스트 R²가 -0.04에 불과하여, Exit→Entry 관계를 학습한 모델이 훈련 세트 패턴을 강하게 암기했지만 미지의 판 환경에서는 전혀 성과를 내지 못함을 알 수 있다. 한편 E2X 모델은 훈련 R² 0.41 대비 테스트 -0.13으로, 성능 자체는 낮지만 과적합 정도는 X2E보다 덜한 편이었다. 이는 Entry→Exit 방향 예측이 비교적 더 단순하거나 일관된 물리 관계를 가지며, Exit→Entry보다 일반화가 약간 수월할 가능성을 보여준다. 두 모델의 예측을 단순 평균하거나 (Phase 10에서는 평균을 산출하여 보고만 함) 통합하여도 Test R²가 음수에서 벗어나지 못했는데, 평균 Test R² = -0.0866로 집계되었다. 결국 교차 예측 프레임워크 도입만으로는 Phase 9 대비 유의미한 성능 개선이 없었다고 평가된다.

흥미로운 점은, Phase 10 초기 실험 단계에서 Δ-타깃/TE/가중치 등을 적용하기 전 교차 모델을 시도했을 때는 일시적으로 평균 Test R²가 0.18~0.19 수준까지 상승한 바 있다는 것이다(예: 실험 047의 평균 Test R² = 0.1892). 이는 Entry와 Exit 간 관계를 활용하면 어느 정도 예측 신호를 포착할 수 있음을 시사하지만, 동시에 해당 성능은 다소 누수 가능성이 있는 설정에서 나왔음을 감안해야 한다. 실제로 047 실험에서는 RM 통계를 전체 데이터로부터 구해 사용하고 Δ-타깃을 적용하지 않는 등 일부 완화된 조건이었기에, 이후 Phase 10의 엄격한 설정을 적용하면서 성능 수치가 다시 하락했다. 최종적으로 Δ-타깃/Train-Only 통계 등 모든 보정 장치 적용 후 얻은 -0.0866이라는 수치는, 과거의 누수로 인한 거품을 모두 걷어낸 상태에서의 실질적인 교차 모델 성능 한계치로 볼 수 있다. 수치상으로는 Phase 9 단일 모델과 큰 차이가 없지만, 이는 모델이 불필요한 정보에 의존하지 않고 온전히 물리적 패턴만으로 학습한 결과라는 점에서 의의가 있다. 한편 Train R²와 Test R² 사이의 큰 격차로 미루어, 현재 모델이 여전히 데이터 내재적 변동성을 충분히 설명하지 못하고 있음을 알 수 있다. 이는 잔존하는 변수 누락 또는 모델 구조상의 한계를 암시하며, 추후 개선이 필요함을 시사한다.

3.2. 통계적 검증 및 로그 포렌식

Phase 10 실험 로그를 면밀히 분석한 결과, 데이터 분포 변화와 모델 일반화 한계에 대한 다수의 단서를 확보하였다. 우선 [Δ-분석] 섹션을 통해 패스 전이 간 분포 차이를 검정한 결과를 살펴보면, Entry→Exit 전이의 경우 std_max/min = 1.775, Kruskal-Wallis p = 1.28×10^-74라는 극단적으로 작은 p값이 관측되었다. X2E 전이에서도 std_max/min = 2.181, p = 2.30×10^-9로 유의수준 0.05를 훨씬 밑돌았다. 이 뜻은 각 패스 전이(예: 1→2 vs 3→4)의 워핑 변화분 분포가 통계적으로 서로 다르다는 것을 강력하게 지지한다. 예컨대 상위 Δ 편차를 보면, 1→2 패스에서는 평균 Δ = -29.217 (표준편차 15.265)으로 큰 음의 변화(워핑 감소)가 일어나지만, 5→6 패스에서는 평균 Δ = -6.84 (표준편차 25.220)로 상대적으로 변화 폭이 작고 불확실성이 크다. 또한 Exit→Entry의 특정 전이(예: 8→9)에서는 평균 Δ = +19.395로 워핑 지수 급등 현상이 나타나는 반면, 어떤 전이(10→11)에서는 -27.0로 크게 떨어지는 등 방향성조차 일정하지 않았다. 이러한 전이별 이질성(Heterogeneity)는 모델이 하나의 회귀 직선(또는 트리 분할)으로 모든 패스를 설명하기 어렵게 만드는 주된 원인이다. Phase 10의 Δ-타깃 적용과 이분산 가중 치략은 바로 이 문제를 해소하기 위한 것이었으며, 로그 상에서도 Δ-타깃 모드 적용 시 특정 전이들 간 분산 격차가 줄어드는 효과가 관찰되었다. 그럼에도 불구하고 분포 차이가 완전히 사라지지는 않아, 모델은 여전히 일부 전이에 대해 과적합 경향을 보였다.

Strict Roll-forward 평가 지표는 모델의 한계를 적나라하게 보여준다. Phase 10에서 훈련된 E2X와 X2E 모델을 교대로 사용해 전체 압연 공정(다수 패스 연쇄)을 롤포워드 시뮬레이션한 결과, Strict Roll-forward R² = -11.7356라는 충격적인 수치가 기록되었다. 이 값은 테스트 세트의 단일 패스 예측 성능(-0.0866)보다 훨씬 낮을뿐더러, 음수 수준이 매우 커 모델 예측 누적 오차가 기하급수적으로 증폭됨을 의미한다. 구체적으로, 한 패스의 예측 오차가 다음 패스 입력에 반영되고 다시 오차를 키우는 오차 누적 현상이 발생하여, 전체 판 수준에서 보면 예측값이 차라리 평균만 예측한 것보다도 훨씬 못한 상황이 되었다. 이러한 결과는 현재의 교차 예측 모델이 국소적인 1-스텝 예측에는 그나마 대응하나, 장기적인 시계열 전이 과정 전체를 견인할 정도의 안정된 패턴을 학습하지 못했다는 것을 시사한다. 이는 Phase 10의 cross 모델이 단기 상호작용은 일부 포착했지만, 전 과정의 동역학(dynamics)을 모사하는 데 한계가 있음을 보여준다. 요컨대, 엄격한 롤포워드 평가에서의 실패는 향후 모델 구조 개편이나 추가 정보의 필요성을 강하게 암시하는 대목이다.

끝으로, 앞서 언급한 퍼뮤테이션 테스트 결과를 재검토하면 모델의 정보 활용 방식이 건전한지를 확인할 수 있다. E2X와 X2E 모델 모두 무작위 타깃에 대해 R² ≈ 0 수준을 기록하여, Phase 10에서 적용된 모든 누수 방지책이 효과적으로 작동했음이 입증되었다. 특히 Phase 2 당시 관측된 permuted R² ≈ 0.95(심각한 누수 상태)와 대비하면, 현재 모델은 불필요한 상관 구조를 전혀 학습하지 않고 순수하게 데이터 패턴만 학습하고 있음을 알 수 있다. 이러한 통계적 검증 결과는 성능이 낮게 나왔음에도 연구팀이 Phase 10 모델을 신뢰할 수 있는 이유를 뒷받침한다. 낮은 R² 자체보다 중요한 것은 그 R²가 거짓 없는 값인가 하는 점이며, Phase 10에서는 비로소 그 조건이 충족되었다.

3.3. 모델 강건성 및 잔차 분석

Phase 10 모델의 강건성을 평가하기 위해 훈련 vs. 테스트 잔차 분포와 상관 구조 변화를 점검하였다. E2X 모델의 경우 훈련 데이터에서의 예측 잔차(실제-예측)의 표준편차는 대체로 안정적이었으나, X2E 모델은 특정 판에서 잔차가 체계적으로 크게 나타나는 현상이 발견되었다. 예를 들어 Exit→Entry 모델은 초기 패스(패스 2→3 등) 구간에서는 잔차가 무작위 노이즈에 가깝게 분포했지만, 후반부 패스(패스 10→11 등)에서는 잔차 평균이 음의 방향으로 크게 치우치고 분산도 증가했다. 이는 모델이 일종의 체력 고갈을 보이는 것으로, 연속된 예측을 거듭할수록 누적 오차를 보정하지 못하고 한쪽으로 편향되는 드리프트(drift) 현상이 있음을 시사한다. Phase 10에서는 이러한 드리프트를 줄이고자 Δ-타깃과 모노토닉 제약을 적용했지만, 여전히 완전하지 않다는 것이 수치로 나타난 것이다.

한편, 특징 상관도 변화를 보면 전반적으로 Δ-타깃 적용 후 현재 패스 워핑(CUR_WARP)과 타깃(TARGET) 간 상관계수는 Phase 9 대비 크게 감소한 것으로 나타났다. 이는 당연한 결과로, 타깃 자체를 변화량으로 정의하면서 절대 수준에 대한 상관성이 사라졌기 때문이다. 대신, CUR_WARP와 잔차 Δ 간의 상관관계는 +0.3 수준으로 새롭게 형성되었는데, 이는 CUR_WARP가 높을수록 다음 패스 증가폭이 줄어드는 경향(음의 영향)이 드러난 것을 의미한다. Phase 10에서 모노토닉 제약을 +1로 설정한 것은 이러한 상관 결과와 모순되지만, 이는 워핑 지수가 높은 판일수록 절대 타깃도 높다는 장기적 추세를 반영한 것이지, 증분 변화량과의 관계와는 다른 차원의 고려였다. 결국 상관 분석은 Δ-타깃으로 모델 상관 구조를 재편했지만, 추가적인 변수(예: 소재 특성 등)가 없이는 예측 성능 향상으로 직결되지 않음을 보여준다.

종합하면, Phase 10의 다양한 분석 지표는 교차 예측 전략이 일정 부분 합리적이고 누수 없는 토대를 마련했음에도, 데이터 자체 한계와 모델 표현력 부족으로 인한 성능 정체를 경험하고 있음을 증명한다.

4. 결론 및 향후 계획

4.1. 종합 평가

Phase 10 실험은 데이터 무결성을 유지하면서 새로운 물리적 인과관계를 모델에 주입하려는 시도였으며, 그 목적은 부분적으로 달성되었다. 긍정적으로 평가할 면은, 이전 Phase들에서 문제되었던 각종 누수 요인을 완벽히 제거하여 신뢰할 수 있는 평가 체계를 확립했다는 점이다. 비록 Test R² 등 정량적 지표의 개선은 미미하거나 소폭 악화(-0.08 → -0.0866)되었지만, 이는 모델에 허용된 정보가 엄격해진 결과이며 거품이 제거된 진실한 성능 수치라는 점에서 의미가 있다. 달리 말해, Phase 10은 “성능 유지”를 대가로 “신뢰성 확보”를 이룬 단계로 볼 수 있다. 그러나 애초 기대했던 교차 모델에 따른 정보 이득은 뚜렷이 확인되지 않았고, 오히려 롤포워드 테스트에서 성능이 크게 악화된 것은 한계로 남는다. 따라서 Phase 10을 통해 Entry-Exit 교차 예측만으로는 현재 데이터의 복잡성을 충분히 설명하지 못한다는 중요한 교훈을 얻었다. 전반적으로 Phase 10은 수치상의 큰 성공은 아니었으나, 향후 올바른 방향 전환을 위한 기술 부채 청산과 문제 재정의를 이룬 의미있는 과정으로 평가된다.

4.2. 핵심 시사점

- 데이터 분포 교정의 중요성: Kruskal-Wallis 검정 결과 판별된 극심한 분포 차이는, 시계열적 데이터에서는 무작위 분할이 아닌 체계적 분포 보정이 필수임을 재확인시켰다. Δ-타깃 등 detrending 기법을 통해 이러한 분포 차이를 완화할 수 있으나, 그에 따른 예측 난이도 상승도 함께 발생함을 깨달았다.
- 누수 없는 모델링의 대가: Phase 10에서 경험했듯이, 모든 누수를 제거한 모델은 초기에는 성능 지표가 급락할 수밖에 없다. 이는 성능 하락이 아니라 숨겨진 과적합 요소 제거로 해석해야 하며, 장기적으로 올바른 모델 개발을 위한 필요한 단계임을 확인하였다.
- 교차 예측의 한계: Entry↔Exit 2스텝 모델링만으로는 공정 전체 동작을 포착하기에 부족하다. 국부적인 1단계 예측은 가능하나, 다단계 예측에서는 작은 오차 누적으로 큰 성능 저하가 발생하였다. 이는 추가적인 보정 장치나 새로운 구조 없이는 현 방식의 확장에 한계가 있음을 시사한다.

4.3. 향후 연구 방향

Phase 10에서 얻은 통찰을 바탕으로, 다음 Phase에서는 모델 구조 및 학습 전략의 근본적인 재설계가 불가피하다. 구체적으로, 이번 교차 예측 접근이 단발성 2스텝 관계에만 초점을 맞추어 장기적인 시계열 의존성(Long-term dependency)을 잡아내지 못했으므로, Phase 11에서는 연속 패스 전체를 한꺼번에 모델링하는 시퀀스 학습을 도입할 계획이다. 예를 들어 LSTM과 같은 순환신경망(RNN) 아키텍처나 Transformer 기반 시계열 예측 기법을 도입하여, 멀티패스 연쇄를 하나의 sequence로 투입하고 출력까지 한 번에 예측하는 접근을 검토하고 있다. 이와 함께, Phase 10에서 식별된 오차 누적 문제를 해결하기 위해 잔차 예측 2단계 모델(Residual Stacking)이나 앙상블 기법을 활용하는 방안도 모색 중이다. 다음 Phase에서는 이러한 새로운 기법들을 통해 현재 -0.08 수준에 머무른 성능을 끌어올리고, 압연 공정 품질 예측의 실용적 활용 가능성을 다시 타진할 예정이다. 또한 Phase 10까지 축적된 노하우 – 예컨대 누수 방지, 분포 보정, 가중치 설계 – 는 Phase 11의 모델 개발 과정에서도 지속적으로 적용되어 정확도와 신뢰성을 겸비한 예측 모델을 구축하는 밑거름이 될 것이다.
