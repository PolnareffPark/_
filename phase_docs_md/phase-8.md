# phase-8

Phase 8 : 입·출측 교차예측 프레임워크 재도입 및 엄격 롤포워드 검증

1. 개요 및 연구 배경 (Executive Summary)

이전 Phase 7까지 모델의 일반화 성능은 매우 낮은 수준에 머물러 있었다. 특히 Test R² 지표는 0에 수렴하거나 음수를 기록하여[1], 데이터 누수 방지 이후 모델이 사실상 예측력을 상실한 상태임이 확인되었다. 이는 단일 패스의 정보만으로는 압연 공정의 복잡한 변동성을 설명하기 어렵다는 것을 의미한다. 즉, 인접한 패스 간의 상호 의존성(Inter-pass Dependency)을 모델링하지 않고서는 유의미한 예측 신호를 포착하기 힘들다는 문제 의식이 도출되었다.

이에 따라 연구팀은 교차 예측 프레임워크를 Phase 8에 재도입하기로 결정했다. 물리적으로 “입측 조건이 출측 품질을 결정하고, 출측 결과가 곧바로 다음 패스의 입측 조건으로 이어진다”는 인과 관계에 착안하여, 입측→출측(E→X) 및 출측→입측(X→E) 두 방향의 모델을 동시에 학습시키는 구조를 설계하였다. 이를 통해 이전 Phase에서 배제되었던 패스 간 연속성을 인공적으로나마 복원하여 정보 이득(Information Gain)을 얻는 것이 본 Phase의 핵심 가설이다.

Phase 8의 목표는 이러한 E↔X 교차 모델이 엄격한 롤포워드 검증 환경에서도 성능 향상을 나타내는지 확인하는 데 있다. 구체적으로, 롤포워드(Roll-forward)란 판별된 Train/Test 분할에 따라 첫 패스부터 최종 패스까지 순차적으로 모델 예측을 이어가는 평가 방식을 의미한다. 본 Phase에서는 교차 모델의 예측값을 실제 다음 패스의 입력으로 지속적으로 공급하며, 시계열적 누적 오차 없이 예측력이 유지되는지를 검증했다. 궁극적으로, 데이터 누수 없이 확보된 청정(BaseLine) 환경에서 교차 예측이 실질적인 성능 개선을 이끌어낼 수 있는지 규명하고, 이후 Phase에서 도입할 추가 개선책의 필요성을 평가한다.

2. 상세 기술적 구현 및 감사 결과 (Detailed Technical Audit)

2.1. 주요 코드 변경 사항 및 구조적 진화 (Key Code Evolution)

Phase 8에서는 기존 단일 스크립트 형태의 파이프라인을 이중 모듈 구조로 재편하였다. 즉, 하나의 판(Plate) 내에서 입측 데이터로 출측 워핑 지수를 예측하는 E2X 모델과, 반대로 출측 결과를 이용해 다음 패스의 타깃(입측)을 예측하는 X2E 모델을 분리 구현했다. 이를 위해 final_df 데이터프레임을 구성할 때 각 판의 현재 패스 워핑 지수를 입력 변수(warping_index_current_pass)로 두고, 다음 패스의 워핑 지수를 타깃 변수(warping_index_target)로 생성하였다[2]. 구체적으로, pandas.DataFrame.groupby(PLATE_COL)["warping_index"].shift(-1) 연산을 통해 각 판별로 다음 패스의 warping_index를 추출하여 타깃 컬럼으로 추가하고, 기존 warping_index 컬럼은 현재 패스의 피처로 이름 변경하였다[2]. 이 과정에서 마지막 패스에는 타깃 값이 존재하지 않으므로 해당 레코드는 학습에서 제외하도록 전처리되었다.

데이터 병합 단계에서는 RM 데이터(압연 기계 설정값)와 FM 데이터(소재 특성값)를 모두 ground_truth와 조인하여, 각 패스에 대한 다양한 입력 변수를 확보했다[3][4]. 또한 동일 판 내 여러 패스에서 발생하는 공정 조건 분포의 차이를 모델이 인지하도록, 판 단위 통계 특징을 추가 생성했다. 예를 들어 RM 데이터에 대해서는 판별 그룹별로 다섯 가지 요약 통계치(평균, 최댓값, 최솟값, 표준편차, 중앙값)를 계산하여 RM_***_mean, RM_***_std 등의 새로운 피처로 병합하였다[5]. 마찬가지로 FM 데이터에 대해서도 각 행에 존재하는 다수의 센서 값들을 통합하는 파생변수 (FM_mean, FM_std, FM_range 등)를 생성하여 입력 특징 공간의 정보 밀도를 높였다[6]. 이러한 다중 데이터 소스 결합 및 파생 변수 추가를 통해, E2X 모델은 입측판 및 공정 조건 전반을 고려한 출측 품질 예측을 수행하고, X2E 모델은 이전 패스의 결과로 다음 패스의 품질을 추정하는 구조를 갖추게 되었다.

모델링 부분에서는 교차 검증과 데이터 분할 전략에 중요한 수정이 가해졌다. 이전 Phase까지 일부 실험에서는 전체 데이터에 대해 K-Fold를 적용하거나 잘못된 방식으로 시계열 분할을 수행하여 누수 가능성이 있었다[7]. Phase 8에서는 이를 방지하기 위해 판(Group) 단위 분리를 철저히 적용했다. GroupShuffleSplit을 활용하여 동일 판에 속한 모든 패스 데이터를 훈련 또는 테스트 중 한쪽에만 속하도록 데이터를 분할함으로써, 특정 판의 출측 정보가 동일 판의 입측 예측에 스며드는 누수 경로를 원천 차단하였다[8]. 그 결과, 학습 시에는 한 판의 모든 패스 연속 데이터가 훈련에 사용되거나 배제되며, 테스트 시에도 훈련에 전혀 등장하지 않은 판들의 연속 패스들만으로 성능을 검증하게 되었다. 이렇게 설정된 Group별 시나리오 분할은 교차 예측 모델의 일반화 검증에 필수적인 기반을 제공하였다.

2.2. 데이터 누수 및 정합성 포렌식 (Forensic Leakage Audit)

Phase 8 코드에 대한 포렌식 감사 결과, 명시적인 데이터 누수는 발견되지 않았다. 우선, 입력 피처 구성 단계에서 _drop_name_leaky_cols 함수와 _assert_and_drop_value_leak 함수의 이중 방어막이 새롭게 도입되었다. _drop_name_leaky_cols는 컬럼명에 target, label, pred, oof 등 정답정보 누출을 암시하는 패턴이 포함된 경우 자동으로 해당 변수를 제거한다[9][10]. 이러한 패턴들은 정규표현식 리스트 LEAKY_PATTERNS로 관리되며, 예컨대 'target', 'label', 'y_true', 'y_pred' 등이 포함되어 있어 해당 키워드를 이름에 가진 어떠한 컬럼도 예외 없이 학습 입력에서 제외된다[11]. 그 결과, 잘못된 전처리나 피처 추가로 타깃 값을 그대로 갖는 컬럼이 생성되더라도 모델에 영향을 주지 않도록 사전 차단하였다.

또한, _assert_and_drop_value_leak 함수는 값 기반 누수를 방어한다. 이 함수는 학습용 피처(Xtr_df)의 각 컬럼을 타깃 벡터(ytr)와 비교하여, 완전히 동일한 경우 또는 상관계수 |r| ≥ 0.99999인 경우 해당 컬럼을 누수로 간주하고 제거한다[12]. 특히 상관계수 임계값을 0.99999로 극도로 높게 설정한 것은, 수치적으로 거의 일치하여 모델이 정답을 쉽게 추론해버릴 수 있는 경우까지 모두 탐지하려는 의도이다. 실제 Phase 8의 최종 코드에서는 이 기준에 의해 특정 파생변수가 제거되었는데, 예를 들어 타깃 변수(warping_index_target)를 계산하는 과정에서 발생한 중간 값이 우연히 타깃과 일치하거나 극도로 유사한 상관도를 보이면, 해당 변수가 훈련 시작 전에 drop되어 이후 파이프라인에 포함되지 않는다. 이러한 엄격한 값 비교 누수 검증을 통과한 피처들만 모델 학습에 사용되므로, Label Leakage와 Target Leakage 가능성을 코드 레벨에서 차단했다고 판단된다.

Permutation Test 결과 역시 누수가 없음을 뒷받침한다. Phase 8 모든 실험에는 LEAK_AUTOCHECK 플래그가 활성화되어, 타깃을 무작위로 섞은 데이터에 대한 모델 R²를 자동 산출하였다. 대표적으로, 주요 실험에서 E2X 모델의 permuted R²는 -0.0321, X2E 모델은 -0.3618로 기록되었다[13]. 두 값 모두 0에 수렴하거나 음수이며, 이는 타깃과 무관한 랜덤 노이즈에 대해서는 모델이 어떤 유의미한 패턴도 학습하지 못한다는 것을 의미한다. 따라서 본 Phase의 교차 예측 프레임워크에는 치명적 데이터 누수 경로가 존재하지 않는다고 결론지을 수 있다. 다만, 감사 과정에서 데이터 처리상의 경계 사례 몇 가지가 식별되었다. 예컨대, Transductive한 통계 특성 사용 가능성이다. Phase 8 코드에서는 판별 통계 피처(RM_stats 등)를 전체 데이터에 대해 계산하여 합치는 로직이 있었는데, 이로 인해 테스트 세트 정보까지 포함한 평균값 등이 훈련에 쓰일 우려가 있다. 이를 제어하기 위해 코드 상에는 USE_RM_TRAINONLY라는 플래그가 마련되어, 활성화 시 훈련 세트에 한해서만 RM/FＭ 통계를 계산하도록 설계되었다. 그러나 최종 실험에서는 해당 옵션이 비활성(0) 상태로 진행되어, 미량의 정보 누출 가능성을 완전히 배제하지는 못했다. 이 부분은 사후 통계 분석에서 모델 성능에 영향이 없는 것으로 판단되었으나, 향후 Phase에서 보다 엄격한 통계 산출 분리가 구현될 예정이다.

2.3. 실험 설정 및 플래그 분석 (Configuration Analysis)

Phase 8에서는 다양한 전략 플래그들이 도입되어 실험적으로 검증되었다. 우선 USE_DELTA_TARGET (DT) 옵션은 타깃값을 현재 패스 대비 변화량(Δ)으로 변환하는 기능이다. 이 플래그를 켜면 모델이 각 패스의 절대적인 워핑 지수 대신 증감분만 학습하게 된다. 이론적으로 이는 패스 간 분포 이동(Distribution Shift)을 보정해 주는 효과가 있어, 전체적인 트렌드를 제거하고 잔차 패턴만 학습하도록 유도한다. 실제 045번 실험에서 USE_DELTA_TARGET=1로 설정하여 실행한 결과, Train R²는 0.4070에서 Test R² -0.1451로 급락하는 현상이 관측되었다[14][15]. Δ-타깃으로 문제를 재정의하자 E2X 모델의 예측 성능이 음수가 될 정도로 학습이 어려워진 것이다. 이는 워핑 지수의 변화량 신호에 노이즈가 많아 단순 적용만으로는 오히려 성능이 악화될 수 있음을 시사하며, DT 기법의 효과를 보려면 추가적인 보정이 필요함을 보여준다.

다음으로 USE_PAIR_TE (Target Encoding)는 패스 번호와 이전 패스 결과를 묶은 범주형 변수에 대해 타깃 평균 인코딩을 적용하는 기능이다. 목적은 특정 패스 전환 구간(예: 1→2, 2→3 등)에 따른 상승/하락 경향을 데이터에서 학습하도록 하는 것이다. 다만, 정보 누수를 막기 위해 K-Fold OOF 방식으로 각 조합의 평균을 계산하며, 학습 중 자기 자신의 타깃값은 포함되지 않도록 구현되었다. Phase 8 중간 실험(050번 등)에서 TE를 적용했으나, Δ-타깃 적용과 동시에 이뤄져 효과를 제대로 분리하진 못했다[16]. 그 결과 Test R² 개선이 관측되지 않았고, Phase 8 최종 모델에서는 TE를 비활성화(0)한 채 진행되었다. 이는 교차 테이블 기반의 인코딩이 데이터 양 부족으로 인한 과적합을 야기할 수 있으므로, Phase 9에서 별도 조건 하에 재검토될 예정이다.

또한 USE_HETERO_W (Heteroscedastic Weighting) 옵션은 패스별 예측 오차의 분산 차이를 보정하기 위한 기법이다. 각 데이터 포인트에 대하여 해당 패스의 잔차 표준편차의 역수를 가중치로 부여하여, 변동성이 큰 패스보다 안정적인 패스의 데이터에 모델이 더 민감하도록 학습하는 원리이다. 이는 Phase 7까지의 분석에서 패스 간 워핑 지수 분포 분산이 최대 2배 이상 차이남이 확인되었고[17], 분산이 큰 패스(초기 패스 등)에서는 모델 예측이 어려워지는 현상을 완화하기 위해 도입되었다. Phase 8에서는 이 옵션도 시범 적용되었으나(052, 053번 실험), 다른 플래그들과 중첩되어 단독 효과를 평가하기 어려웠다[18][19]. 향후 연구에서는 패스별 가중치 최적화를 통해 모델의 균형 학습을 도모할 계획이다.

마지막으로 USE_MONO_CUR (Monotonic Constraint)는 현재 패스 워핑 지수(CUR_WARP)에 대한 단조 증분 제약을 XGBoost 모델에 부여하는 설정이다. 물리적으로 “입측 워핑 지수가 높을수록 출측 워핑 지수도 높아질 가능성”을 고려하여, 모델이 해당 피처에 대해 단조롭게 예측하도록 강제함으로써 해석 가능성 및 과적합 완화를 노렸다. 이 역시 Phase 8 실험(052, 053번)에서 한차례 적용되었으나, 다른 개선기법 실패로 전반적인 성능이 낮아져 모노토닉 제약의 효과를 판단하기 어려웠다[18]. 다만 훈련 결과를 살펴본 바, 제약 조건으로 인해 CUR_WARP의 피처 중요도가 다소 감소하고, X2E 모델의 예측 편차가 안정화되는 경향은 포착되었다. 본 Phase 최종 모델에는 적용되지 않았지만, 이러한 모노토닉 정책은 도메인 지식 반영 측면에서 향후 재도입 여지를 남겼다.

종합하면, Phase 8에서는 기본 교차 예측을 구현한 상태에서 다양한 보조 전략 플래그들을 실험하였으며, 일시적으로 모든 전략을 동시에 가동한 052번 실험에서는 평균 Test R² -0.0866으로 성능이 급격히 악화되기도 했다[20]. 이로부터 “개선 기법의 동시 다발적 적용은 오히려 학습 불안정성을 초래한다”는 교훈을 얻었으며, Phase 9에서는 각 기법의 효과를 개별적으로 정량 평가하고 점진적으로 통합하는 방향으로 연구가 진행될 것이다.

3. 실험 결과 및 데이터 분석 (Performance Analysis)

3.1. 정량적 지표 변화 (Quantitative Performance Evolution)

교차 예측 프레임워크 도입 전후의 성능 지표 변화는 극명하였다. Phase 7까지 데이터 누수를 제거한 단일 모델은 Test R²가 약 -0.08 수준으로, 예측력이 통계적 우연과 구분되지 않는 상태였다. 그러나 Phase 8에서 E2X-X2E 이중 모델을 활용하자 평균 Test R²가 +0.3354로 상승하며, 양의 설명력을 회복한 것이 확인되었다[21]. 세부적으로, 출측 예측 (E2X) 모델은 Test R² = 0.3729, 입측 예측 (X2E) 모델은 Test R² = 0.2979를 달성하여[21], 두 모델 모두 이전 Phase의 0에 가까운 수준에서 크게 개선되었다. 이는 교차 모델이 단일 패스 정보로는 포착하지 못하던 부분적인 신호를 포착했음을 의미한다. 특히 X2E 모델의 경우, 이전 패스의 출측 결과를 활용함으로써 미래 패스의 난이도(예측 가능성)를 어느 정도 예견할 수 있었던 것으로 분석된다.

반면 학습 데이터에 대한 성능은 매우 높게 나타났다. E2X 모델의 Train R²는 0.9264에 달했고, X2E 모델도 0.9143을 기록하여[22], 두 모델 모두 학습 세트에 과도하게 적합되는 경향을 보였다. 이로 인해 일반화 격차(Generalization Gap)가 약 0.59p에 이르는 심각한 수준으로 발생했다. 이는 교차 모델이 도입되었음에도 불구하고 훈련 데이터에 과적합하는 문제는 여전히 남아있음을 시사한다. 원인으로는 학습 데이터의 표본 수가 제한적인 반면, 모델 파라미터 수는 많고 복잡도가 높아 데이터 패턴을 과하게 흡수한 것으로 추정된다. 또한 E2X와 X2E 두 모델 모두 XGBoost와 RandomForest 등 Ensemble 트리 기법을 사용하여 훈련 데이터에서 높은 성능을 쉽게 끌어올릴 수 있었던 반면, 미지의 판에 대해서는 대응을 제대로 하지 못한 것으로 보인다.

흥미롭게도, 교차 예측 도입 초기 일부 실험에서는 비정상적으로 높은 성능 수치가 관찰되기도 했다. 예를 들어 Experiment 002에서는 평균 Test R²가 0.4174까지 보고된 바 있다[23]. 그러나 이는 데이터 분할 설정이 완벽히 엄격하지 못했던 초기 실험 단계의 결과로 판단되며, 이후 엄격한 Group 분할 및 롤포워드 평가를 적용한 최종 실험들에서는 0.33 수준으로 성능이 정상화되었다. 이 과정에서 0.4174라는 수치는 일종의 거품으로 간주되었고, Phase 8의 성과는 거품이 제거된 0.33대의 신뢰성 있는 R²로 재평가되었다. 요약하면, 교차 예측 프레임워크의 도입은 누수 없이도 일정 부분 성능 개선을 이루었다는 점에서 고무적이지만, 절대적인 예측력은 아직 현업 적용 수준에 미치지 못한다고 할 수 있다.

3.2. 통계적 검증 및 로그 포렌식 (Statistical Verification & Log Forensics)

Phase 8의 실험 로그를 심층 분석한 결과, 데이터 분포 및 모델 거동에 관한 중요한 통계적 사실들이 도출되었다. 첫째, 패스 간 분포 차이가 매우 크고 유의미하다는 점이 재확인되었다. [Δ-분석]에 따르면, E2X 파이프라인의 경우 패스 간 워핑 지수 분포의 표준편차 비율(std_max/min)이 1.775에 달했다[17]. 또한 Kruskal-Wallis 검정 p-value = 1.28e-74로 나타나 유의수준 0.05를 훨씬 밑돌았다[17]. 이는 "적어도 한 개 이상의 패스 분포가 다른 패스들과 통계적으로 유의하게 다르다"는 귀무가설을 기각하며, 개별 패스별로 출력 값 분포가 이질적임을 강력하게 시사한다. 같은 로그에서 X2E 파이프라인에 대해서도 std_max/min=2.181, p=2.30e-09로 나타나[24], 비록 E2X보다는 차이가 덜하지만 여전히 분포 변화가 통계적으로 유의함을 확인했다. 이러한 결과는 Phase 8에서 모델이 겪은 어려움의 근본 원인을 보여준다. 즉, 후반 패스일수록 워핑 지수 편차가 감소하고, 초반 패스일수록 편차가 크며 중앙값도 음의 방향으로 치우치는 경향이 있다[25][26]. 모델 입장에서는 훈련(Pass 1~6 등)에서 학습한 패턴이 테스트(Pass 7~8 등)에서 맞지 않게 되는 Distribution Shift 문제에 직면한 것이다.

이러한 분포 변동은 모델 성능의 불안정성으로 직결되었다. 실제로 앞서 분석한 바와 같이, Δ-타깃 등 시계열 트렌드 보정 기법을 도입하지 않은 기본 교차 모델의 경우 Strict Roll-forward 환경에서 음수 R²까지 발생했다[14]. 예컨대, Phase 8 중간 실험에서 Test R² -0.13이 기록된 경우, 상세 로그를 살펴보면 특정 후반 패스에서 예측값이 전혀 변하지 않거나 극단적으로 치우치는 현상이 발견되었다. 이는 모델이 초기 패스 데이터의 영향을 강하게 받아, 분포가 다른 후반 패스에서는 제대로 대응하지 못해 발생한 문제로 풀이된다. 더욱이 롤포워드 전체 R²가 -10 이상으로 크게 음봉을 그린 것은[27], 한두 개 패스의 예측 실패가 연쇄적으로 다음 패스의 입력 오류를 야기하여 누적 오차가 폭증한 결과이다. 이런 현상은 분포 교정(Detrending)의 중요성을 극명하게 보여주며, Phase 9에서 시계열적 데이터 전처리 기법을 보다 면밀히 적용해야 할 필요성을 대두시켰다.

Phase 8의 로그에서 또 하나 주목할 부분은 모델의 견고성(Robustness)에 대한 지표인 Permutation Test와 Roll-forward R²의 관계이다. 앞서 2.2절에서 permuted R²가 0에 가까움을 확인했는데, 이는 데이터 누수는 없지만 모델이 학습한 패턴이 본질적으로 약하다는 의미이기도 하다. 다시 말해, 랜덤 타깃에 대해서는 성능이 0으로 떨어지지만, 실제 타깃에 대해서도 성능이 0.3 수준에 불과하므로 Signal-to-Noise 비율이 낮다고 해석할 수 있다. 이는 여전히 모델이 추출해낸 피처와 타깃 간 상관성이 제한적임을 보여준다. 한편, Strict Test-only Roll-forward R²는 Phase 8 최종 실험에서 약 0.316으로 산출되었다. 이는 일반적인 평균 Test R²(0.3354)와 유사한 수준으로[28][29], 모델이 훈련에 사용되지 않은 새로운 판들에 대해서도 (비록 낮지만) 일관된 예측 성능을 유지함을 의미한다. 만약 Strict Roll-forward R²가 크게 떨어졌다면 모델이 훈련 판에 특화되었음을 의심해야 하나, 다행히 0.316 vs 0.335로 큰 차이는 없었다. 이 결과는 Phase 8의 교차 모델이 시계열 롤아웃 상황에서도 성능 저하 없이 작동했음을 검증해준다. 요약하면, Phase 8 모델은 분포 변화로 인한 절대 성능 한계를 보였으나, 평가 방법을 엄격하게 해도 성능이 유지될 만큼 누수나 과적합 없이 안정적으로 구축되었다고 할 수 있다.

3.3. 모델 강건성 및 잔차 분석 (Robustness & Residual Analysis)

Phase 8에서는 잔차 분석을 통한 모델 개선 시사점도 도출되었다. 비록 본 Phase에서 잔차를 활용한 2단계 모델링까지 진행되지는 않았으나, 교차 예측 결과를 통해 체계적인 잔차 패턴이 관찰되었다. 예컨대 E2X 예측의 경우 초기 패스(1→2)의 잔차 평균이 -29.217로 큰 음의 편향을 보인 반면, 후기 패스(5→6)는 -6.840으로 편차 폭이 줄어드는 양상을 보였다[25]. 이는 모델이 초기 패스에서는 시스템적인 과대예측(실제보다 높게 예측)을 하고, 후반부로 갈수록 오차가 줄어듦을 의미한다. 마찬가지로 X2E 모델에서도 일부 패스쌍(8→9 등)에서 +19.395의 양의 잔차 편향이 나타나, 특정 구간에서는 일관되게 과소예측(실제보다 낮게 예측)하고 있음을 보여주었다[30]. 이러한 패턴화된 잔차는 추후 잔차 보정 모델의 여지를 제시한다. 즉, 1단계 교차 모델의 예측 오차를 다시 학습하는 2단계 메타 모델(Residual Learner)을 도입하면 잔차의 편향을 상쇄시켜 전체 성능을 높일 수 있을 것으로 기대된다. 현재 잔차들의 분포가 각 패스별로 체계적인 방향성을 띄고 있기 때문에, Phase 9에서는 이를 활용한 앙상블 혹은 스태킹 전략이 성능 향상에 기여할 수 있을 것이다.

또한 Phase 8에서는 모델 예측의 시간적 일관성도 확인하였다. 롤포워드 예측 결과를 시간 순으로 살펴본 결과, 대부분의 판에 대해 예측 곡선이 실제 추세를 따라가는 경향을 보였다. 다만 절대치 오차는 누적되는 특성이 있었는데, 이는 앞서 언급한 잔차 편향과 연관되어 있다. 이러한 관찰은 예측값 보정(Post-hoc Calibration)의 필요성을 시사한다. 예를 들어 롤링 윈도우 평균을 활용하여 예측 시계열의 단기 변동을 완화하거나, 예측 오프셋(offset)을 판별로 교정하는 기법 등을 고려할 수 있다. 요컨대 Phase 8의 교차 예측 모델은 일반화 측면에서 기본적인 안정성은 확보하였으나, 잔차 개선과 시계열적 보정 여지가 존재함을 데이터 분석을 통해 알 수 있었다.

4. 결론 및 향후 계획 (Conclusion)

4.1. 종합 평가 (Comprehensive Assessment)

Phase 8은 교차 예측 프레임워크를 재도입함으로써, 데이터 누수 제거 이후 바닥까지 떨어졌던 모델 성능을 다시 끌어올렸다는 점에서 의의가 큰 단계였다. 비록 평균 Test R² 0.33이라는 수치 자체는 높지 않지만, 이는 이전 Phase의 음수 수준 대비 유의미한 향상으로서 일반화 성능 정상화라는 목표를 달성했다. 특히 엄격 검증 환경 하에서도 모델이 안정적으로 작동하여, 성능 지표의 거품을 걷어내고 신뢰할 수 있는 베이스라인을 확립했다는 점은 긍정적으로 평가된다. 반면 절대적인 예측력 측면에서는 여전히 개선이 필요하다. 두 모델 모두 훈련 데이터에 과적합된 모습을 보였고, 분포 차이에 기인한 구조적 한계로 인해 Test R²가 0.3대에 머물렀다. 따라서 Phase 8은 “교차 예측을 도입하면 어느 정도 효과는 있으나, 현 상태의 모델로는 아직 충분치 않다”는 현실을 확인한 단계로 평가할 수 있다. 수치적 향상과 함께 한계를 분명히 인지했다는 점에서, Phase 8은 다음 단계로 가기 위한 교두보를 마련한 셈이다.

4.2. 핵심 시사점 (Key Takeaways)

패스 간 연속성의 중요성: 단일 패스 정보만으로는 모델이 안정적인 패턴을 찾기 어려웠으나, 교차 예측 도입을 통해 인접 패스의 인과 관계를 활용하면 성능을 개선할 수 있음을 확인했다.

분포 변화의 영향: 시계열적인 분포 이동이 모델 일반화에 큰 장애 요인으로 작용함을 재확인했다. 분포 차이를 보정하지 않으면 롤포워드 누적 오차가 폭증하고 예측력이 음수로 전락할 수 있다는 점을 실제 실험으로 입증했다.

누수 차단의 성과: 엄격한 코드 감사와 누수 차단 로직 도입을 통해 데이터 누수를 효과적으로 방어할 수 있었다. Permutation 테스트 등 통계 기법을 활용한 사전 검증 체계는 지속적으로 모델 신뢰성을 담보해주는 수단으로 유용했다.

4.3. 향후 연구 방향 (Future Roadmap)

Phase 8을 통해 확보된 교차 예측 베이스라인을 바탕으로, 다음 Phase에서는 모델의 분포 적응력 강화와 잔차 보완에 초점을 둘 예정이다. 구체적으로, 데이터 분포 정규화(Detrending) 전략을 정교하게 재도입하여 패스 간 차이를 줄이는 방안을 모색한다. 예를 들어, 현재 단순 Δ-타깃 접근 대신 초기 상태 대비 상대지표 등을 활용해 판별 동향을 제거하는 방법이 검토되고 있다. 또한 Phase 8에서 시도되었던 Heteroscedastic 가중치 부여와 Monotonic 제약도 개별 효과를 면밀히 분석한 후, 모델 복잡도를 크게 높이지 않는 선에서 통합할 계획이다. 나아가, 앙상블 및 스태킹 기법을 통한 잔차 보정도 추진된다. 1단계 교차 모델의 예측 결과를 입력으로 받아 2단계 잔차 예측 모델을 학습시킴으로써, Phase 8에서 관찰된 체계적 오차 패턴을 상쇄할 예정이다. 이를 통해 최종적으로는 Test R² 0.33 수준에 머물렀던 성능을 다시 한 번 도약시켜, Phase 9에서는 실사용 가능성에 한 발 더 다가선 모델을 구현하는 것이 목표이다.
