# phase-6

개요 및 연구 배경

Phase 5에서는 기존 판(t) → 판(t+1) 예측 모델에서 라벨 누수(leakage) 문제로 인해 비정상적으로 높은 결정계수(R²)가 관찰되었으며, 모델의 검증 지표가 신뢰할 수 없다는 결론에 이르렀다. 특히 전체 데이터를 한 번에 학습하거나 미래 시점 정보를 포함하는 등의 누수 패턴이 존재하여, 훈련/검증 분리를 제대로 하지 못한 상태에서 모델 성능을 과대평가하고 있었다[1]. Phase 6의 목표는 이전 단계에서 확인된 6가지 누수 패턴(A~F)을 철저히 감사 및 수정하고, 교차 모듈(V2) 기법을 도입하여 모델의 일반화 성능을 개선하는 것이다. 이를 위해 Phase 6에서는 각 누수 유형에 대응하는 코드 수정과 재실험을 수행하였으며, 수정 전후의 R² 변화, 퍼뮤테이션 검정 결과 및 통계 분석을 통해 누수가 제거되었음을 확인하고자 한다. Phase 5에서 확립된 기반 위에, Phase 6는 데이터 분할(anchor split) 고정, 교차-특징 누수 차단, OOF(Out-Of-Fold) 방식 특성 생성, 단조 제약 및 이분산 처리 등 기술적 대책을 도입하였다. Phase 7에서는 이러한 개선 효과를 활용하여 다모듈 V2 전략을 본격화하고 잔여 과제를 다룰 예정이다.

상세 기술적 구현 및 감사 결과

Phase 6에서는 누수 패턴 A부터 F까지 각각에 대응하는 감사 프로토콜을 적용하였다. 각 패턴의 정의와 Phase 6 코드 상의 수정 사항은 다음과 같다:

패턴 A – 학습/검증 미분리(Fit-on-Full) 누수: 학습 시 전체 데이터(검증 포함)를 사용하거나, 교차검증 시 검증 데이터를 미리 참조하여 모델을 최종 학습하는 유형의 누수이다. Phase 6 이전 코드에서는 데이터 분할이 불완전하여 앵커 스플릿 이전에 특징 생성이나 모델 선택이 전체 데이터에 대해 이뤄지는 문제가 있었다. Phase 6에서는 이를 해결하기 위해 plate-group 기반 앵커 스플릿을 도입하였다. scripts/084_test.py에서는 GroupShuffleSplit으로 판 번호 그룹 단위로 데이터를 훈련/테스트로 한 번 무작위 분할하고, 해당 분할 결과(테스트 판 목록)를 파일로 저장하여 이후 재실행 시에도 동일한 분할을 사용한다[2][3]. 이렇게 함으로써 임의의 재실행에도 동일한 판이 테스트에 머물러 학습과 검증의 경계가 고정되고, 전체 데이터를 잘못 학습하는 경우를 방지하였다. 또한, 모든 특징 생성과 선택이 훈련 세트에 한정되도록 구현하였다. 예를 들어, 상관 기반 특징 선택(select_kbest_by_corr)은 훈련 데이터의 분산과 상관계수만을 활용하고, 테스트 세트에는 선택된 컬럼만 적용하도록 설계되었다[4][5]. 그 결과 Phase 6의 085~088 실험까지 평균 Test R²는 약 0.23 수준으로 정상화되었고, 학습 데이터에 과적합되었던 084번 실험의 0.9142에 달하던 비정상치가 사라졌다[1][6]. 이는 패턴 A의 누수가 해소되어 검증 데이터에 대한 과대평가가 제거되었음을 의미한다.

패턴 B – 시계열 그룹 불균질(KFold-TS) 누수: 이는 판의 시간적 순서나 그룹 특성을 무시한 교차검증으로 인한 누수를 말한다. Phase 5에서는 GroupKFold를 사용하면서도 실질적으로 미래 판의 정보를 과거 판 모델에 누적시키는 문제가 있었다. Phase 6 코드에서는 GroupKFold(판 번호 그룹)와 GroupShuffleSplit(판 그룹 단위 분할)을 엄격히 활용하여, 동일 판의 데이터가 훈련과 테스트에 겹치지 않도록 했다[1]. 특히 교차특징 생성 시에도 OOF 전략으로 그룹 누수를 차단하였다. 예를 들어 Pair Δ-Target Encoding 특성(pair_delta_te) 생성 과정에서, 판 그룹별 교차검증을 수행하여 훈련 내에서 OOF로 평균값을 얻고, 최종 테스트에는 전체 훈련 세트의 통계만 사용하도록 구현했다[7][8]. 이를 통해 각 판 그룹의 평균 변형(te) 값이 해당 그룹의 검증샘플에 누출되지 않도록 하였다. 이러한 조치로 같은 판 번호의 데이터가 교차검증 폴드 사이에 섞이는 현상이 제거되어 패턴 B 누수가 해결되었다. 그 결과 Phase 6의 실험들에서 검증 R² 분포의 이상치나 높은 분산이 크게 완화되었다.

패턴 C – 잘못된 라벨 시프트(Negative-Shift) 누수: t+1 목표값 생성 과정에서 인덱스 정렬 오류로 잘못된 라벨이 입력 특성에 섞이는 누수를 의미한다. 이전 코드에서는 df.shift(-1)을 사용할 때 판 경계를 고려하지 않거나 불연속적인 Pass 간의 관계를 간과하여, 다른 판 혹은 건너뛴 pass의 값이 타겟으로 잘못 결합되는 문제가 있었다. Phase 6에서는 load_and_merge_tplus1()에서 판 별로 groupby하여 shift(-1)를 수행함으로써 각 판 내부에서만 다음 pass의 Warping Index를 타겟으로 설정했다[9]. 또한 불연속적인 Pass (예: 1→3으로 건너뛰는 경우)를 검출하기 위해, 다음 Pass 번호(_next_pass)가 현재 Pass+1이 아닌 경우 해당 행의 타겟을 NaN으로 취급하여 삭제하였다[9]. 이렇게 t와 t+1 간 인덱스가 어긋난 샘플을 제거함으로써, 잘못된 짝짓기로 인한 라벨 누출을 방지하였다. 그 결과 084 실험에서 문제가 되었던 잘못 매칭된 t+1 라벨이 085 실험부터는 완전히 제거되어, 훈련 샘플 수가 일부 감소하였으나(누수 데이터 삭제) 모델의 일관성이 향상되었다고 로그에서 확인된다 (t→t+1 행 개수 감소)[10]. 패턴 C 수정 이후, Permutation 기반 감사에서도 명백한 누수 징후가 제거되어, 089 실험의 퍼뮤테이션 테스트 R²가 -1.3263 ~ -0.9561로 0에 가까운 값(오히려 음수, 오차범위 내)임을 확인하였다[11].

패턴 D – 훈련-검증 교차 특성 누수: 훈련 전용 통계를 검증에 활용하거나, 검증 데이터를 통해 산출된 정보를 특성에 포함하는 누수를 뜻한다. 대표적으로 Target Encoding이나 과거 이력 통계를 훈련+검증 전체로 계산하여 검증에 누출하는 실수가 이에 해당한다. Phase 6에서는 이러한 패턴 D를 차단하기 위해 모든 통계 특성은 훈련 세트로부터만 계산되도록 했다. 앞서 언급한 Pair Δ-TE는 OOF로 구현되었고, RM(train-only) 특성의 경우 별도 함수 attach_train_only_rm_stats()를 통해 검증에 없는 판의 이전 공정 통계는 NaN으로 두고, 훈련 세트에서만 판별 통계를 계산하여 병합하도록 변경했다[12][13]. 구체적으로 posco1 공정 데이터에서 훈련 판들에 대해서만 판별 평균, 최댓값, 표준편차 등을 구해 훈련 데이터프레임에 붙이고, 동일 통계를 테스트에도 병합하되 테스트에 존재하지 않는 판은 NaN으로 남긴 후 중앙값으로 대치하였다[14]. 이를 통해 테스트 세트의 RM 특성 값은 훈련 통계에 기반한 추정치로만 채워지며, 테스트 자체의 정보가 유입되지 않는다. Phase 6의 085 실험부터 모든 통계 기반 추가 특성은 이러한 Train-only 원칙 하에 생성되었음을 Flag RM=1 설정으로 확인할 수 있었다. 그 결과 검증 R²의 신뢰도가 향상되었고, permutation R²에도 큰 영향 없이 0 주변의 값을 유지하였다.

패턴 E – 교차 참조 누수(Cross-Reference Leak): 이는 이중 모듈(E→X, X→E) 간에 정답 정보를 교환하여 생기는 누수를 말한다. Phase 5까지는 Entry→Exit(E2X) 모델과 Exit→Entry(X2E) 모델을 각각 훈련하였으나, 롤포워드(Roll-forward) 예측을 할 때 두 모듈 간 실제 값을 교차 사용하면서 누수가 발생했다. 예를 들어 이전에는 E2X 예측 후 실제 관측된 Exit 값을 X2E의 다음 입력으로 사용하는 방식으로 다단계 예측을 평가하여, 모듈 간 피드백에 실제 값이 섞이는 문제가 있었다. 그 결과 Phase 5의 롤포워드 R²가 비정상적으로 높게 나타났는데(084 요약의 Rollforward R² = 0.5695[15]), 이는 일부 실제값이 포함된 교차 참조로 인한 낙관적 평가였다. Phase 6에서는 089 실험부터 V2 크로스 모듈 개념을 도입하여, Strict Test-only Rollforward 평가를 실시하였다. 두 모듈을 교대로 사용하여 여러 pass를 예측할 때 모든 단계에서 이전 단계의 예측값만을 다음 입력으로 사용하도록 시뮬레이션하여 엄격한 테스트 기준을 적용했다. 그 결과 089_V2 실험에서 Strict 롤포워드 R²는 0.3389로 낮아졌고[11], Phase 5에서 교차 누수로 부풀려졌던 0.57 수준의 값이 정상화되었다. 이는 교차 참조 누수를 제거한 평가로, E2X와 X2E 모듈이 완전히 독립적으로 작동함을 의미한다. 이후 091 실험에서는 두 모듈 모두 개선된 모델로 재학습하여 Strict 롤포워드 R²가 0.4264까지 상승하였는데[16], 이 값은 누수가 제거된 상태에서 두 모듈의 성능이 향상되었음을 보여준다. 요약하면, Phase 6 초반(084~088)까지는 패턴 E로 인해 롤포워드 평가가 왜곡되었으나 089부터 바로잡혀, Phase 7에서의 다단계 예측 평가가 신뢰할 수 있는 기반 위에 놓이게 되었다.

패턴 F – 잔존 누수 및 검증 한계: 마지막으로 패턴 F는 위의 조치들을 모두 취한 후에도 남아있는 미세한 누수 징후를 가리킨다. Phase 6의 최종 실험(091)에서는 대부분의 누수가 제거되고 평균 Test R²도 안정적으로 상승했지만, 퍼뮤테이션 기반 진단에서 약간의 상관이 남는 현상이 관찰되었다. 091 실험의 Quick Permutation R²은 E2X의 경우 0.2927, X2E는 0.2274로 0보다 유의미하게 크다[17]. 이는 완전 무작위 라벨에도 모델이 일정 수준의 예측 상관을 보였음을 뜻하며, 이상적으로는 0에 가까워야 한다. 이러한 잔존 상관의 원인은 완벽히 제거하기 어려운 데이터 구조 혹은 미세한 정보 누출 가능성이다. 예를 들어 판 고유 특성이나 공정 변수 분포가 타겟과 연관되어 모델이 무작위 라벨에도 일부 패턴을 학습한 경우가 있다. Phase 6에서는 이를 인지하고, Permutation 테스트를 자동화하여 매 실험마다 로그에 출력함으로써[18][19] 미세 누수를 지속 감시하도록 했다. 또한, 091 실험에서 관찰된 Permutation R² ≈0.25 수준은 앞선 089 실험의 ~0 수준에 비해 높으므로, Phase 7에서는 해당 원인을 추가 분석(예: 특정 특성의 영향력 점검 등)하여 남은 누수 요소를 식별할 계획이다.

以上의 감사 결과, Phase 6에서는 코드 전반에 걸쳐 누수 방지를 위한 리팩토링과 추가 검증이 이루어졌다. 특히 _hard_leak_guard 함수를 통해 컬럼명에 target, pred, oof 등의 문자열이 포함된 경우 자동으로 제외시켜 데이터 컬럼 단위의 하드 누수 가드를 적용하였고[20], Feature Engineering 단계에서 수치형 이외의 컬럼 제거 및 중앙값 대치 등을 일괄 적용하여 데이터 누수를 원천 차단하였다[21]. 이러한 기술적 구현을 통해 Phase 6의 각 스크립트(084~091)는 모두 누수 패턴 A~F에 대응하는 수정을 포함하게 되었다. 예를 들어, 084_test.py에서는 패턴 E 문제가 발견되었으나 085_experiment.py에서 Anchor split 재설계로 이를 수정하였고, 089_experiment.py(V2)에서는 패턴 E 완전 제거와 함께 XGBoost 기반 모듈 재구축을 수행하였다. 각각의 변경 사항은 실험별 요약 파일(summaries/)에 상세히 기록되었으며, Issue 코드로 관리되었다[22].

실험 결과 및 데이터 분석

Phase 6의 누수 제거 및 개선 기법 도입 효과는 평가 지표의 정상화와 향상 추이로 나타난다. 먼저 라벨 누수 제거의 효과를 살펴보면, Phase 5 말기의 084번 실험에서 평균 Test R²=0.9142로 비정상적으로 높았던 값이, Phase 6 초기 085~088 실험에서는 0.2313 수준으로 급락하고 안정화되었다[6]. 이는 앞서 설명한 누수 패턴 A~D 수정으로 과대평가가 해소된 결과이다. 084→085 단계에서 Test R² 감소 폭이 약 75%p에 달하는데, 이는 검증 데이터가 모델 학습에 유출되었던 부분이 완전히 제거되었음을 의미한다. 한편 Train R²의 경우 084 실험에서는 훈련에 누적된 누수로 인해 과도하게 높았으나, 085 실험부터는 E2X 약 0.66, X2E 0.62로 합리적인 수준으로 유지되었다[23]. 이는 모델이 훈련 세트 내에서 과적합되지 않고 현실적인 설명력을 갖추었음을 보여준다.

Phase 6 후반부에서는 교차모듈 V2 도입과 성능 개선에 주력하여, Test R²가 다시 소폭 상승하는 추이를 보였다. 089_V2 실험에서는 새로운 알고리즘(XGBoost)과 엄격한 평가로 평균 Test R²=0.2098로 다소 하락했으나[24], 이는 누수 제거에 따른 일시적 감소로 해석된다. 이후 090~091 실험을 통해 모델 개선 기법(Delta Target, Hetero-Weight, Monotonic Constraint 등)을 적용한 결과, 최종 091번 실험에서 평균 Test R²=0.2576으로 향상되었다[25]. 특히 091 실험은 두 방향 모두 XGBoost를 사용하고, USE_DELTA_TARGET=1, USE_PAIR_TE=1, USE_HETERO_W=1, USE_MONO_CUR=1 등의 설정을 활성화한 구성으로서, Phase 6에서 가장 정교한 모델에 해당한다. 이 모델은 동일 데이터에 대해 Phase 5 대비 누수 없이도 높은 예측 성능을 회복했다는 점에서 의미가 크다. 구체적으로 XGBoost 도입과 함께 단조 제약(MONO)을 Current Warp 특성에 부여하여[26][27], 물리적으로 누적되는 변형량이 일방향으로 작용한다는 도메인 지식을 반영하였다. 또 Δ-Target 기법(DT)을 통해 타겟 스케일을 줄여 모델이 변형량의 증분을 예측하도록 함으로써, 091 실험의 E2X/X2E Train R²가 각각 0.75/0.79 수준으로 낮아져 과적합을 방지하고 Test R²를 높이는 효과가 있었다[28]. Pair Δ-TE 특성(TE)과 이분산 가중치(W) 적용도 성능에 기여하였다: 091 모델은 가중치 적용으로 중심데이터에 대해 더 정확히 학습하고, TE 특성을 통해 각 연속 Pass 쌍의 평균적 변형 경향을 포착하여 추가적인 설명력을 얻었다. 이러한 개선으로 091 실험에서는 X2E 방향의 Test R²가 0.2615까지 올라 초기 대비 약 1.7배 향상되었고[28], E2X 방향도 0.2537로 크게 증가하였다.

통계적 유의성 검증도 Phase 6의 중요한 분석 요소이다. 우선 Permutation Test를 통해 누수 제거 효과를 계량화하였는데, 084 실험에서는 Permutation을 실시하지 않았던 것에 반해 089 실험부터 결과 요약에 그 수치를 포함시켰다. 089_V2 실험의 Quick Permute R²는 E2X -1.3263, X2E -0.9561로 0에 매우 가까운 (약간 음수) 값을 보여주었다[29]. 이는 라벨과 특성 간 무작위 재배치 시 모델 예측력이 0에 수렴함을 의미하며, 모델이 아무런 누수된 신호를 학습하지 않았음을 검증해준다. 반면 091 실험의 Permute R²가 0.2~0.3대로 상승한 부분은 앞서 논한 패턴 F (잔존 누수 가능성)을 시사하지만, Phase 5 당시 084 실험의 상황과 비교하면 여전히 현격히 낮은 수치다 (참고로 084 실험의 Test R² 0.91 중 상당 부분이 누수로 인한 것이었음을 상기할 때, 091의 0.25는 무작위 라벨에 대한 모델 출력 상관도가 낮은 편이다). 추가적으로, Kruskal-Wallis 검정과 Levene 등분산 검정을 통해 Δ-분포의 이질성을 확인하였다. 모든 Phase 6 실험 요약에는 E2X와 X2E 각각에 대해 각 연속 Pass 쌍별 Warping 증분(Δ)의 표준편차 분포를 분석한 결과가 포함된다. 예를 들어 085 실험에서 E2X 방향의 Δ값 최대/최소 표준편차 비는 1.775이고, 대응하는 Kruskal p-value는 1.28×10^-74로 유의수준 0.001보다 훨씬 작았다[30]. 이는 Pass 쌍에 따라 Warping 증가분의 분산이 통계적으로 유의하게 다르다는 것을 나타낸다. X2E도 std_max/min=2.181, p=2.30×10^-9로 비슷한 경향을 보인다[31]. 이러한 유의미한 분산 차이는 이분산 가중치(W) 적용의 타당성을 뒷받침한다. 실제로 Phase 6 모델들은 Δ 분산이 큰 쌍에 대해서는 가중치를 낮춰 학습함으로써, 균일 가정 하에서 놓쳤을 불균일성을 보정하였다. 마지막으로 [베스트] 항목을 보면, 실험 2 (Phase 1의 초기 모델 추정치) 대비 Phase 6 말기의 평균 Test R² 향상이 부각된다 (0.4174 대비 0.2576 수준)[25][32]. 비록 절대적인 수치는 낮아졌지만 이는 누수 제거에 따른 건전한 감소이며, Phase 7에서 추가 개선의 여지가 있는 출발점으로 해석된다.

결론 및 향후 계획

Phase 6에서는 Phase 5에서 드러난 다양한 형태의 데이터 누수 문제를 전면적으로 재점검하고 수정함으로써, 신뢰할 수 있는 교차 예측 모델링 기반을 구축하였다. 요약하면, 누수 패턴 A~F (학습/검증 분리 실패, 시계열 교차검증 오류, 잘못된 라벨 시프트, 교차특성 누출, 모듈 교차 참조 누수, 잔존 미세 누수)에 대응하여 데이터 처리 파이프라인과 모델 학습 과정 전반을 개선하였다. 주요 성과로는 검증 성능 지표의 정상화(평균 R² 0.91 → 0.23)와 모델의 실제 일반화 능력 회복, 그리고 V2 크로스 모듈 프레임워크의 도입을 들 수 있다. 특히 V2에서는 Entry/Exit 이중 모듈 간의 정보흐름을 엄격히 통제하여, Phase 7에서 다단계 예측을 사용할 수 있는 모델 파이프라인의 모듈화를 완성하였다. 또한 Phase 6에서 새롭게 추가된 플래그 설정(DT, TE, W, MONO, RM)들은 각 개선 요소를 모듈화하여 실험적으로 검증할 수 있게 해주었고, 필요에 따라 쉽게 켜고 끌 수 있는 형태로 구현되었다[33][34]. 이를 통해 Phase 7에서는 여러 조합의 전략(예: Δ-Target+Hetero-Weight 동시 적용 등)을 탐색하고 최적 조합을 찾아낼 수 있는 유연성이 확보되었다.

향후 Phase 7에서는 Phase 6에서 구축된 누수 없는 안정적인 환경을 바탕으로, 남아있는 성능 향상 과제를 추진할 예정이다. 구체적으로는 잔류 Permutation 상관의 원인 분석(패턴 F 보완)과 교차모듈 V2의 성능 극대화가 핵심 과제가 된다. 예를 들어, Phase 6에서 도입된 Monotonic Constraints, Pair Δ-TE 등의 기법을 최적화하고, 필요시 모델 앙상블이나 Feature augmentation을 적용하여 성능을 끌어올릴 계획이다. 또한 Phase 7에서는 멀티페스(multi-pass) 롤포워드 예측 시나리오를 확장하여, Phase 6에서 확보한 Strict 롤포워드 평가 지표를 다양한 조건에서 시험함으로써 모델의 실제 공정 활용 가능성을 평가할 것이다. 결론적으로, Phase 6는 데이터 누수를 제거하고 모델링 기법을 고도화한 단계로서, 신뢰성 있는 성능지표 확보와 향상된 예측력의 토대를 마련하였다. 이 토대를 딛고 Phase 7에서는 보다 공격적인 모델 개선과 현장 적용을 향한 준비에 착수하게 될 것이다.
