# phase 7

[Phase 7] : 딥러닝 기반 모델 아키텍처 도입 실험 및 검증

1. 개요 및 연구 배경
Phase 6까지 여러 전통적 ML 모델(랜덤포레스트, XGBoost 등) 앙상블로 성능 향상을 도모했으나 Test R² 향상이 한계에 도달하였다. 이에 따라 연구팀은 심층 학습 모델(RNN 계열)을 재도입하여 시계열 패턴 학습을 시도하였다. 특히 Plate당 순차적 특성을 포착하기 위해 LSTM과 1D-CNN과 같은 딥러닝 아키텍처를 도입하고, 기존 트리 기반 모델과의 성능 격차를 검증하는 실험을 설계하였다. 이 과정에서 동일한 데이터 조건에서 기존 모델 대비 신규 모델의 효과를 정량 비교하기 위해, 하나의 실험에 두 가지 러너(기존 vs 딥러닝)를 병행 실행하는 “No-Op 대조 프레임워크”를 구축하였다.

2. 기술적 구현 및 감사 결과
 딥러닝 모듈 통합: Phase 7의 실험 코드(099_test_no_op.py 등)를 분석한 결과, PyTorch 기반 LSTM 회귀 모델이 새로 추가되었다. 예를 들어, 코드에는 import torch, torch.nn as nn 구문과 함께 class LSTMRegressor(nn.Module): ... 정의, 배치 학습 루프 및 DataLoader 활용 등이 명시되어 있었다. 이를 통해 기존 XGBoost/RandomForest 대신 시계열 RNN 모델을 학습시키는 경로가 도입되었음을 확인할 수 있다.
 No-Op 비교 구조: Phase 7 코드에는 --no_op라는 인자(flag)를 통해 신규 딥러닝 모형의 사용 여부를 제어하는 로직이 구현되었다. 예를 들어, if args.no_op: ... 기존모델 실행 ... else: ... LSTM모델 실행 ... 형태로 분기하여, 하나의 스크립트로 두 가지 모델의 결과를 모두 산출하도록 구성되었다. 그 결과 각 실험 ID마다 _no_op_summary.txt(기존모델 성능)와 _test_summary.txt(신규모델 성능) 두 개의 요약 파일이 생성되어 동일 조건하에 모델 성능을 직접 비교할 수 있었다.
 데이터 누수 점검: Phase 7의 코드에 대한 포렌식 감사 결과, 중대한 데이터 누수 패턴은 새로 발생하지 않은 것으로 평가되었다. 이전 Phase에서 문제가 되었던 Label Leak (Pattern A)의 경우, 본 Phase의 모든 특징 생성 단계에서 타깃 컬럼(_target)을 명시적으로 제외하여 모델 입력에 포함하지 않는 것으로 확인되었다. 또한 통계량 산출이나 정규화 단계에서도 훈련 데이터 기준으로만 평균·분산을 계산하고 Test 세트 분포를 참조하지 않도록 설계되어 Transductive Leak (Pattern C) 위험을 최소화하였다. 실제로 코드 주석에는 “train/test 분할 이후에만 모든 통계/정규화 계산 수행”이라는 지침이 포함되어 있고, 중요도 가중 등 잠재적 누수 기능(IW_MODE)은 기본적으로 비활성화 또는 OOF방식으로 설정되었다. 다만 Phase 7 말미의 실험(118_test.py)에서는 SVM 모델 적용 및 전처리 과정에서 일부 전역 스케일링이 사용되어, Pattern C (전반적 통계 누수)* 가능성이 미미하게 발견되었다. 이는 특성 스케일링 시 전체 데이터 분포를 기준으로 한 점을 지적하는 것으로, 영향 범위는 제한적이었으나 감사 관점에서 언급될 만한 사항이다.

3. 실험 결과 및 시사점
 성능 비교: 딥러닝 아키텍처 도입의 효과는 명확히 부정적인 것으로 드러났다. No-Op 대비 실험에서 기존 트리 모델이 일관되게 우수한 성능을 보였다. 예를 들어, 실험 105에서 기존 모델(Test R²≈0.2529)은 LSTM 모델(Test R²≈0.1376)을 크게 상회하였다. 다수의 비교 실험에서 신규 딥러닝 모델의 Test R²는 0.1 내외로 baseline 대비 급격한 저하를 나타냈으며, 극단적인 경우 학습 불안정으로 유의미한 예측 능력을 전혀 보여주지 못하는 상황도 관측되었다.
 분석 및 조치: 성능 저하의 원인을 분석한 결과, 데이터 크기와 시계열 길이가 충분하지 않아 딥러닝 모델이 과적합되는 한편, 복잡한 신경망의 이점이 발휘되지 못한 것으로 판단되었다. 또한 Phase 7 내내 병행된 엄격한 누수 차단 조치로 인해, 딥러닝 모델이라고 해서 이전 Phase의 비정상적 고 R²(>0.9)를 재현할 수 없었고, 오히려 모델의 진짜 실력만 드러난 셈이 되었다. 결국 연구팀은 “현 단계에서는 심층 신경망보다 특성 공학 및 앙상블 강화에 주력한다”는 전략적 판단을 내렸다. Phase 7 후반부터 딥러닝 시도를 공식적으로 철회하고, Phase 8에서는 다시 트리 기반 모델 중심의 개발 방향으로 선회하였다. 이는 복잡한 모형보다 도메인 지식 기반 접근이 본 문제에 적합함을 재확인한 결과로서, 향후에도 데이터 규모가 충분히 확대되지 않는 한 유사한 딥러닝 접근은 신중히 검토하기로 하였다.
