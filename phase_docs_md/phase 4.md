# phase 4

[Phase 4] : 데이터 정규화 단계의 누수 차단 및 성능 저하 현상 분석

1. 개요 및 연구 배경
이전 단계까지 모델 예측 성능이 비정상적으로 높게 나타나는 현상이 관찰되었으며, 이는 데이터 누수로 인한 허수 성능일 가능성이 제기되었다. 연구팀은 특히 데이터 정규화 및 통계 특성 산출 과정에서 검증 데이터 정보가 사전에 활용되었을 가능성에 주목하였다. 실제 코드 감사 결과, StandardScaler를 이용한 스케일링과 압연(Rolling Mill) 통계량 계산시 훈련용 데이터뿐만 아니라 전체 데이터(훈련+검증)를 대상으로 fit하는 오류가 확인되었다. 이는 검증 데이터의 분포 정보가 모델 학습에 누설되는 전형적인 데이터 누수 상황으로, 모델의 검증 성능을 부풀린 원인으로 판단되었다. 본 Phase 4에서는 이러한 정규화 단계의 누수를 차단함으로써 모델 평가의 신뢰성을 확보하고자 하였다.

2. 기술적 구현 및 감사 결과
 정규화 로직 수정: scripts/052_experiment.py에서는 데이터 스케일링과 통계 특성 생성시 전 데이터셋에 대한 fit이 이루어져 누수가 발생하고 있었다. 감사 결과 해당 구현은 Pattern C (Transductive Leak)에 부합하는 결함으로 확인되었다. 이에 연구팀은 후속 버전인 scripts/053_experiment.py에서 플래그 USE_RM_TRAINONLY 값을 0에서 1로 활성화하여 코드를 수정하였다. 그 결과 StandardScaler 및 RM 통계량 산출 시 훈련 데이터에 한해서만 fit을 수행하고, 검증 데이터에는 그 결과를 적용(transform)하도록 조건 분기가 도입되었다. 예를 들어, 수정된 코드에서는 if USE_RM_TRAINONLY: scaler.fit(train_X); scaler.transform(test_X) 형태로 동작하며, Rolling Mill 통계량도 훈련 셋의 판(plate)에 대해서만 그룹 연산하여 산출한 후 양 셋에 매핑하는 방식으로 변경되었다. 이를 통해 기존 코드의 전역 통계치 활용 오류를 제거하여 데이터 누수를 차단하였다.
 데이터 누수 감사 결과: 상기 수정사항 이외의 다른 주요 누수 요인은 본 단계에서 추가로 발견되지 않았다. 모델 입력 피처 구성 시 타깃 컬럼은 이미 제외 처리되어 Pattern A (Label Leak)가 방지되고 있었고, t→t+1 시계열 타깃 생성도 판별(unique plate) 단위로 적절히 shift되어 미래 값 혼입(Sequence Leak) 없이 타깃이 정의되었다. 또한 이상치 제거 등 데이터 필터링은 훈련 데이터 분포 기준으로만 수행되고, 테스트 셋에는 동일 기준을 적용(clip)하는 방식이어서 검증 정보 유출 없이 처리되었다. 코드에는 _hard_leak_guard 함수로 잠재적 누수 컬럼을 일괄 제거하고, quick_perm_leak_r2 함수를 통해 모든 실험에 대해 타깃 무작위 치환 후의 검증 R²를 산출하는 자동 누수 점검절차가 포함되었다. 이러한 자동화된 감사 결과 053 실험부터 모든 permuted R² 값이 0에 수렴하는 것으로 기록되었는데, 이는 수정 후 더 이상 숨겨진 누수가 없음을 뒷받침한다. (딥러닝 기반의 복잡한 모델은 본 Phase에서 도입되지 않았으며, 여전히 RandomForest, XGBoost와 같은 트리 기반 알고리즘을 활용하였다.)

3. 실험 결과 및 시사점
 성능 지표 변화: 정규화 단계 누수 차단 조치 후 모델의 검증 성능은 예상대로 큰 폭으로 하락하였다. 수정 이전 단계에서는 일부 실험에서 비현실적으로 높은 R² (예: 0.9 이상)이 관측되었으나, 누수 제거 직후 실시된 052~053번 실험에서는 평균 Test R²가 -0.08 수준으로 떨어졌다. 구체적으로 053 실험의 경우 RandomForest와 XGBoost 모델 모두 음수의 R²를 기록하여(Train R² 대비 현저한 격차) 모델이 사실상 검증 데이터에 대한 예측력을 상실했음을 보여주었다. 이 같은 급격한 성능 저하는 이전 단계의 고성능이 데이터 누수에 기인한 착시였음을 입증하는 결과로 해석된다. 연구팀은 오히려 이러한 하락을 정상적인 평가 체계로 전환된 긍정 신호로 받아들였으며, 이후 비로소 모델의 실제 실력 수준을 정확히 파악할 수 있게 되었다.
 시사점: Phase 4의 조치를 통해 데이터 정합성을 확보한 결과, 모델은 초기에는 낮은 성능(-0.08 R²)에서 다시 출발하였으나 이는 의도된 효과였다. 이후 동일한 조건에서의 지속적인 모델 개선을 통해 Phase 4 말까지 평균 Test R² 약 0.3 수준까지 성능을 회복하였다. 이는 누수 제거 후에도 추가적인 피처 엔지니어링과 튜닝을 통해 일정 부분 예측력을 끌어올릴 수 있음을 보여준다. 궁극적으로 본 Phase에서는 누수를 완전히 차단하고 평가의 신뢰성을 높였다는 점이 가장 큰 성과로, 과거의 과대평가된 결과를 교정하였다. 연구팀은 이 깨끗해진 평가 환경을 바탕으로 다음 Phase에서 모델의 실질적 성능 향상 전략을 모색함으로써, 진정한 예측력 향상에 집중할 수 있게 되었다.
