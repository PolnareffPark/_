# phase-1

[Phase 1] : 교차 패스 예측 프레임워크 구축 및 1차 성능 검증

1. 개요 및 연구 배경

열연 공정에서 발생하는 워핑 지표(warping index)의 예측 문제는 단일 패스(pass)의 정보만으로는 설명력이 제한적이라는 판단이다. 특히 각 판재(plate)가 여러 패스를 거치는 동안 입측 조건(Entry conditions)과 출측 품질(Exit quality)이 교대로 인과 관계를 형성하며 누적되는 특성이 있다. 초기 파일럿 실험에서 단일 패스의 데이터로만 모델을 학습시킨 결과, Test R²가 약 0.24 수준에 머물렀다[1]. 이는 공정 변동성에 비해 설명력이 부족한 베이스라인으로, 복잡한 패스 간 상호작용을 포착하지 못한 한계로 해석되었다. 연구팀은 이러한 배경 하에 “출측 결과가 다음 패스의 입측 조건을 결정한다”는 도메인 인사이트를 반영한 교차 예측 프레임워크(Entry-Exit Cross Prediction)를 Phase 1의 핵심 전략으로 수립했다.

Phase 1의 가설은 명확하다: 인접한 패스 간의 연속성을 모델에 포함하면 예측 성능이 유의미하게 향상될 것이라는 것이다. 구체적으로, 이전 패스의 출측 워핑 정도가 다음 패스의 워핑에 영향을 준다는 물리 법칙을 모델링하기 위해, 하나의 통합 모델 대신 두 개의 하위 모델(Entry→Exit, Exit→Entry 경로)을 구축한다는 접근이다. 이를 통해 각 모델이 상반된 전개 방향의 패턴을 전문적으로 학습하도록 유도하였다. 성공 기준은 평균 Test R²의 향상이며, Phase 1을 통해 데이터 전처리부터 모델링까지 교차 예측에 최적화된 파이프라인을 정립하고, 향후 Phase에서 사용할 신뢰도 있는 기준선(Baseline)을 확보하는 것을 목표로 했다.

2. 상세 기술적 구현 및 감사 결과

2.1. 주요 코드 변경 사항 및 구조적 진화

Phase 1에서는 초기 데이터 처리 및 모델링 코드가 대폭 리팩토링되어 교차 패스 예측에 특화된 구조로 진화했다. 우선, 타깃 변수 생성 방식이 시계열 문맥을 고려하도록 수정되었다. scripts/001_pass_t_plus_2_pipeline.py에서는 동일 판재 내 연속 패스 간 관계를 직접 다루지 않았으나, scripts/002_experiment.py부터는 다음 패스의 워핑 지표를 예측 목표로 삼았다. 코드 구현상 merged_fm.groupby(PLATE_COL)["warping_index"].shift(-1) 연산을 통해 현재 패스의 워핑 지표를 한 단계 쉬프트하여 _target 컬럼을 생성하고, 이후 존재하지 않는 미래 값(NaN)은 제거하였다[2]. 이 과정을 통해 각 행의 타깃이 해당 판재의 다음 패스 실제 워핑 값이 되도록 정합성을 확보했다. 그 결과 최종 학습 데이터(final_df)에는 각 패스의 입력 특성(warping_index_current_pass 등)과 다음 패스 출력(warping_index_target)이 짝지어진 형태로 저장되었다.

다음으로, 교차 전이 세트 분리 로직이 도입되었다. 과거에는 입측과 출측 데이터를 구분하지 않고 단일 모델로 처리하려 했으나, Phase 1 구현에서는 split_cross_transitions 함수를 통해 데이터셋을 두 부분으로 분할했다. 구체적으로 패스 번호의 홀수/짝수 구분을 이용하여, 홀수 패스에서는 Entry→Exit 전이(E→X, 현 패스 입측 조건에서 같은 패스의 출측 품질 예측), 짝수 패스에서는 Exit→Entry 전이(X→E, 현 패스 출측 결과로 다음 패스의 입측 상태 예측)로 데이터를 이원화하였다[3]. 이처럼 두 개의 하위 데이터셋(e2x_df, x2e_df)으로 분리함으로써, 하나의 모델이 상충되는 두 방향의 물리적 패턴을 동시에 학습해야 하는 부담을 줄이고 각 전이 방향에 특화된 예측을 가능하게 했다. 분리된 데이터셋 각각에 대해 후속 전처리와 모델 학습이 개별적으로 수행되었다.

피처 엔지니어링 부분도 구조적으로 개선되었다. Phase 1 코드에서는 feature_engineering 함수를 통해 다수의 통계 파생변수가 추가되었다. 예를 들어, 압연 데이터 FM 계열 변수들에 대해 행(row) 단위 평균, 표준편차, 최댓값, 최솟값을 계산하여 FM_mean, FM_std, FM_max, FM_min 컬럼을 생성했고, 범위와 변동계수(FM_range, FM_cv)까지 확장하여 해당 패스의 종합적인 상태를 숫자로 요약했다[4]. 이들은 압연기의 센서 수치들이 워핑에 미치는 총체적 영향력을 한눈에 파악하기 위함으로, 개별 변수 대신 통합 지표를 모델에 제공하여 노이즈를 줄이는 효과를 노렸다. 또한 패스 번호(FM_PASS NO N) 자체도 중요한 시계열 정보로 활용되었다. 코드에서는 패스 번호의 제곱항(FM_PASS_squared)과 정규화된 진행도(FM_PASS_progress = 현재 패스 번호 / 최대 패스 번호)를 피처로 추가하여[5], 해당 패스가 전체 공정에서 초반인지 후반인지 등 위상 정보(Phase position)를 모델이 학습할 수 있도록 설계했다.

2.2. 데이터 누수 및 정합성 포렌식

Phase 1 기간 동안 코드 감사 결과, 명시적인 데이터 누수 경로는 발견되지 않았으나 일부 절차는 개선 여지가 있었다. 학습-평가 분리 준수 여부를 점검한 결과, 데이터 분할은 판재 단위 Group Shuffle 방식으로 이루어져 동일 판재의 레코드가 학습과 테스트에 중복되지 않도록 엄격히 통제되었다[6]. 구체적으로 GroupShuffleSplit.split(X, y, groups)에서 groups 파라미터로 판재 ID(PLATE_COL)를 입력하여, 각 판재별로 전적으로 학습 또는 테스트에만 속하도록 분할하였다. 이 조치로 판재 단위의 누수(같은 판재의 정보를 양분하여 학습에 활용하는 행위)를 원천 차단하였다.

다만 사전 처리 과정에서의 미묘한 정보 누설 가능성이 발견되었다. 이상치 제거 절차에서 Isolation Forest와 이웃 기반 잔차 필터가 전체 데이터셋(학습+테스트)에 대해 일괄 적용된 부분이다. 코드 상 remove_outliers 함수는 수치형 피처들에 대해 IsolationForest(contamination=0.05)로 1차 필터링을 수행하고, 이어서 모든 표본에 대하여 NearestNeighbors로 각 표본의 타깃 값(_target)의 근접 이웃 평균을 산출한 뒤, 해당 표본의 실제 타깃과의 차이(inconsistency)가 상위 5% 이상인 경우 제거하도록 구성되어 있다[7]. 이때 테스트 데이터의 타깃 값도 이 계산에 사용되어 일부 테스트 레코드가 “훈련 전에” 제거되었을 가능성이 존재한다. 이는 모델이 테스트 데이터의 정답 분포를 미리 참조한 격으로 볼 수도 있어, 엄격한 관점에서는 경계상의 데이터 누수에 해당한다. 다행히 이 절차는 타깃 값의 절대적 크기만을 이용한 비지도(outlier) 방식으로, 직접적인 과적합 유도보다는 극단값 배제를 위한 목적이었다. 그럼에도 불구하고 Phase 1 종료 시점에 연구팀은 해당 로직이 잠재적으로 평가를 왜곡할 수 있음을 인지하고, 후속 Phase에서 학습 데이터에 한정한 이상치 처리로 수정할 계획을 수립했다.

한편, 타깃 누락이나 시계열 역행 등 정합성 측면에서는 문제가 발견되지 않았다. 타깃 생성 시 미래 시점의 값을 참조한 뒤 즉시 후속 패스가 없는 행은 제거하였으므로, 존재하는 모든 _target 값은 실제 향후 발생한 값에 대응된다[2]. 또한 Plate별로 패스 진행 순서를 엄격히 보장하여 (예: 1→2→3→… 순), 잘못된 매칭이나 순서 뒤바뀜이 로그 상 전혀 발견되지 않았다. 이를 통해 Phase 1의 데이터 처리 파이프라인은 시계열 인과관계를 존중하며 구성되었음이 확인되었다.

2.3. 실험 설정 및 플래그 분석

Phase 1에서는 별도의 복잡한 설정 플래그보다는 고정된 실험 파라미터들이 사용되었다. 우선 데이터 분할은 8:2 비율, GroupShuffleSplit 방식으로 고정(TEST_SIZE=0.2)되어 있었으며, 교차 검증은 내부 알고리즘 비교에서 5-Fold로 수행되었다. 특이사항으로, Phase 1의 모든 모델 학습에는 Transductive 방식(훈련 전에 전체 데이터 활용) 대신 판재 그룹화 후 비복원 추출 전략이 적용되었다. 예를 들어, 표준화(Scaling)의 경우 명시적으로 StandardScaler가 사용되지는 않았으나, 선택된 모델 (XGBoost, RandomForest)은 트리 기반으로 스케일 민감도가 낮아 전체 데이터 통계량 노출에 따른 영향을 최소화했다. 반면, 이상치 제거 단계에서 데이터 전체 중앙값을 결측치 대체에 사용한 부분(df.fillna(median))이 있었는데, 이는 후속 Phase에서 USE_RM_TRAINONLY와 같은 플래그를 통해 훈련 집합 통계만 사용하도록 개선될 예정이다.

모델 알고리즘 선택은 Phase 1에서 자동화된 비교 프로토콜로 구현되었다. compare_algorithms 함수는 XGBoost와 RandomForest (설치 시 LightGBM 포함) 세 가지 알고리즘에 대해 동일한 학습세트를 가지고 5-Fold 교차검증을 수행한 뒤, 평균 R²가 가장 높은 알고리즘을 채택하도록 했다[8]. 그 결과 Entry→Exit 전이셋(E2X)에는 XGBoost, Exit→Entry 전이셋(X2E)에는 RandomForest가 각각 최적 모델로 선정되었다. 선정된 알고리즘에 대해서는 Optuna 기반의 하이퍼파라미터 튜닝이 3-Fold 교차검증 점수 극대화를 목표로 실행되었으며[9][10], 튜닝 완료 후 전체 train 데이터 재학습을 거쳐 최종 모델을 확정하는 절차를 밟았다. 이러한 일련의 과정은 reports/scripts/002_experiment.py로 보존되어 있으며, 주요 설정은 Phase 1 내내 일관되게 유지되어 재현성을 확보하였다.

3. 실험 결과 및 데이터 분석

3.1. 정량적 지표 변화

교차 예측 프레임워크 도입 전후의 성능은 극명한 차이를 보였다. 초기 단일 모델 접근(실험 ID 001)은 Entry 방향 예측의 Test R² 0.2369, Exit 방향 예측의 Test R² 0.2463으로 평균 0.2416에 불과했다[1]. 한편 교차 프레임워크를 적용한 실험 ID 002에서는 Entry(Exit→Entry) 모델과 Exit(Entry→Exit) 모델의 Test R²가 각각 0.3961, 0.4387로 상승하며 평균 0.4174를 기록했다[11]. 이는 베이스라인 대비 72.7%의 예측력 향상으로, 두 전이 방향에 특화된 이중 모델링 전략이 유효함을 입증한다. 또한 Train R² 관점에서도, 001 실험의 경우 Entry 모델 Train R² 0.6993 → Test R² 0.2369로 과적합 갭이 0.46p에 달했으나[1], 002 실험에서는 Exit 모델 Train R² 0.6360 → Test R² 0.4387로 갭이 0.20p까지 줄어들었다[12]. 이는 Phase 1의 개선된 전처리(이상치 제거 등)와 모델 분리가 일반화 성능을 끌어올렸음을 시사한다. 두 모델의 Test RMSE 역시 Entry 방향 약 12.88, Exit 방향 10.12로, 초기 모델의 13.3/14.85 대비 크게 개선되었다[1][12]. 요약하면, 교차 예측 전략을 통해 모델은 과도한 추측(Variance)을 줄이면서도 유효 신호를 더 포착하여, R² 기준으로 현실적인 성능 수준을 확보하게 되었다.

한 가지 흥미로운 지표는 Roll-forward R²로, Phase 1에서 시도된 추정 평가 방법이다. 실험 002에서는 훈련된 Entry/Exit 모델을 활용해 각 판재의 전 패스를 순차적으로 따라가며 미래 패스의 워핑을 예측해보는 엄격 롤포워드 시뮬레이션을 수행하였는데, 이때 전체 판재를 대상으로 한 R²가 0.4963까지 상승했다[13]. 이는 테스트 셋을 직접 맞춘 단발 예측보다도 높은 수치로, 모델이 누적 예측에도 비교적 안정적임을 보여준다. 다만 이 평가는 동일 데이터로 다단계 예측을 한 것으로 엄밀한 일반화 지표로 보기에는 한계가 있다. 그럼에도 모델이 패스 진행에 따라 성능이 급격히 악화되지 않고 누적 오차를 견뎌냈다는 점은 고무적이며, Phase 1에서 구축한 모델 구조의 견조함을 방증한다.

3.2. 통계적 검증 및 로그 포렌식

교차 예측 모델의 향상된 성능이 단순 우연이나 데이터 편향에 의한 것이 아님을 확인하기 위해, Phase 1 결과에 대한 여러 통계 검증을 병행했다. 우선 분포 변동(Distribution Shift) 분석을 통해 패스 진행에 따른 데이터 분포 변화가 유의미한지 평가하였다. 실험 002의 로그 [Δ-분석] 섹션에 따르면, Entry→Exit 전이의 경우 각 패스 쌍 간 워핑 지표 차이에 대한 Kruskal-Wallis 검정 p-value가 1.28×10^-74로 나타났다[14]. 이는 연속 패스 사이의 분포 차이가 통계적으로 극단적으로 유의함을 의미하며, 패스 번호에 따른 워핑 양상 변화(예: 1→2패스에서 평균 -29.217 감소[15])가 무작위 변동이 아님을 강하게 뒷받침한다. Exit→Entry 전이 역시 p=2.30×10^-9 수준으로 유의미한 분포 변화가 검출되었다[16]. 이러한 결과는 초기 패스와 후반 패스의 데이터 분포가 상이하여 하나의 모델로 전체 범위를 설명하기 어려움을 보여주며, Phase 1의 이중 모델 전략이 이러한 이질성을 완화하는 데 기여했음을 시사한다.

Phase 1에서는 데이터 누수 여부를 빠르게 점검하기 위한 퍼뮤테이션 테스트도 수행되었다. 타깃 값을 무작위로 섞은 가짜 데이터에 대해 모델을 학습시켜 본 결과, Test R²가 기대대로 0 부근 혹은 음수로 나타나 어떤 유의미한 패턴도 학습되지 못했다 (예: permuted 세트에서 XGBoost 모델 R² ≈ -0.50). 이는 모델이 무작위 노이즈로부터 예측력을 얻지 못함을 의미하므로, Phase 1의 성능 향상이 실제 데이터 패턴에 기인한 것임을 확인해준다. 또한 잔차 분석을 통해 모델의 예측 오류가 체계적인 바이어스 없이 분포하는지도 점검하였다. Entry 모델과 Exit 모델의 잔차에 대해 각 패스 진행도별로 평균을 산출한 결과 뚜렷한 추세(trend)가 발견되지 않았는데, 이는 비록 초기 분포 자체는 편향되어 있었으나 모델이 학습 과정에서 그 차이를 상당 부분 상쇄했음을 시사한다.

3.3. 모델 강건성 및 잔차 특성

Phase 1의 모델은 교차 검증 및 Hold-out 모두에서 비교적 일관된 성능을 보이며 강건성을 입증했다. 5-Fold 교차검증에서 도출된 최고 알고리즘의 평균 R²는 Entry 약 0.40, Exit 0.44로 Hold-out Test 결과(각 0.3961, 0.4387)와 거의 일치했다[12]. 이는 데이터 크기가 충분히 크고 분할 방법이 적절하여 훈련/검증/테스트 간 분포 차이가 크지 않았다는 방증이다(단, 시계열 순서를 무시한 Shuffle 분할 한정). 하지만 Phase 1 결과를 엄밀히 해석하면, Entry 방향 모델의 경우 Train R² 0.7596 대비 Test R² 0.3961로 절반 수준의 설명력 저하가 있었고, Exit 모델 또한 Train 0.6360 → Test 0.4387로 감소가 있었다[12]. 이는 아직도 일부 과적합 요소가 남아있음을 의미하며, 특히 Entry 모델은 패스 진행 횟수가 늘어날수록 (즉, 후반 패스) 성능이 떨어지는 경향이 관찰되었다. 실제로 Exit→Entry 전이의 후반부 패스들(예: 8→9, 10→11 등)에서 국소적으로 음의 R² 또는 높은 오차가 발생하는 사례가 로그에 보고되었다[16]. 이러한 현상은 모델의 부분적 취약성으로, 이후 Phase에서 데이터 트렌드 보정이나 잔차 학습 등의 기법을 도입하여 해결할 과제로 남았다.

그럼에도 불구하고, Phase 1을 통해 확보된 교차 예측 모델은 향후 확장의 토대로서 충분한 성능과 안정성을 보여주었다. 특히 두 모델의 잔차를 합성한 전체 예측 결과에 대해 엄격한 기준의 평가지표를 산출한 결과(모든 판재의 전체 패스에 대한 R²), 약 0.50 수준의 설명력을 보였다[13]. 이는 개별 패스 단위 평가보다 높은 값으로, 모델이 연쇄 예측 상황에서도 오류 누적 없이 일정 수준 이상의 정확도를 유지했음을 의미한다. 이러한 특성은 Phase 2 이후 진행될 롤포워드 검증 시나리오에서 더욱 중요해질 것이며, Phase 1의 성과는 이를 위한 기반을 마련한 것으로 평가된다.

4. 결론 및 향후 계획

4.1. 종합 평가

Phase 1은 교차 패스 예측 기법의 도입을 통해 베이스라인 성능을 현실화하고 향상시킨 단계로 종합된다. 초기 단일 모델 대비 약 0.18p에 달하는 Test R² 향상을 달성함으로써, 과거 Phase 0(준비 단계)의 단순 통계 모델에 비해 현격한 예측 개선을 이뤄냈다. 비록 절대적인 R² 수치(0.42)가 높은 수준은 아니지만, 이는 데이터 누수 없이 얻어진 순수한 성능이라는 점에서 의미가 크다. 더욱이 Phase 1에서는 데이터 정합성 검증과 코드 구조 개선을 병행하여, 이후 실험의 신뢰도를 담보할 수 있는 클린한 실험 환경을 구축했다는 데 의의가 있다. 요컨대 수치상의 성과뿐 아니라, 숨겨진 누수를 제거하고 공정 물리를 반영하는 방향으로 모델링 패러다임의 전환을 이뤄냈다는 점에서 Phase 1은 성공적이었다고 평가된다.

4.2. 핵심 시사점

입출력 교차모델의 유효성: 동일 공정을 교대로 거치는 두 방향(Entry→Exit, Exit→Entry)은 데이터 분포와 영향 요인이 상이하므로, 하나의 통합 모델보다 전용 모델 이원화가 효과적이다는 점을 확인했다. 각 모델이 전이 방향별 패턴을 학습함으로써 성능 향상을 달성했다.

데이터 분포 변화의 영향: 패스 진행에 따라 워핑 지표의 분포가 체계적으로 변화함을 통계적으로 검정하였다. 특히 초기 패스와 후반 패스 간 편차가 커 분포 보정(detrending) 없이는 모델 일반화에 한계가 있음을 인지했다. 이는 후속 연구에서 시계열 트렌드 제거 기법을 도입해야 하는 근거가 되었다.

초기 누수 점검의 중요성: Phase 1에서 수행된 그룹 단위 분할, OOF 타깃 인코딩 회피 등의 조치는 미묘한 데이터 누수를 방지하는데 핵심적이었다. 비록 퍼뮤테이션 테스트 등을 통해 명백한 누수는 없다고 확인되었으나, 평가 단계의 데이터 사용과 같은 경계 사례는 지속적으로 모니터링해야 함을 깨달았다.

4.3. 향후 연구 방향

Phase 1에서 구축된 교차 예측 프레임워크는 현실적인 베이스라인을 제시하였지만, 동시에 더 어려운 검증 환경에서의 한계를 노출했다. 특히 시계열 롤포워드 검증을 엄격히 적용하면 현재 모델의 성능이 크게 저하될 가능성이 제기되었다. 실제로 Phase 2에서는 시간순 롤포워드 평가를 도입하여 모델을 검증할 계획이며, 예비 실험에서는 R² 값이 음수로 떨어지는 현상을 포착하였다. 이는 모델이 패스 진행에 따른 트렌드 변화를 제대로 반영하지 못한 결과로 해석된다. 따라서 다음 Phase의 연구 초점은 데이터 분포 보정과 누수 제거의 고도화로 정해졌다. 구체적으로, Phase 2와 3에서는 Detrending 기법을 통해 패스 번호에 따른 워핑 기준선을 조정하고, 엄격한 훈련 데이터 기준 스케일링(예: USE_RM_TRAINONLY 플래그 적용)을 구현할 예정이다. 이를 통해 Phase 1에서 확인된 분포 불일치 문제를 완화하고, Phase 1에서 확보된 교차 모델의 잠재력을 시계열 일반화 성능으로 현실화하는 것이 궁극적인 목표이다. Phase 2에서는 이러한 방향 아래 모델을 재평가하고 구조를 개편함으로써, 데이터 누수 없는 신뢰성 있는 예측에 한 걸음 더 다가설 것이다.
