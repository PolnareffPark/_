# phase-4

개요 및 연구 배경

포스코 AI 모델링 파이프라인 Phase 4에서는 모델 구축 과정 전반에 걸친 데이터 누수(Data Leakage) 여부를 정밀 감사하고, 이를 제거함으로써 모델의 성능을 올바르게 평가하는 데 중점을 두었다. 이전 단계에서 보고된 비정상적으로 높은 예측 성능(예: 테스트 R² ≈ 0.95)은 데이터 누수에 기인한 것으로 의심되었으며, 실제 모델의 일반화 성능을 과대평가하고 있었다. 본 단계에서는 이러한 잠재적 누수를 변수 수준까지 추적 분석하여 원인을 규명하고, 개선된 전처리 및 학습 전략을 도입함으로써 신뢰할 수 있는 평가 체계를 구축하고자 하였다. 또한 누수 제거 후 낮아진 모델 성능을 면밀히 분석하여 공정 데이터의 내재된 통계적 특성을 파악하고, 향후 모델 개선 방향을 수립하였다.

상세 기술적 구현 및 감사 결과

Phase 4에서는 학습-검증 데이터 분리 이후에 이루어지는 전처리 및 피처 엔지니어링 기법을 철저히 Train 전용으로 한정함으로써, 데이터 누수 가능성을 원천 차단하였다. 구체적으로, 그룹 분할을 통해 동일한 강판(Plate)의 데이터가 훈련과 테스트에 중복 투입되지 않도록 보장한 후, 모든 통계량 계산과 스케일링 작업을 학습 데이터에 대해서만 수행하였다. 예를 들어 표준화(Scaling)에는 StandardScaler를 학습 데이터에 대해서만 fit 적용하고, 그 결과로 테스트 데이터를 변환하여 테스트 정보가 스케일 파라미터에 반영되지 않도록 하였다. 또한 Rough Mill 공정 데이터에 대한 통계 피처 생성 시 USE_RM_TRAINONLY 플래그를 도입하여, Rough Mill 변수들의 평균, 표준편차 등의 집계치를 전체 데이터가 아닌 훈련 집합에 한해서만 산출하고 이를 양 집합에 매핑하도록 구현하였다. 이 방식으로 테스트 집합의 분포 정보가 훈련 피처에 스며드는 위험을 제거하고, 훈련 시에 얻은 통계량으로 일관성 있게 테스트 데이터를 처리한다. 실제 코드 구현에서 USE_RM_TRAINONLY=1 설정 시, 훈련 데이터의 Plate 번호 집합만을 사용하여 Rough Mill 데이터를 그룹화 및 집계하고, 그 결과를 훈련/테스트 세트에 각각 병합하도록 되어 있다. 이때 한산된 통계 피처의 결측값은 훈련 집합 통계의 전역 중앙값으로 채워 일관성을 유지하였다.

이와 함께 Feature 누출 방지를 위한 추가적인 안전장치도 적용되었다. 모델 입력 피처명에 target, label, pred 등의 민감 키워드가 포함된 경우 해당 변수를 자동 제거하는 Hard Leak Guard 룰을 적용하여, 혹시 모를 타깃 정보 누출 신호를 사전에 차단하였다[1]. 또한 패스(pair) 단위로 생성되는 Δ-타깃 평균(Target Encoding)이나 이분산 가중치 산출 과정에서도, Out-of-Fold 방식을 사용해 훈련 데이터 내부에서만 통계치를 추정하고 테스트 세트에는 이를 학습 결과로서만 적용하도록 설계하였다. 예를 들어, 인접한 두 패스의 워핑 지수 차이를 학습 데이터에서 그룹별로 계산하여 생성한 pair_delta_te 피처의 경우, 학습 세트 내 3-fold 교차검증을 거쳐 산출된 OOF 값을 사용하고 최종 모델에는 학습 전체에서 얻은 통계를 매핑함으로써 테스트 데이터의 정보를 전혀 참조하지 않는다[2][3]. 마찬가지로 이분산성 보정을 위한 가중치 추정 시에도 학습 세트를 몇 개의 fold로 분할하여 각 폴드의 “밖(Out)”에서 계산된 분산 추정치로 해당 폴드의 데이터에 대한 가중치를 매겨, 테스트 데이터 뿐 아니라 학습 데이터 내에서도 자기 자신을 참조하지 않도록 처리하였다[4][5]. 이러한 다각도의 통제 장치 덕분에, Phase 4의 모델 학습 파이프라인에는 데이터 누수의 여섯 가지 패턴(A~F) 중 어떤 형태도 존재하지 않음을 확인하였다.

구체적으로, 패턴 A (학습/평가 데이터 혼용)의 경우 모든 모델 훈련(.fit)과 변환 과정이 철저히 훈련 데이터로 제한되어 있어 발생하지 않는다. 패턴 B (그룹/시계열 무시한 부적절한 분할)도 Plate ID 그룹별 분리 및 GroupShuffleSplit 적용으로 해결되었다. 패턴 C (타깃 누설)에 해당하는 레이블 누출 가능성은, 타깃 변수인 t+1 패스의 워핑 지수를 동일 Plate 내에서 한 패스 뒤로 이동(shifting)하여 정의하고 마지막 패스에서 발생하는 누락분을 삭제함으로써 제거하였다[6]. 아울러 전체 데이터에 대해 교차검증이나 모델 selection을 수행하는 패턴도 Phase 4 코드에서는 등장하지 않는다. 일례로, 자동화된 코드 스캔에서는 일부 실험용 함수에서 cross_val_score(model, X, y, cv=5)이나 StandardScaler().fit_transform(X) 같은 구문을 탐지하였으나[7], 이는 모델 개발 과정 중 내부 검증을 위한 실험 코드일 뿐 최종 모델 학습에는 사용되지 않으며, 현재의 공식 파이프라인과 보고서 결과에는 영향을 주지 않는다. 정리하면, Phase 4 단계에서는 모델 학습 및 평가 상의 모든 누수 위험 요소를 제거하였고, 코드 레벨 분석을 통해서도 추가적인 누수 패턴 위반이 없음을 재확인하였다.

실험 결과 및 데이터 분석

데이터 누수 제거의 영향을 정량적으로 평가한 결과, 예상대로 모델의 테스트 성능 지표가 크게 하락하여 정상 수준으로 교정되었다. 누수 통제 이전에는 테스트 R² 값이 약 0.95에 달해 훈련 R²과 비슷한 비현실적으로 높은 수준을 보였으나, 누수를 차단한 동일 조건의 모델은 테스트 R²가 -0.08 전후로 급격히 떨어졌다. 예를 들어 Phase 1 단계의 누수 미감사 모델이 테스트 R² = 0.952를 기록했던 반면, Phase 4에서 동일한 데이터셋에 대해 누수를 방지한 모델을 훈련시킨 결과 테스트 R² = -0.086으로 나타났다. 이는 모델이 더 이상 테스트 데이터의 정보를 전혀 활용하지 못하며, 순수하게 학습 데이터에서 얻은 패턴만으로는 예측력이 거의 없는 수준임을 의미한다. 달리 말하면, 종전의 높은 성능은 온전히 데이터 누수에 기인한 허상임이 실증되었다. 이러한 극단적인 성능 저하는 누수 문제가 해결되었음을 방증함과 동시에, 실제 공정 변수들만으로 목표 변수를 예측하는 일이 훨씬 어려운 과제임을 보여준다. 다행히 이후의 추가 개선을 통해 모델 성능을 일부 회복할 수 있었는데, Phase 4에서 구축한 기준 모형(Baseline)의 테스트 R²는 약 0.18 수준으로 확인되었다. 비록 0에 근접한 낮은 결정계수이지만, 이는 누수 없는 조건에서 모델이 얻을 수 있는 사실상의 출발점 성능으로서 의미가 있다.

이러한 Baseline 모델을 기준으로, Phase 4에서는 도입된 각 기능별 효과를 정량적으로 분석하기 위해 다양한 기술 옵션 토글 실험을 수행하였다. 학습 스크립트 내 환경 설정 플래그(USE_DELTA_TARGET, USE_PAIR_TE, USE_HETERO_W, USE_RM_TRAINONLY 등)를 사용하여 특정 기능을 켜고 끈 상태에서 동일 데이터로 모델을 학습하고 테스트 R²를 비교한 것이다. 그 결과, Δ-타깃(USE_DELTA_TARGET) 기능의 영향이 가장 두드러졌다. Δ-타깃 모드는 모델이 절대 워핑지수 대신 “현재 패스 대비 다음 패스 증감량”을 예측하도록 하는 전략인데, 이를 활성화하면 테스트 R²가 0에 수렴하거나 음수로 떨어져 예측 성능이 크게 악화되었다. 예컨대 한 실험에서 Baseline 대비 Δ-타깃 적용 모델의 R²는 +0.188 → +0.009로 급감하였고, 일부 조합에서는 –0.26까지 감소하였다[8][9]. 이는 Δ-타깃 접근법이 데이터 분포를 변화시켜 모델이 일반화하기 어려워졌음을 시사한다. 한편 이분산 가중치(USE_HETERO_W) 적용 역시 일관되게 성능 저하를 가져왔다. Heteroscedastic 가중치를 도입한 모델들은 대부분 테스트 R²가 음수(-0.10 내외)로 나타나, 오히려 모델이 평균보다도 못한 예측을 하는 상황이 벌어졌다[10]. 가중치를 통해 어려운 샘플을 강조하고 쉬운 샘플의 영향력을 낮춘 의도와 달리, 실제 효과는 모델의 학습을 방해하여 과도한 성능 감소를 유발한 것으로 판단된다.

반면 Pair Δ-Target Encoding(USE_PAIR_TE) 기능은 성능에 거의 영향을 미치지 않았다. 해당 특성을 켰을 때와 끄았을 때 테스트 R² 변화가 미미하여 (예: 0.188 → 0.187로 0.001 수준 변화[8]), 패스쌍 평균 편차 피처가 현재 데이터셋에서는 정보량을 거의 추가하지 못했음을 알 수 있다. RM Train-Only 통계(USE_RM_TRAINONLY) 추가에 따른 영향도 비교적 제한적이었다. Rough Mill 통계 피처를 포함하면 성능이 대체로 0.15~0.17 수준으로 약간 낮아지는 경향을 보였다[11]. 예컨대 한 실험에서 RM 통계를 넣지 않은 Baseline이 R²=0.188, RM 통계를 포함한 모델은 R²=0.147로 소폭 감소하였다. 이는 새로 추가된 Rough Mill 관련 피처에 유용한 신호도 있으나 노이즈도 함께 포함되어 모델이 다소 혼란을 겪었을 가능성을 보여준다. 마지막으로 다항 특성(Poly)을 추가로 고려한 실험에서는, Poly 기능 적용 시 테스트 R²가 0.14~0.17 수준으로 Baseline 대비 약간 감소하는 양상이 관찰되었다[12][13]. 다항식 변환이나 SVR 다항 커널의 효과가 제한적으로 나타난 것으로, 데이터 복잡도 대비 과적합 우려를 반영한 결과로 해석된다.

흥미로운 점은 여러 기능을 동시에 적용할 경우 성능 저하가 복합적으로 누적되어 나타났다는 것이다. Δ-타깃, TE, 가중치, RM 통계, Poly를 모두 활성화한 종합 모델의 경우 테스트 R²가 -0.26까지 하락하여[14], 개별 기법 적용 때보다 훨씬 큰 성능 악화를 보였다. 이는 본래 각 기법이 개선을 목표로 도입되었으나, 현 단계에서는 상호작용 효과 등이 제대로 제어되지 않아 부정적 시너지가 발생했음을 시사한다. 요약하면, Phase 4의 실험 결과 현재 데이터셋에서는 Baseline (누수 제거된 순수 모델) 대비 추가 기법들의 이점이 명확히 입증되지 못했다. 오히려 일부 기법은 성능을 크게 저해하여, 향후 이러한 방법론의 재검토 또는 개선이 필요함을 나타낸다.

한편, 데이터 누수 제거의 완전성을 이중으로 확인하기 위해 [Leak Audit] 퍼뮤테이션 테스트를 수행하였다. 이는 타깃 변수를 무작위로 섞은 가짜 데이터로 모델을 학습시켜 R²가 0에 가까운지 확인함으로써, 모델이 어떤 숨겨진 누출 신호를 학습하고 있지 않은지 검증하는 절차이다. Phase 4의 최종 파이프라인에서는 이 퍼뮤테이션 검증을 자동화하여 매 실험마다 보고하도록 구현하였다. 실제로 한 실험(Experiment 052)에서 타깃을 임의 치환한 데이터로 모델을 학습하고 평가한 결과, E2X 모델 permuted R² = -0.0321, X2E 모델 permuted R² = -0.3618로 보고되었다[15]. 두 경우 모두 결정계수가 0 또는 음수로 나타나, 임의 예측 수준의 출력만 산출되었음을 의미한다. 특히 X2E 방향의 경우 -0.36으로 조금 더 낮게 나왔으나, 이는 R² 산식 상 모델이 평균값으로 예측하는 것보다도 못한 경우에 해당하며, 예측 신호가 전혀 없을 때 드물지 않게 발생할 수 있는 수준이다. 이러한 결과는 본 모델이 실제 타깃과의 관계 없이는 어떤 유의미한 패턴도 학습하지 못함을 보여주며, 데이터셋 외부의 불순한 연관성(누수)이 존재하지 않음을 강력히 뒷받침한다. 다시 말해, Phase 4의 모델은 허구의 타깃에 대해 무작위 추측과 다름없는 성능을 보이므로, 실제 타깃에 대한 앞서의 R² 성능은 온전히 합법적인 예측 실력임을 확인하였다. 퍼뮤테이션 테스트를 통해 데이터 누수 방지 조치의 효과를 최종 검증함으로써, 모델 평가의 신뢰도를 한층 높일 수 있었다.

공정 데이터 분포 특성 분석도 Phase 4에서 심층적으로 수행되었다. 특히 압연 패스 간 워핑 지수 변화(Δ)의 분포가 패스 단계별로 어떻게 달라지는지 분석하고, 이를 통해 이분산성과 비정상성의 존재 여부를 통계적으로 검정하였다. E2X(Entry→Exit 방향 모델)와 X2E(Exit→Entry 방향 모델) 각각에 대해, 모든 Plate의 연속 패스 쌍별로 워핑 지수 변화를 계산한 뒤 그룹 간 분포 차이를 비교하였다. Kruskal-Wallis 검정 결과, 두 모델 모두에서 패스 구간별 Δ 분포 차이가 매우 유의미한 것으로 나타났다. E2X의 경우 검정 통계 p-value가 1.28×10^-74에 불과했고, X2E의 경우도 2.30×10^-9로 0.05 기준 훨씬 아래였다[16]. 이는 적어도 한 쌍 이상의 패스 구간에서 다른 구간들과 중앙값이 유의하게 다르다는 것을 의미하며, 전체적으로 볼 때 패스 진행 단계에 따른 워핑 지수 변화량의 분포가 동일하지 않다는 귀무가설을 강하게 기각한다. 나아가 Levene 등분산 검정에서도 E2X p-value = 4.24×10^-17, X2E p-value = 1.50×10^-10으로 이분산성이 통계적으로 유의하게 검정되었다[16]. 즉, 패스 구간별로 워핑 지수 변화의 분산(산포) 역시 서로 동일하지 않고 크게 차이가 난다는 것이다. 한 구간에서의 워핑 변화 폭이 다른 구간에 비해 훨씬 변동성이 크거나 작다는 뜻이며, 실제 수치를 보면 E2X 기준 최대 분산 구간의 표준편차가 최소 분산 구간의 1.775배에 달했고 X2E에서는 그 비가 2.181배까지 커졌다[16].

구체적인 예를 들면, 1→2 패스 전환 구간에서의 워핑 지수 변동은 E2X 모델 기준 평균 -29.217, 표준편차 15.265(median≈-28)로 나타났다[17]. 초기 패스에서 워핑 지수가 크게 감소하는 경향을 보이는 것이다. 반면 5→6 패스 구간의 경우 평균 -6.840, 표준편차 25.220(median≈-12)으로, 후반 패스로 갈수록 개선 폭은 작고 개별 사례들의 편차는 오히려 커지고 있음을 알 수 있다[17]. 특히 표준편차는 1→2 구간 대비 5→6 구간이 약 1.65배에 달해, later passes에서 결과의 일관성이 떨어지는 양상을 보였다. X2E 방향에서는 일부 구간에서 워핑 지수가 악화되는 현상도 관찰되었다. 예를 들어 8→9 패스 전환 시 평균 +19.395 (표준편차 31.194)로 워핑 지수가 오히려 증가하는 경향이 있었고[18], 해당 분포는 다른 구간들과 함께 분석되며 그룹 간 차이를 유의하게 만들었다. 요컨대, 데이터 분석 결과 압연 공정이 진행됨에 따라 초기 패스에서의 큰 개선이 후반부의 미미한 개선 또는 변동성 증가로 단조 감소하지 않고 변화한다는 중요한 사실을 확인하였다. 이는 데이터가 명백한 이분산 특성을 지니고 있음을 의미하며, 단일 모델로 전체 패스 구간을 모두 예측할 경우 특정 구간에서 오차가 크게 발생할 수 있음을 시사한다. Phase 4에서 시도한 이분산 가중치 기법은 이러한 분포 차이를 보정하기 위한 아이디어였으나, 앞서 본 바와 같이 현 구현에서는 성공적이지 못했다. 그럼에도 본 통계 분석을 통해 얻은 통찰은, 향후 패스 구간별 모델링 전략이나 가중치 설계의 필요성을 뒷받침하는 근거가 된다.

결론 및 향후 계획

Phase 4 감사 작업을 통해 포스코 AI 예측 모델링 파이프라인의 데이터 누수 문제가 전면 해결되었다. 코드 검증과 실험적 재현을 거쳐, 이전 단계에서 관측된 이례적으로 높았던 모델 성능이 데이터 누수에 기인한 것임을 규명하였고, 다양한 Train 전용 전처리 기법 도입과 절차 개선으로 이러한 누수를 완벽히 차단하였다. 그 결과 모델의 테스트 R² 지표는 누수 제거 전보다 크게 낮아졌으나, 이는 모델의 진짜 실력을 나타내는 값으로서 의미가 크다. 특히 약 0.95에서 -0.08 수준으로의 결정계수 변화는, 본 프로젝트 초기에 간과되었던 데이터 누출 효과를 정량적으로 보여주는 동시에, 향후 개선해야 할 여지가 막대한 현실적인 난제를 드러내준다. Phase 4를 통해 우리는 평가 절차의 신뢰성을 확보하고 숨겨진 문제점을 투명하게 드러냈다는 점에서 큰 성과를 거두었다. 이는 추후 모델 개선 작업의 탄탄한 기반이 될 것이다.

향후 연구 및 개발 단계에서는, 누수 없는 환경에서 모델 성능을 향상시키는 방향으로 노력을 집중할 계획이다. Phase 4에서 확인된 바와 같이 현재 모델의 예측력은 제한적이므로, 특징 공학 및 알고리즘 개선을 통해 실제 도메인 패턴을 더 잘 포착할 수 있도록 추진한다. 예를 들어, 앞서 통계적으로 밝혀진 패스 진행 단계에 따른 이질성에 대응하기 위해 패스 구간별로 별도 모델을 구축하거나 적응형 가중치를 재설계하는 방안을 고려할 수 있다. 또한 이번 단계에서 효과가 미흡했던 Δ-타깃 접근과 이분산 가중치 기법에 대해서는 실패 원인을 면밀히 분석하여 보완하거나 대안을 모색할 예정이다. 이외에도, 새로운 유의미한 피처 발굴(예: 공정 전문가와의 협력을 통한 도메인 피처 추가)과 고도화된 모델 아키텍처(예: 앙상블 기법이나 딥러닝 모델)의 도입도 검토하고 있다. 궁극적으로, Phase 4에서 수립된 데이터 무결성을 바탕으로 모델의 예측 정확도를 꾸준히 끌어올려, 포스코 압연 품질 예측 모델을 현장 실무에 활용 가능한 수준으로 향상시키는 것이 향후 목표이다.
