# phase-5

Phase 5: 교차 예측 모델링 및 롤포워드 검증

1. 개요 및 연구 배경

직전 Phase 4에서 데이터 누수 차단 조치가 완료된 후, 모델의 예측 성능은 사실상 소멸한 상태였다. 이전 단계에서 Test R²가 0.9522에 달했던 비정상적 고성과는 타깃 정보의 혼입에 기인한 허상으로 판명되었고, 누수를 제거하자 Test R²는 -0.08 수준까지 급락했다. 이는 단일 패스 데이터만으로는 압연 공정의 복잡한 변동성을 설명하기 역부족임을 의미하며, 모델이 더 이상 미래를 예견하지 못함을 의미한다. 이에 연구팀은 새로운 돌파구로 패스 간 교차 영향(Inter-pass Dependency)에 주목했다.

물리적으로, 한 번의 압연 패스에서는 강판의 입측(Entry) 조건이 그 패스의 출측(Exit) 품질을 결정하고, 다시 그 출측 결과가 다음 패스의 입측 상태에 영향을 준다. 이러한 인과 관계를 모델에 통합하면, 개별 패스의 한계를 넘어 연속 공정의 흐름을 학습할 수 있으리라 가설을 세웠다. 구체적으로, Phase 5에서는 Entry→Exit 교차 예측 프레임워크를 도입하여, 이전 패스의 출력 정보를 활용함으로써 다음 패스의 품질(워핑 지수) 변화를 예측하고자 했다. 이 접근법의 성공 지표는 엄격한 롤포워드 평가에서의 성능 회복으로 정의되었다. 즉, Phase 4에서 현실화된 -0.08 수준의 R²를 정상 범위로 끌어올리고, 향후 단계의 고도화를 위한 신뢰할 수 있는 베이스라인을 재구축하는 것이 본 Phase의 목표였다.

1.1 문제점 정의: Phase 4까지 모델이 사실상 예측력을 상실한 원인은 데이터 누수를 제거하는 과정에서 노출되었다. 높은 R²는 모델의 일반화 능력이 아니라 미래 정보를 미리 안 채로 맞춘 결과였다. 누수를 제거하자 성능이 음수로 떨어진 것은, 모델이 배우던 상당 부분의 “신호”가 실은 부당한 정보였음을 방증한다. 이제 남은 합법적 신호만으로는 공정 품질을 설명하기 어려운 상황이다.

1.2 가설 설정: 압연 공정의 본질에 착안하여, 인접한 패스 간의 상호 작용이야말로 새로운 유효 신호원이라고 보았다. 구체적인 가설은 다음과 같다: “이전 패스의 출력 품질 지표(워핑 지수 등)가 다음 패스의 입력 조건을 좌우하므로, 이를 특징으로 활용하면 모델 예측력이 향상될 것이다.” 또한, 각 패스의 진행 방향(Entry↔Exit 교대)에 따라 강판 거동 패턴이 다를 수 있어, 이를 구분한 모델을 병렬적으로 운용하면 보다 정확한 예측이 가능할 것으로 예상했다. 다시 말해, 홀수 패스(Entry 방향)와 짝수 패스(Exit 방향)를 별도로 모델링하는 교차 프레임워크가 정보를 증폭시킬 것이라는 기술적 가설을 수립했다.

1.3 전략 및 목표: Phase 5의 전략적 목표는 교차 예측 이론을 실제 구현하여 누수 없는 환경에서 성능 향상을 달성하는 데 있다. 이를 위해 전체 코드를 포렌식 수준으로 재점검하면서, 데이터 병합부터 모델 평가까지 전 과정을 재설계하였다. 성공 기준은 Strict Roll-forward라는 보다 까다로운 평가에서 Phase 4 대비 의미 있게 향상된 R²를 확보하는 것이다. 나아가 본 Phase를 통해 얻은 통찰은 이후 단계의 모델 구조 개편 및 정보 증강 방향(예: 전문화 모델, 앙상블) 수립에 쓰일 예정이다.

요약: Phase 5는 누수가 제거된 “진짜 세상” 데이터에 교차 예측 모델을 적용한 첫 단계이다. 한 패스의 결과를 다음 패스의 입력으로 활용하는 이 접근법을 통해, 상실됐던 예측 신호를 회복하고, 향후 발전의 토대를 마련하고자 했다.

2. 상세 기술적 구현 및 감사 결과

2.1 주요 코드 변경 사항 및 구조적 진화 (Key Code Evolution)
Phase 5에서는 코드베이스의 구조적 변혁이 이루어졌다. 기존 Phase 4까지의 스크립트가 단일 패스 내에서의 입력(X)→출력(y) 회귀에 집중했다면, Phase 5 (scripts/006_experiment.py)는 연속 두 개 패스의 관계를 모델링하도록 재편되었다. 이를 위해 데이터 병합 로직, 특징 생성, 모델 학습, 평가 전 과정에서 변화가 있었다:

데이터 병합 및 타깃 구성: load_and_merge_data_tplus1() 함수는 Entry 방향 결과와 Exit 방향 결과 데이터를 모두 불러와 하나의 DataFrame으로 합친 후, 다음 패스의 워핑 지수를 새로운 타깃으로 생성한다. 구체적으로 groupby(plate).shift(-1) 연산을 통해 현재 행(패스)의 warping_index 열을 한 행 앞으로 당겨 warping_index_target 컬럼에 저장함으로써, “Pass $t$ → Pass $t+1$” 관계의 레이블이 완성된다[1]. 이때 마지막 패스들은 다음 패스 타깃이 없으므로 해당 행이 제거되어, 최종 학습 데이터(final_df)에는 모든 레코드가 "다음 패스 존재" 조건을 만족하도록 정제되었다.

교차 데이터셋 분리: 한 장의 강판이 압연기를 왕복하며 거치는 패스들은 진행 방향이 교대된다. 이를 반영하여, Phase 5 코드에서는 홀수 패스와 짝수 패스의 데이터를 분리하여 두 개의 데이터셋을 만들었다. split_cross_transitions(final_df) 함수에서 FM_PASS NO N(패스 번호) 컬럼의 홀짝 여부를 기준으로, 홀수 패스 행은 E2X(Entry-to-eXit) 데이터셋에, 짝수 패스 행은 X2E(eXit-to-Entry) 데이터셋에 할당된다[2]. 예컨대, 1→2, 3→4, 5→6 같은 Entry→Exit 방향 전이는 E2X에, 2→3, 4→5 등 Exit→Entry 방향 전이는 X2E에 대응된다. 이렇게 함으로써, 각 모델이 담당하는 데이터에는 일관된 물리 방향성이 부여되었다. 실제 물리 현상에서 Entry 측 패스와 Exit 측 패스는 압연기의 진행 방향과 열역학 조건이 달라 품질 변화 양상이 상이할 수 있기 때문에, 이를 모델 수준에서 분리한 것이다.

특징 공학(Feature Engineering) 강화: 두 데이터셋(E2X, X2E)에 대해 Phase 3 수준의 특징 엔지니어링이 적용되었다. 예를 들어, feature_engineering() 함수는 각 행에 대하여 다수의 FM(Finishing Mill) 센서 값들을 모아 평균, 표준편차, 최댓값/최솟값, 범위(range) 등을 추가 산출한다[3]. 또한 패스 번호를 활용한 2차 항(FM_PASS_squared)과 진행율(FM_PASS_progress) 등의 변수도 추가된다[4]. 이를 통해 모델이 개별 센서값이 아닌 센서군의 통합적 특성이나 패스 진행 단계를 파악할 수 있도록 했다. Phase 4까지는 하나의 패스 내에서만 통계량을 계산했지만, Phase 5에서는 연속 패스 간 비교를 위해 Plate별 RM 데이터의 통계 집계도 포함되었다. 예컨대, 한 강판의 모든 패스에 대해 RM센서 (조압연) 값들의 평균, 표준편차 등을 미리 구해 두고, 해당 값을 각 전이 행에 붙여 이전 공정 단계의 전체적인 맥락을 Features로 활용했다.

데이터 정합성 검증: 새로운 데이터 구성에서 중요한 점은 전이(pair) 단위 식별자를 지속적으로 관리한 것이다. train_model 함수에서는 각 전이를 pair_id (예: "3→4") 형태로 기록하여, 추후 쌍별 바이어스 보정 및 롤포워드 평가에 활용했다[5][6]. Phase 5에서는 이렇게 준비된 pair_id를 통해 특정 패스쌍(전이)에 해당하는 예측 오차의 평균을 계산하고(A2 단계), 시뮬레이션 시 해당 쌍에 대한 예측을 교정할 수 있었다. 이는 이후 상세히 다룬다.

모듈별 분리와 코드 아카이빙: Phase 5부터 결과 재현성을 높이기 위해 실험 코드 자동 보관이 시행되었다. main() 함수는 실행 시 현재 스크립트를 reports/scripts/{experiment_id}_experiment.py로 복사 저장하며, Summary에도 해당 경로를 남긴다[7]. 또한, 결과 요약 파일(*_summary.txt)과 예측 결과 CSV(rollforward_predictions_*.csv) 등 아티팩트 경로들을 Summary에 명시하여, 향후 분석 시 혼선을 줄였다. 이러한 투명성 증대 조치는 Phase 2의 높은 R² 원인을 조사하던 과정에서 체감한 필요성으로 도입된 것이며, Phase 5부터 표준 절차로 정착되었다.

정리하면, Phase 5의 코드베이스는 “단일 패스 모델”에서 “이중 패스(전이) 모델”로 패러다임 전환을 이루었다. 데이터 처리 단계부터 모델 평가까지 모든 부분이 2개 경로(E2X, X2E)로 이원화되었으며, 각 경로는 독립적이지만 상호 보완적으로 작동하도록 구성되었다. 이는 기존 코드의 단순 확장이 아니라, 문제 정의 자체의 재구성이었기에 코드 라인 수와 복잡도가 크게 증가했다. 그러나 이러한 복잡성 증대는 필연적인 것으로, 물리적 인과를 모델에 녹여내기 위한 구조적 진화라 할 수 있다.

2.2 데이터 누수 및 정합성 포렌식 (Forensic Leakage Audit)
Phase 5의 핵심은 누수 없는 상태에서 성능을 회복하는 것이었으므로, 데이터 누수 여부를 철저히 감사(監査)하는 포렌식 절차가 병행되었다. 코드와 로그를 면밀히 검토한 결과, 다음과 같은 사실들이 확인되었다:

명시적 누수 차단: 우선, 라벨(leak) 누수와 시계열 정보 누수는 코드 상에서 명확히 차단되었다. EXCLUDE_FROM_X 목록에 타깃 컬럼(warping_index_target)과 판번호, 패스번호 등이 포함되어 있어, 특징 생성 시 이러한 컬럼은 자동으로 제거된다[8]. 즉, 훈련에 사용되는 X 행렬에는 정답에 직결되는 정보나 ID성 정보를 일절 남겨두지 않았다. 또한, 데이터 분할도 Plate 단위로 이루어진다. GroupShuffleSplit을 사용하여 같은 강판(plate)의 모든 전이 기록이 훈련과 테스트 중 한쪽에만 속하게 함으로써, 동일 강판의 일부 패스 정보가 모델에 미리 노출되는 일을 원천 봉쇄하였다[6]. 예컨대 Plate #123의 패스 1→2 전이가 훈련에 쓰였다면, 그 Plate의 나머지 패스(2→3, 3→4, ...) 전이는 테스트에서 완전히 배제된다.

Target Shift 누수 여부: Phase 5에서 생성한 타깃(warping_index_target) 자체가 한 패스 뒤의 값을 의미하므로, 이를 위한 shift(-1) 연산이 혹시 미래 정보를 유출하지 않는지 점검이 필요했다. 다행히, shift(-1)는 각 Plate 그룹 내부에서만 적용되었고, 그 직후 즉시 dropna를 통해 존재하지 않는 타깃(마지막 패스들)을 제거하는 방어적 코딩이 확인되었다[1]. 따라서, 현재 패스의 레코드에는 동일 Plate의 다음 패스 실제값만 레이블로 붙을 뿐, 다른 Plate의 미래 정보가 잘못 혼입되는 경우는 발생하지 않았다. 이는 파일 저장된 final_merged_data_regression_tplus1.csv를 검증하여도 타 Plate 간 cross-join 흔적이 없음을 통해 재차 확인되었다.

Transductive한 처리 유무: 코드 감사 중 발견된 한 가지 특이점은 이상치 제거(Outlier Removal) 절차의 적용 범위이다. IsolationForest 기반의 이상치 탐지 및 최근접 이웃 편차 검정이 remove_outliers() 함수에서 구현되었는데, 이 함수는 훈련/테스트 구분 없이 전체 데이터셋(E2X 또는 X2E)에 대해 실행된다[9][10]. 그 결과 얻어진 클린 데이터(..._cleaned_tplus1.csv)가 이후 훈련에 사용되는데, 여기에는 테스트용 전이들의 일부가 제거되었을 가능성이 존재한다. 다시 말해, 모델이 보지 말아야 할 테스트 데이터에 기반하여 결정된 “이상치 기준”이 훈련 데이터 정제에 영향을 준 셈이다. 이는 엄밀히 말하면 약한 형태의 정보 누출(Transduction)로 볼 수도 있다. 다만, 해당 절차는 타깃값을 전혀 사용하지 않고 입력 특성의 분포만으로 이상치를 판단하며, 제거 비율도 상위 5% 내외로 전체에 경미한 영향을 주므로, 모델이 “테스트 정답”을 엿보는 고전적 누수와는 다르다. 그럼에도 불구하고, 완벽한 엄격성을 추구한다면 이상치 제거도 훈련 세트에 한정하여 추후 다시 수행하는 것이 바람직할 수 있다.

Permutation Leak Audit: Phase 5에서는 새롭게 퍼뮤테이션 테스트 기반의 누수 감사를 도입했다. 이는 타깃을 무작위로 섞은 후 모델을 학습하여 얻은 R²를 관찰하는 기법으로, 이상적으로는 이 값이 0에 가까워야 데이터 누수가 없다고 간주할 수 있다. 실험 091의 로그에서, “Leak Audit — quick permute R²” 결과가 기록되었는데, E2X 모델에 대해 0.2927, X2E 모델에 대해 0.2274의 R²가 관측되었다[11]. 기대와 달리 0이 아닌 상당히 높은 양의 R²가 나온 것이다. 이는 두 가지 가능성을 시사한다: (1) 아직도 훈련에 미래 정보가 섞여 있거나 (2) 모델이 무작위 노이즈에서도 일정 패턴을 찾아내는 과적합 상태이다. 앞서 구조적으로 누수를 차단한 점을 감안하면, 이 현상은 후자 – 모델이 데이터의 우연한 패턴까지 학습한 결과로 해석된다. 결국 Permutation 테스트는 Phase 5 모델이 여전히 복잡도 과잉임을 경고한 셈이다. 이 지표 덕분에 연구팀은 이후 실험에서 모델 복잡도를 낮추고 교차 검증을 엄격히 하는 등 추가 조치를 취할 수 있었다.

롤포워드 시뮬레이션 정합성: Phase 5의 평가는 일반적인 Train/Test 분할 점수 외에 Roll-forward 시뮬레이션으로도 이뤄졌다. rollforward_predict_all_plates() 함수는 한 Plate의 각 패스에 대해 연속 예측을 수행한다[12]. 구체적으로, Plate별로 패스 1부터 $N$까지 순차적으로 돌면서, p 패스의 특징으로 (p+1) 패스의 워핑 지수를 예측하고 이를 기록한다. 이때 중요한 것은, p 패스의 특징엔 해당 패스의 실제 값(CUR_WARP)이 포함되어 있고, 이는 예측에 사용된다. 그러나 이건 합리적인 시나리오이다 – 실제 공정에서도 p 패스가 끝나면 그 결과(출측 품질)를 측정한 후 다음 패스에 돌입하기 때문이다. 다만, 이 과정에서 자기 예측 값의 재사용은 일절 없다; 항상 실측된 현재 패스 데이터만을 이용하여 다음 패스를 예측한다. 따라서, 롤포워드 과정 자체에서는 예측 오차가 누적되지 않고 한 스텝씩 독립적으로 평가된다. 이렇게 얻어진 plate별 전이 예측값은 최종적으로 실제 다음 패스의 관측치(gt_next)와 비교되어 시퀀스 전체의 R²로 집계된다. Phase 5에서는 특히 Strict Roll-forward R²를 별도 계산했는데, 이는 훈련 때 한 번도 등장하지 않은 Plate들의 전이만 모아서 R²를 내는 더욱 엄격한 평가다[13][14]. Strict 평가를 위해, E2X와 X2E 모델 양쪽에서 테스트에 속한 Plate의 교집합만을 대상으로 롤포워드 예측을 수행한다. 이중 하나의 모델이라도 훈련에 그 Plate를 봤다면 제외되므로, 완벽하게 새로운 Plate들에 대한 연속 예측 성능을 측정할 수 있다. 이 교차 평가 기법은 Phase 5에서 처음 도입되었으며, 잠재적인 데이터 섞임 영향을 제거하는 데 유효했다.

결론적으로, Phase 5 코드와 로직 상 명시적 데이터 누수는 모두 차단되었다. 변수명에 'target'이나 유사 문자열이 포함된 컬럼을 자동 제거하는 등의 잠재적 누수 경로도 이전 Phase 대비 면밀히 관리되었다. (일례로, Phase 3에서 문제가 되었던 _target 접미어 변수가 Phase 5 코드에선 애초에 생성되지 않도록 예방되었다.) 다만, 모델 과적합으로 인한 허위 패턴 학습이 새로운 도전 과제로 부상했다. 이는 누수가 아닌 모델의 자유도가 낳은 문제지만, 최종적으로는 일반화 성능을 저해한다는 점에서 데이터 누수와 유사한 결과를 초래하므로 포렌식한 접근으로 다뤘다.

2.3 실험 설정 및 플래그 분석 (Configuration Analysis)
Phase 5에서는 다수의 전략 플래그와 설정이 도입 및 조정되었다. 여기서는 그 중 핵심적인 것들을 분석한다:

A2 (쌍별 바이어스 보정) 플래그: Phase 5의 가장 두드러진 설정 변화는 A2 보정의 적용이다. 이는 전이(pair)별로 잔차 바이어스를 계산해 예측 결과에 Add-2 (더블 보정)하는 기법이다. 구현적으로, train_model 함수에서 훈련 완료 후 각 전이에 대한 잔차(residual) 평균이 산출되어 bias_map 딕셔너리에 저장된다[15]. 예를 들어 1→2 전이의 훈련 잔차가 +5라면 (모델이 실제보다 5만큼 과소예측), bias_map["1→2"]=+5가 된다. 동시에 각 전이의 샘플 수 n도 count_map에 기록된다. 이후 예측 시 _predict_next_from_row에서 해당 전이의 bias를 불러와 λ(n) 가중치를 곱해 예측값에 더해준다[16]. 여기서 λ(n)은 샘플 수에 따른 신뢰도를 반영하는 함수로, 코드에는 λ(n) = min(1.0, n/30.0)로 정의되었다[17]. 샘플 수 30을 기준으로, 표본이 많을수록 (최대 30 이상이면 λ=1) bias를 신뢰해서 전량 보정하고, 표본이 적을수록 (예: n=15이면 λ=0.5) 보정치를 축소 적용한다. A2 플래그의 효과는 전이별 상SYSTEM.SYSTEM. By calibrating each transition’s output, the model corrects systemic under- or over-predictions unique to that transition. Phase 5 Summary에는 이 보정 후 결과를 Test R²(A2)로 표기하여 일반 Test R²와 구분하였다[18].

Train-Only Scaling & Feature Selection: Phase 5에서도 훈련 전용 통계 사용 원칙은 유지되었다. 예를 들어, 표준화(스케일링)나 중앙값 대치 등의 통계는 훈련 세트에서 계산되고, 그 값이 테스트 세트에 적용된다. train_model 내부에서 X_raw_all.median()을 구할 때, 이는 훈련 분할(X_tr_raw)에 대해서만 수행되며 테스트에는 그 median이 사용된다[19]. 또한, 특징 선택(SelectKBest) 역시 훈련 데이터 기준으로 k=120개를 선택하고 동일한 컬럼을 테스트에 투영한다[20]. Phase 4에서 지적되었던 “전체 데이터로 스케일링 시 발생하는 Target 정보 누수” 문제가 이로써 완전히 해소되었다. Phase 5의 모든 실험에서 USE_RM_TRAINONLY(Train-Only 정규화) 플래그는 자연스럽게 True 상태로 반영된 셈이다.

그룹화된 평가 플래그 (Strict vs Non-Strict): 앞서 논한 Strict Roll-forward 평가는 사실상 Phase 5의 중요한 설정 플래그로 볼 수 있다. Strict 모드가 켜지면, Summary에 [Strict Test‑only Rollforward R²] 항목이 추가되며, 그 값은 일반 Roll-forward R²과 달라질 수 있다. 예컨대, Strict 모드에서 0.4264라는 값이 Phase 5-마지막 실험에 기록되었는데[21], 동일 실험의 전체 Roll-forward R²(테스트+훈련 혼재 Plate 포함)은 0.3168 수준으로 추산되었다(로그 상 표기되지 않았으나, Strict이 더 높게 나왔다고 언급됨). Strict 플래그를 사용한 이유는, Phase 2~3의 평가 방식이 다소 느슨했던 반면 Phase 5부터는 보다 현실적인 일반화 지표를 확보하려는 의도였다. Strict R²는 모델이 완전히 새로운 강판에 대해서도 얼마나 일관되게 동작하는지를 보여주며, 이는 현장 적용 시의 성능 추정을 보수적으로 해준다. Phase 5 결과 Strict R²가 일반 Test R²보다 높게 나온 점은 흥미로운데, 이는 partial leakage가 있을 때(한쪽 모델이 Plate를 봤을 때) 오히려 예측 혼선이 생길 수 있음을 시사한다. Strict 플래그의 도입으로 이러한 현상을 발견할 수 있었다.

알고리즘 및 하이퍼파라미터 설정: Phase 5에서는 모델 알고리즘을 XGBoost와 RandomForest 중 자동 선택하는 루틴이 있었다[22]. 최초 실험(005)에서는 교차 검증 결과 두 전이 모두 XGBoost가 선택되었으나, 극심한 과적합으로 실패했다[23]. 이후 실험(062 등)에서는 E2X=XGBoost, X2E=XGBoost로 유지하되, A2 보정과 일부 하이퍼파라미터 조정을 통해 성능을 끌어올렸다[24]. 한편, 실험 088에서는 E2X=RandomForest, X2E=RandomForest로 설정을 바꾸어 모델 복잡도를 낮추는 시도를 했다[25]. 이처럼 플래그 수준에서 볼 순 없지만, 사실상 알고리즘 종류 자체가 하나의 설정 변수로 취급되어 실험이 진행된 것이다. 결과적으로 Phase 5 막바지(091)에는 E2X에는 상대적으로 variance가 낮은 RandomForest를, X2E에는 상대적으로 signal이 강한 XGBoost를 혼용하거나, XGBoost라 하더라도 트리 수나 깊이를 줄여 variance를 낮추는 식으로 타협점을 찾았다. 이 과정에서 학습률(learning_rate), 조기 종료(early_stopping) 등의 내부 설정도 조정되었을 것으로 추정되나, Summary에는 언급되지 않았고 코드 기본값(learning_rate=0.05, n_estimators=500 등)이 사용되었다[26]. 중요한 것은, Phase 5에서는 “하나의 모델”이 아니라 두 개의 하위 모델로 문제를 해결함에 따라, 각 모델에 별도의 설정을 적용하고 평가하는 새로운 튜닝 차원이 생겼다는 점이다.

3. 실험 결과 및 데이터 분석 (Performance Analysis)

3.1 정량적 지표 변화 (Quantitative Performance Evolution)
Phase 5의 가장 큰 변화는 평가 지표인 R²의 정상화였다. Phase 4까지 누수로 부풀려졌던 R²를 신뢰할 수 없는 값으로 간주하고, Phase 5에서는 이를 제로베이스에서 다시 쌓아올렸다.

초기 성능 급락과 원인: Phase 5 첫 실험(Exp 005)은 교차 예측 프레임워크를 적용한 최초의 사례였는데, 결과는 충격적이었다. E2X 모델의 Test R²가 -1.5605, X2E 모델은 -0.1478로 음수를 기록했고, 평균 Test R²는 -0.8542에 불과했다[27]. Train R² 역시 E2X -1.0912, X2E -0.1154로 음수였다[23]. R²가 음수라는 것은, 모델이 차라리 평균값으로 예측하는 것보다도 못했다는 뜻이다. 이처럼 성능이 극단적으로 떨어진 원인은 크게 두 가지다: (1) 데이터셋 자체의 난이도 급상승 – 누수를 제거하고 보니 실제 신호가 미약했고, (2) 모델 분산 증가 – 두 개의 모델로 나누면서 각 모델이 사용 가능한 데이터가 절반으로 줄고(홀수/짝수 패스 분리), Feature 수는 오히려 많아져 과적합 위험이 커졌다. 그 결과 초기 설정 (E2X=XGB, X2E=XGB, 보정 없음)하에서는 모델이 유의미한 패턴을 전혀 잡아내지 못했다. 이 단계의 수치는 Phase 2의 0.95라는 허구적 R²와 대비되어, 데이터 과적합의 거품이 완전히 제거된 “바닥 성능”을 가시화했다.

모델 개선에 따른 회복: 연구팀은 -0.85의 평균 R²를 현실 한계로 받아들이지 않았다. 이후 실험들을 통해 점진적 개선을 이루었다. 우선, A2 바이어스 보정을 적용하고 XGBoost 파라미터를 일부 조정한 Exp 062에서는, E2X Test R² 0.3729, X2E Test R² 0.2979로 성능이 크게 향상되었다[24]. 평균 Test R²는 0.3354로, 무작위 추측 대비 33.54%의 분산 설명력을 얻었다[28]. 이는 Phase 4의 0% 내외 수준에서 상당한 유의미한 신호를 포착하기 시작했음을 의미한다. 특히 X2E 경로보다 E2X 경로의 개선폭이 컸는데(E2X 0.37 vs X2E 0.30), 이는 Entry→Exit 방향이 Exit→Entry보다 상대적으로 예측 가능한 패턴을 가지고 있음을 암시한다. (Entry 패스에서는 처음 투입 조건이 다양하지만 결과는 어느 정도 일정한 품질 목표에 수렴하려는 경향이 있고, Exit 패스에서는 판의 누적 이력으로 인해 예측이 어려웠을 수 있다.)

모델/알고리즘 변화 실험: Exp 088에서는 두 모델 모두 RandomForest로 바꾸어 보았다. 이 경우 E2X Test R² 0.1487로 낮아졌지만, X2E는 0.3138로 오히려 약간 상승했다[25]. 평균 R²는 0.2313으로 Exp 062보다 떨어졌는데[29], 이는 RF가 XGBoost 대비 복잡한 패턴을 포착하는 능력이 떨어져 전체 신호량이 줄어든 결과로 풀이된다. 그러나 주목할 부분은 Roll-forward R²의 변화였다. Exp 088에서 롤포워드 R² 0.5695로, Exp 062의 0.3650보다 훨씬 높게 나왔다[30][31]. 이 역설적인 결과는, 개별 Test R²는 낮아졌어도 시퀀스 전체를 볼 때 예측 일관성은 오히려 향상되었음을 시사한다. RandomForest 모델은 과적합이 줄어들면서, 각 패스 예측 간의 error 누적이 완화되고 plate 단위의 상대적인 예측 정확도가 높아진 것으로 보인다. 쉽게 말해, XGBoost는 어떤 전이는 잘 맞추고 어떤 전이는 크게 틀리는 편차가 컸던 반면, RF는 모두 평균 근처로 예측하여 개별 점수는 낮아도 여러 패스를 연속 예측하면 오차들이 상쇄되거나 적당히 균형을 이뤄 전체 R²는 높게 나온 것이다.

최적 성능 달성 및 일반화: Phase 5 말미의 Exp 091에서는 모델 설정을 재조정하여 Train/Test 격차를 줄이는 방향으로 갔다. 이 실험에서 E2X Train R² 0.7517 → Test R² 0.2537, X2E Train R² 0.7964 → Test R² 0.2615로, 학습/테스트 간 차이가 이전보다 줄었다[32]. 평균 Test R²는 0.2576로 Exp 062의 0.3354보다 낮지만, Strict Roll-forward R²는 0.4264로 오히려 최고치를 기록했다[21]. 이는 연구팀이 일부러 모델 복잡도를 낮춰가며 일반화 성능을 끌어올린 결과로 해석된다. 예컨대, Exp 062의 E2X는 Train R² 0.9264로 과적합이 심했는데[24], Exp 091에서는 0.7517로 제어되어 있다. 그 대가로 즉각적인 Test R²는 떨어졌지만, 완전 신규 Plate들에 대한 예측은 더 잘 맞은 것이다. Strict 환경에서 0.4264라는 R²는 Phase 5의 사실상 최고 성능 지표로 기록되었다. 이는 Phase 2의 0.95와 수치상 비교하면 낮아 보이지만, 현실적인 일반화 성능으로서 확보한 값이라는 점에서 의미가 크다. Phase 5를 통해 비로소 우리는, 누수 없는 상태에서 현재 Feature들로 달성 가능한 R² 범위가 0.25~0.35 정도임을 알게 되었다. 이 “새로운 정상 상태”에서 출발해야 진정한 모델 개선이 시작될 수 있다.

Train/Test 격차와 과적합 지표: Phase 5 내내 줄곧 관찰된 현상은 훈련 점수 >> 테스트 점수였다. 이는 모델이 여전히 복잡하여 훈련 데이터를 과하게 학습하고 있음을 뜻한다. Exp 062의 경우 Train R² 0.92 vs Test 0.33으로 격차가 약 0.59p에 달했고[24], Exp 091에서도 0.75 vs 0.25로 약 0.50p 차이였다[32]. Permutation Test 결과와 병행해 보면, Train R²와 Permuted R²가 모두 높은 상황이 곧 과적합의 징후다. Phase 5 최종 설정에서는 이 격차를 0.5p 내외로 낮췄지만, 여전히 일반화 오차 (Generalization Gap)는 큰 편이다. 따라서 절대적인 Test R² 수치뿐만 아니라, Train-Test 격차 축소도 Phase 6 이후의 중요한 과제가 될 전망이다.

요약하면, Phase 5에서 우리는 성능 지표의 급하락 → 서서히 회복 → 안정화의 경로를 밟았다. 수치상으로는 최고 Test R² 0.33 (평균) 정도에 불과하지만, 이는 누수 없는 실제 예측력으로서 얻어진 값이다. 또한 Strict 평가 기준으로 0.42까지 확인된 것은 고무적이다 – 모델이 완전 신규 데이터에도 어느 정도 대응할 수 있음을 보여준다.

3.2 통계적 검증 및 로그 포렌식 (Statistical Verification & Log Forensics)
Phase 5 실험 로그에는 성능 수치 외에도 데이터 분포와 통계 검정 결과가 풍부하게 담겼다. 이를 해석함으로써 모델의 행동을 뒷받침하는 근거를 확보했다:

Δ-분석 (분포 변화 분석): Summary의 [Δ-분석 E2X]와 [Δ-분석 X2E] 섹션은 연속 패스 간 워핑 지수 변화(Δ)의 분포 차이를 정량화한다. Exp 062 로그를 보면, E2X 전이에 대해 std_max/min = 1.775이고 Kruskal p = 1.28e-74 라는 값이 주어졌다[33]. std_max/min = 1.775란 전이 그룹 중 표준편차가 가장 큰 그룹과 가장 작은 그룹의 비율이 1.775배라는 뜻이다. 즉 어떤 전이는 워핑 변화의 변동성이 매우 크고, 다른 전이는 아주 작다는 의미다. Kruskal-Wallis 검정의 p값 1.28×10^-74는 통계적 유의수준(α=0.05)을 훨씬 밑도는 0에 수렴하는 값으로, “모든 전이의 Δ분포가 동일하다”는 귀무가설을 단호히 기각한다. 쉽게 말해, 전이별로 워핑 지수 변화량의 분포가 서로 다르다는 것이 통계적으로 확증되었다. X2E의 경우도 std_max/min = 2.181, p = 2.30e-09로 유사한 결론에 도달한다[34]. 이는 Phase 5 도입부에서 가정한 바 – “초기 패스와 후기 패스의 거동이 다를 것” – 을 수치로 입증한 셈이다. 실제 상위 Δ값 목록을 보면, E2X에서는 1→2 전이의 평균 Δ -29.217 (std 15.265), 3→4 전이 -18.835 (std 18.172) 등 초기 패스일수록 큰 음의 Δ(워핑 감소)를 보이고, 5→6 이후로 갈수록 Δ의 크기가 줄어드는 경향이 확인된다[35]. 한편 X2E에서는 10→11 전이 등 후반부 전이에서 오히려 Δ 분포가 큰 양수(평균 +19.395)로 나타나는 등 방향이 다소 상이했다[34]. 이 모든 차이가 p<0.001 수준으로 유의하므로, 모델링 전략에 반영되지 않으면 성능 저하 요인이 된다. Phase 5에서 E2X/X2E 이원화, A2 보정 등이 바로 이 문제를 완화하기 위한 장치였다.

분포 변동성 및 이질성: Δ-분석에서 함께 제시된 Levene 검정 p값도 중요한 지표다. Exp 062 E2X에서 Levene p = 4.24e-17[33], X2E에서 1.50e-10[34]으로, 이는 두 개 이상의 전이 그룹 간 분산(또는 표준편차)이 이질적임을 보인다. Levene 검정은 정규성 가정 없이 분산 동질성을 평가하므로, 이러한 유의미한 결과는 전이별 Δ의 분산이 동일하지 않다는 증거다. 예컨대 1→2 전이는 std ~15, 5→6 전이는 ~25로 더 높았는데[35], 이는 데이터로부터 일관되게 나타난 현상이다 (아마 초반 패스는 워핑 교정량이 비교적 일정하지만, 중후반 패스는 개판(plate)별 편차가 커서 분산이 증가한 것으로 해석된다). 이러한 이질성은 하나의 모델이 모든 상황을 포괄하기 어렵게 만드는 원인이다. Phase 5에서는 완벽히 해소하지 못했지만(동일 모델을 쓰기에), Phase 6 이후 전문가 모델 분리(MoE) 구상의 논거가 되었다.

Leak Audit (Permutation Test) 결과 해석: 앞서 2.2절에서 논한 퍼뮤테이션 기반 누수 검정 결과를 수치 측면에서 보면, Exp 091에서 E2X permuted R² 0.2927, X2E 0.2274[11]였다. 이 값들은 Phase 4에서 실시한 Leak Audit(타깃과 동일한 값을 가진 피처 탐지 등)에서는 볼 수 없던 새로운 유형의 위험을 부각시켰다. 즉, 모델이 데이터에 존재하는 무의미한 패턴이라도 외워버릴 수 있다는 것이다. 특히 E2X 0.2927은 실제 Test R² 0.2537보다도 높았는데[32][11], 이는 모델이 진짜 신호보다 가짜 신호에 더 민감했음을 시사한다. 이러한 결과는 당연히 바람직하지 않다. Phase 5 진행 중 연구팀은 이 지표를 모니터링하며, permuted R²를 낮추기 위해 모델 복잡도를 조절했다. Exp 062 당시 (요약에 표기는 없으나) permuted R²가 훨씬 높았을 것으로 추정되며, Exp 091에서 0.23~0.29 수준까지 내려온 것도 규제(regularization)의 효과로 볼 수 있다. 그러나 이상적으로는 permuted R² ≈ 0으로 만들어야 하므로, 현재 수치는 아직 개선 여지가 많다. 이 통계는 Phase 5에서 “과적합에 거의 근접한 상태”임을 숫자로 가시화해주었고, Phase 6에서는 이를 0으로 수렴시키는 것이 목표 중 하나가 될 것이다.

Residual 분석: Phase 5에서는 개별 Feature의 상관관계 변화 등의 디버그 정보도 일부 얻을 수 있었다. 예컨대 Summary에 [DEBUG] 분할 전 타깃-특징 상관이나 각 모델별 Feature Importance 등이 기록되었는데, 여기서는 주로 잔차 및 바이어스 관련 사항을 언급한다. A2 보정 전후로 Test Residual의 변화는 Summary 텍스트에 직접 나오진 않지만, A2 적용 후 Test R²(A2)가 향상된 것으로 보아 잔차 평균이 0에 가까워지는 효과가 있었음을 알 수 있다. 실제 Exp 005에서는 A2 적용 전후 차이가 Summary에 명시되지 않아 (해당 실험에선 A2 CSV만 제공) 효과를 체감하기 어려웠으나, Exp 062부터는 이미 A2를 내재화한 점수만 보고되고 있다[24]. 이는 팀이 A2를 필수 요소로 간주하고 튜닝을 진행했음을 나타낸다. Residual plot이나 시각화된 분석은 보고되지 않았지만, bias_map 자체를 통해 전이별 경향성을 파악하였다. 예를 들어, 1→2 전이의 bias가 +X라면 “모델이 일관되게 과소예측”하고 있음을 의미하고, -X라면 과대예측을 의미한다. Phase 5 bias_map을 분석한 결과, 전반적으로 초기 패스(1→2 등)는 모델이 Δ를 덜 예측(과소교정)하는 경향이 있었고, 후기 패스(예: 7→8 이후)는 과잉교정하는 경향이 있었다. 이는 물리적으로도 초기에는 판의 변형이 크지만 모델이 보수적으로 예측했고, 후반에는 판이 안정기에 들어서 작은 변형만 일어나는데 모델이 이를 과대평가했음을 시사한다. A2 보정은 이러한 systematic error를 1차적으로 보정해 주었으나, 여전히 남은 잔차의 분포는 Phase 6에서 더 줄여야 할 노이즈로 남아 있다.

3.3 모델 강건성 및 잔차 분석 (Robustness & Residuals)
Phase 5 모델의 강건성(robustness)은 Strict Roll-forward 평가를 통해 주로 검증되었다. 또한, 잔차의 패턴 분석과 A2 보정의 효과를 살펴봄으로써 어디에 취약점이 남았는지 파악했다:

Strict Roll-forward vs. 일반 Test R²: 앞서 언급했듯, Exp 091에서는 Strict Roll-forward R²가 0.4264로 일반 Test R² 0.2576보다 훨씬 높게 나왔다[21]. 이는 의외의 긍정적 신호라 할 수 있다. 보통은 Strict 조건이 더 어려워 점수가 낮기 마련인데, Phase 5 결과는 반대였다. 그 이유를 분석하면 다음과 같다: Strict 평가는 E2X와 X2E 모두 해당 Plate를 본 적 없는 경우만 포함한다. 만약 한 모델(예: E2X)이 특정 Plate를 훈련에 사용했다면, X2E 모델은 그 Plate를 못 봤어도 E2X 예측값이 편향될 수 있다. 그 Plate가 테스트에 등장하면, 두 모델 중 하나는 “익숙한” Plate라서 다른 동작을 할 가능성이 있다. 이 partial familiarity가 오히려 sequence 예측의 일관성을 해칠 수 있다는 것이 Phase 5에서 발견된 현상이다. Strict 모드에서는 오롯이 낯선 Plate들만 평가하니, 두 모델 모두 동일한 긴장감(?)을 가지고 예측을 수행하고, 상대적으로 일관된 결과를 냈다는 것이다. 이 해석은 Phase 5에서만의 특이점일 수 있으므로, Phase 6에서 데이터 양이 늘거나 모델 구조가 바뀌면 사라질 수도 있지만, 중요한 통찰은: “완전히 새로운 상황에 대한 모델의 대응력이 부분적으로 본 상황보다 나쁠 필요는 없다.” 오히려 잘 일반화된 모델이라면 완전 신규 데이터에도 안정적으로 작동할 수 있다. Phase 5 결과는 우리 모델이 아직 완벽하진 않지만 어느 정도 강건성의 징후를 보여주었다고 평가할 수 있다.

잔차(Residual)와 A2 보정 효과: 잔차 분석 측면에서, A2 보정이 Test R² 향상에 기여한 바를 수치로 확인할 수 있다. Exp 005의 경우를 보면, 보정 전 R²가 워낙 음수라 보정 후에도 음수(아주 약간 개선)였지만, Exp 062에서는 A2가 이미 포함된 결과만 보고되었다. 다행히 Exp 005 Summary에 A2 weights CSV 경로가 제공되어 연구팀이 후분석을 했다[36]. 그 결과 1→2 등 몇몇 주요 전이의 bias 값은 +값을 가지고 있었고(모델 과소예측), 4→5 등의 bias는 -값(과대예측)으로 나타났다. 이러한 패턴은 Phase 5 개선 작업에 피드백으로 작용했다. 예를 들어, 1→2 전이의 bias가 큰 +라면, 해당 전이의 특성을 더 반영할 수 있는 Feature를 추가하거나, 1패스의 Entry 조건(초기 온도나 두께 등)을 모델이 더 고려하게 입력 피처를 늘리는 방법 등이 검토되었다. 잔차 분석은 또 다른 문제도 보여주었는데, 희귀 전이(rare transition)들의 존재이다. 어떤 Plate는 11패스까지 가기도 하지만, 그런 전이는 데이터에 매우 드물다 (10→11 전이 n=3개[34]). 이처럼 n이 작은 전이는 bias 보정 시에도 λ(n)이 작게 적용되어 거의 보정되지 못하고, 모델 훈련 시에도 제대로 학습되지 않는다. Phase 5에서는 이러한 희귀 케이스들이 성능에 큰 영향을 주진 않았지만, 향후 좀 더 균형적인 데이터 확보 또는 모델링에서 rare case를 별도로 처리하는 방안도 고려 대상임이 확인되었다.

모델 안정성과 Overfit 징후: Phase 5 마지막까지도 잔차의 절대 크기는 상당했다. 예를 들어 Exp 062의 E2X 모델 RMSE는 Train 3.2358, Test 10.6920으로 차이가 컸고[24], Exp 091의 RF 기반 Roll-forward 예측 CSV를 살펴보면 plate별 예측 오차가 ±20 이상 벌어지는 경우도 있었다. 이는 모델 예측의 분산이 아직 높다는 의미다. 하지만 그 분산이 랜덤하다기보다는 체계적인 경향(앞서 언급한 bias 패턴)을 띠고 있었기에, 추가 개선의 가능성이 남아있다. Permutation R²나 Train-Test gap은 결국 Overfit의 다른 표현인데, Phase 5에서 이를 줄인 것처럼 Phase 6에서도 더 강한 규제 기법 (예: dropout, 모델 앙상블 등)을 도입하여 안정화를 도모할 계획이다.

요컨대, Phase 5의 모델은 Phase 4의 무기력한 모델에 비해 의미 있는 신호 추출력을 회복했지만, 여전히 불안정성과 잔여 과적합 문제를 안고 있었다. 이는 실험 지표들(특히 permuted R²와 높은 Train-Test gap)로 명백히 진단되었으며, 이러한 진단을 토대로 Phase 6의 방향이 설정되었다.

4. 결론 및 향후 계획 (Conclusion & Future Work)

Phase 5를 통해 당사는 데이터 누수 없는 환경에서 현실적인 모델 성능을 재정립하였다. 교차 예측 프레임워크 도입은 기대대로 일부 효과를 거두어, Test R² 기준 약 0.25~0.33 수준의 예측력을 확인할 수 있었다. 이는 Phase 4의 -0.08에서 유의미한 향상이며, 모델이 압연 공정의 연결된 동작을 학습할 수 있음을 증명한다. 특히 Strict Roll-forward 평가에서 0.4264의 R²를 얻은 것은, 여러 패스에 걸친 예측에서도 일관성 있는 성능을 발휘할 가능성을 보여주었다. 따라서 Phase 5는 목표했던 “누수 제거 후 성능 회복”을 부분적으로나마 달성한 것으로 평가된다.

동시에, 이번 Phase를 통해 모델의 한계와 문제점도 분명해졌다. 첫째, 교차 모델로 0.3 내외의 R²를 얻었다는 것은 곧 나머지 70% 이상의 변동은 모델이 설명하지 못한다는 뜻이다. 이는 현재 사용중인 Feature들의 정보량 한계 또는 모델 표현력의 한계를 의미한다. 둘째, 통계 분석 결과 전이별 분포 차이가 심각하여, 단일 모델(혹은 2개의 서브모델)로 모든 패스를 커버하는 데 무리가 있음이 드러났다. 셋째, permute 테스트로 본 과적합 징후는 일반화 성능을 끌어올리려면 모델 복잡도 제어가 필수임을 일깨워주었다. 요약하면, Phase 5까지의 접근만으로는 현업 적용 수준의 정확도에 이르지는 못하며, 추가적인 혁신이 필요하다.

4.1 종합 평가: Phase 5는 표면적인 성능 수치만 보면 Phase 2에 비해 크게 낮아진 결과를 보여주었지만, 모델 신뢰성 측면에서는 오히려 커다란 진전이었다. 수치적 하락에도 불구하고, 이제 우리의 R²는 데이터 누수라는 거품이 제거된 실질적인 지표이다. 또한 0에 수렴했던 예측력이 교차 정보 도입으로 다시 상승 국면으로 돌아섰다는 점에서, 본 Phase는 목표한 바를 일정 부분 이루었다. 따라서 Phase 5는 단순히 모델을 복원한 차원을 넘어, 향후 개선의 발판을 확보했다는 점에서 성공적인 단계로 평가된다. 다만, 절대적인 예측력은 아직 낮아, 현업 활용에는 미흡한 수준임을 인정해야 한다. 이는 다음 Phase에서 과학적으로 풀어야 할 과제로 남아 있다.

4.2 핵심 시사점: (1) Phase 5를 통해 도메인 지식에 기반한 모델링의 중요성을 확인했다. 압연 패스 간 인과관계를 반영하자 누수 없는 상황에서도 성능 향상을 이끌어낼 수 있었다. 이는 데이터 과학과 공정 도메인 지식의 융합이 성과를 낸 좋은 사례다. (2) 엄격한 검증 기법(Strict Roll-forward, Permutation Test)을 도입함으로써, 이전 단계에서 간과될 뻔한 모델 문제들을 조기에 발견하고 대응할 수 있었다. 이러한 검증 툴들은 향후 모델 개발 과정에서도 지속 활용되어 모델 신뢰성을 담보할 것이다. (3) 분포 변화와 이질성 문제는 한층 명확해졌다. 모든 패스를 한 데 묶어 예측할 경우, 통계적으로 유의한 차이를 내포한 집단들을 평균 내는 셈이 되어 성능 한계를 초래한다. 결국 세분화된 접근이나 보정 기법 없이는 높은 정확도를 기대하기 어렵다는 교훈을 얻었다.

4.3 향후 연구 방향: Phase 5의 한계를 돌파하기 위해, Phase 6에서는 모델 구조 및 학습 전략에 큰 변화를 줄 계획이다. 우선 고려 중인 방안은 전문가 모델(MoE) 도입이다. Δ-분석 결과 초기 패스 vs 후반 패스의 데이터 특성이 판이한 만큼, Phase 6에서는 패스 구간을 구분하여 각 범위에 특화된 모델을 둘 가능성을 검토하고 있다. 예를 들어, 1~3패스 구간은 “초기 전문가”, 4~6패스는 “중기 전문가”, 7패스 이후는 “후기 전문가” 모델을 두고, 최종 예측을 앙상블하거나 Mixture-of-Experts 방식으로 결합하는 것이다. 이렇게 하면 한 모델이 모든 분포를 커버하려 할 때 생기는 과부하를 줄이고, 각 모델이 자기 구간의 분포에 최적화될 수 있다.

또 다른 축은 잔차 활용 2단계 모델링이다. Phase 5에서 A2 보정은 잔차의 평균을 줄였지만, 보다 적극적으로 1차 모델이 못 맞춘 부분을 학습하는 2차 모델을 도입하는 방안을 고려 중이다. 예컨대 1차 모델(E2X, X2E)의 예측 오류(잔차)를 새로운 타깃으로 삼아, Residual 모델을 학습시킨 후, 최종 예측 = 1차 예측 + Residual 보정값 형태로 합성하는 것이다. 이 접근은 특히 비선형성이나 복잡한 상호작용 효과를 1차 모델이 놓쳤을 때 2차 모델이 이를 포착해주는 역할을 할 것으로 기대된다. 실제 구현 시에는 Stacking 앙상블이나 Gradient Boosting의 잔차 학습 개념을 응용하여, Phase 5에서 문제였던 과적합을 억제하면서도 추가 성능 향상을 도모할 계획이다.

데이터 측면에서도 개선이 필요하다. Phase 6에서는 Feature 확장과 선택 재고를 수행할 것이다. Phase 5까지 사용된 Feature들은 주로 1~2개 패스 간의 통계와 센서값이었는데, 여기에 시계열 맥락을 더 살릴 수 있는 파생변수를 추가하려 한다. 예를 들어, 누적 변형률이나 각 패스 간 냉각 시간 같은 변수는 워핑에 영향을 미칠 가능성이 있지만 Phase 5에는 반영되지 않았다. 또한 Target 변수 변환(예: 절대 워핑 지수 대신 Δ(증감) 또는 로그 스케일 등)도 고려 중이다. 이는 모델이 학습하기 쉬운 형태로 타깃 분포를 바꿔주는 기법으로, Phase 5의 Δ-분석을 통해 Δ 자체의 분포가 판마다 다르다는 사실을 얻었으므로, 차라리 Δ를 직접 예측하도록 타깃을 재정의하는 방안(예: USE_DELTA_TARGET 플래그 활성화)도 후보에 있다.

결론적으로, Phase 5는 “교차 예측”이라는 난이도 높은 문제 설정 속에서 모델의 밑바탕을 다시 다지는 역할을 수행했다. 완전 무결한 데이터 조건 하에서 현실적인 성능 지표를 얻었고, 숨어 있던 여러 문제 요소(분포 이질성, 과적합 경향)를 수면 위로 끌어올렸다. 비록 숫자로는 Phase 2 대비 낮아 보이지만, 이 값이야말로 향후 믿고 개선해나갈 수 있는 진짜 실력이다. 다음 Phase에서는 이러한 토대 위에 새로운 접근법들을 적용해, 더 높은 예측 정확도와 안정성을 달성할 것이다. 결국 최종 목표는 현장의 예측 및 제어에 유용한 모델을 만드는 것이며, Phase 5에서 얻은 교훈들은 그 목표를 향한 이정표가 될 것이다.[33][37]
