# phase 9

[Phase 9] : 데이터 분포 변화 대응을 통한 모델 성능 복원

1. 개요 및 연구 배경
Phase 8까지 지속된 성능 저하 원인을 분석한 결과, 데이터 분포의 시간적 변화가 주요 요인으로 지목되었다. 특히 초기 패스와 후반부 패스에서 warping index 값 분포가 크게 달라지는 현상이 관측되었고, 이 분포 불일치로 인해 모델 예측력이 급격히 떨어진 것으로 판단되었다. 이에 연구팀은 타깃 변수의 추세 제거(Detrending)를 통해 이러한 분포 차이를 보정하고자 하였다. 구체적으로 각 압연 판(Plate)의 초기 상태나 패스 진행도에 따른 기준치를 타깃 값에서 차감하여, 시간 경과에 따른 전반적인 감소 추세를 제거하는 방안을 채택하였다. 아울러 Plate별 데이터량 불균형으로 특정 판의 데이터가 모델에 과도한 영향을 주는 문제도 인지되어, 학습 단계에서 표본 가중치 조정을 병행하는 전략이 수립되었다.

2. 기술적 구현 및 감사 결과
- 추세 제거(Detrending) 구현: Phase 9부터 모델은 연속 패스 간의 변동분을 예측하도록 개선되었다. scripts/165_test_no_op.py를 기점으로 코드에서 USE_DELTA_TARGET 플래그가 활성화되어, 타깃 변수를 계산할 때 현재 패스의 warping 값을 다음 패스의 값에서 빼주는 로직이 적용되었다. 그 결과, 모델의 학습 타깃이 “다음 패스 증분값”으로 정규화되어 초기와 후기 패스 간 분포 차이가 완화되었다. 또한 동일 파일에서 패스 진행도 지표(FM_PASS_progress)가 도입되어, 각 데이터가 전체 공정에서 몇 번째 패스인지 정보를 특징으로 활용하게 하였다. 이러한 코드를 통해 시간 경과에 따른 체계적인 변화 추세를 모델이 자체적으로 보정할 수 있는 기반이 마련되었다.
- 데이터 가중치 조정: Phase 9 중반부터 Plate 불균형 완화를 위한 표본 가중치가 도입되었다. 초기에는 패스별 warping 변동 분산 규모에 따라 가중치를 부여하는 이분산 가중치 기법이 실험되었으나, 효과가 제한적이었다. 따라서 scripts/189_test_no_op.py에서 Plate별 균형 가중 로직이 새로 추가되었다. 구현상 학습 데이터 내 각 Plate의 표본 수에 반비례하도록 가중치를 설정(w = 1/표본수), 데이터가 많은 압연 판의 영향력을 줄이는 방식이다. 이 변경으로 모델 학습 시 모든 Plate를 고르게 고려하도록 유도하여, 특정 대용량 Plate에 치중하던 학습 편향을 완화하였다.
- 데이터 누수 점검: 본 Phase의 코드에 대해 6가지 유형의 데이터 누수 패턴(A~F)을 면밀히 검사한 결과, 특별한 누수 사례는 발견되지 않았다. 학습 파이프라인 상에서 타깃 _target 컬럼은 철저히 피처 목록에서 제외되고 있으며, 그룹 기반 데이터 분할(Plate 단위의 GroupShuffleSplit)로 동일 압연 판의 기록이 훈련∙테스트에 중복되지 않도록 관리되었다. 또한 이전 Phase에서 문제가 되었던 미래 시점 정보 누출(예: shift(-1) 활용) 역시, 이번 Phase에서는 각 Plate 내부에서 순차적 타깃 생성에만 활용되며 모델 입력 피처로는 사용되지 않았다. 아울러 전역 통계치 사용에 따른 누수 가능성에 대비하여, USE_RM_TRAINONLY 등의 플래그가 코드에 포함되어 필요한 경우 테스트 세트 정보가 포함된 통계 변수를 배제할 수 있도록 설계되었다. 이러한 예방 조치들과 누수 스크리닝 절차(피처 상관 검증 등)가 Phase 9에서도 엄격히 적용되어, 모델 성능 향상이 누수에 기인하지 않았음을 확인하였다.

3. 실험 결과 및 시사점
- 성능 향상 추이: 분포 보정 전에는 테스트 R² 값이 -0.1 내외로 음수를 기록하고, 특히 detrending을 끄면 -0.5 수준까지 급락하는 등 모델이 실제 예측력을 발휘하지 못했다. 그러나 Detrending 적용 후 테스트 성능이 비약적으로 향상되어, 초기 실험(예: 171번)에서 거의 0에 수렴하던 테스트 R²가 174번 실험 이후 +0.16 ~ +0.18 수준으로 반전되었다. 이는 평균 편차 제거로 예측 난이도가 완화되고 모델이 유의미한 신호를 학습하게 되었음을 보여준다. 이어서 Plate 균형 가중치를 도입한 결과 일시적으로 성능 저하(189번 실험: R²≈0.13)가 있었으나, 가중치 산정 기준을 조정한 후 0.1852(194번 실험)까지 성능이 재반등하였다. 최종적으로 Phase 9 말까지 평균 테스트 R²가 0.19± 수준으로 회복되었으며, 이는 Phase 4 이후 최저점이었던 -0.08 대비 크게 개선된 수치이다.
- 시사점: 이번 Phase를 통해 데이터 분포 변화에 대한 모델 대응력 확보가 성능 유지에 필수적임이 입증되었다. 분포 차이를 제거하자 모델의 추정 능력이 본래 수준으로 복원되었고, 이는 이전의 저조한 성능이 모델 구조의 한계가 아니라 데이터 세트 편향에 기인한 것이었음을 시사한다. 아울러, 학습 데이터 구성의 불균형(특정 Plate 편중)을 보정함으로써 더욱 안정적인 예측 성능을 얻을 수 있었다. 정량적 감사 결과, Phase 9의 성능 향상은 데이터 누수 없이 얻어진 유효한 개선으로 확인되었다. 연구팀은 “이제 분포 격차는 상당 부분 해소되었다. 남은 과제는 미세한 최적화”라고 평가하였으며, 이는 후속 Phase에서의 세부 튜닝 및 고도화 작업의 방향성을 제시한다.
